## 9.1 章节总览

- **广播**：共享介质上「一对全」，**所有主机 CPU** 都要过一遍协议栈（至少到 L4 才能丢弃）。  
- **组播**：仅**加入组**的主机处理；依赖 **D 类地址 / IPv6 ff00::/8** 与成员管理协议。  
- **IPv6**：**废除广播**，由**链路本地组播**等替代（见 ch02）。

<a id="ch09-2"></a>

## 9.2 广播（Broadcasting）

### 地址类型

| 类型 | 地址 | 转发 |
|------|------|------|
| **受限广播** | **255.255.255.255** | **仅本地链路**，路由器**不转发** |
| **定向广播** | 子网内主机位全 1 | 指向特定子网；**现代路由器默认禁止跨子网转发** |

### 定向广播计算

```text
定向广播 = IP | (~掩码)
```

**例**：`128.32.1.14/24`，掩码 `255.255.255.0`  
→ `128.32.1.14 | 0.0.0.255` = **`128.32.1.255`**

→ 详表：[ch02 广播地址](../01_architecture/ch02_internet_addresses.md#ch02-3)

### 数据流

1. 应用/UDP → IP 目的为广播地址  
2. 链路层 → 以太网 **`FF:FF:FF:FF:FF:FF`**  
3. 子网内**所有网卡**收帧 → 中断 → 栈解析至传输层再决定是否丢弃  

### 易混

| 误区 | 事实 |
|------|------|
| IPv6 仍有广播 | **无**；用链路本地**组播**等替代 |
| 路由器默认转发定向广播 | **否**（防 **Smurf** 等）→ [ch08 §攻击](../03_network_layer/ch08_icmpv4_icmpv6.md#ch08-7) |

## 9.3 组播（Multicasting）

**逻辑分发**：L3 组播组 → L2 硬件地址映射是核心。

### IPv4 组播 → 以太网 MAC（9.3.1）

```text
IPv4 组播 (32b):
  [1110][00000][23 bit 组 ID 低23位映射到 MAC]
   D类   丢弃5位

以太网 MAC (48b):
  [01:00:5E][0][23 bit 来自 IP 的低23位]
   IANA前缀  固定位
```

- **32:1 重叠**：IP 组 ID 有 **28** 位参与映射，MAC 只留 **23** 位 → **32** 个不同 IP 组播地址可映射到**同一 MAC**（2⁵=32）。

### 三级过滤（减轻 CPU）

1. **硬件**：网卡只收已注册组播 MAC  
2. **链路层**：剔除 32:1 重叠带来的**无关**组播帧  
3. **网络层**：按**完整 IP 组播地址**最终匹配  

### 地址空间

| 版本 | 范围 |
|------|------|
| **IPv4** | **D 类** `224.0.0.0/4` |
| **IPv6** | **`ff00::/8`** |

## 9.4 IGMP 与 MLD

**软状态（Soft State）**：路由器不永久保存成员表；**查询–响应**周期刷新，超时则删除组状态。

### 查询–响应周期

1. **查询器（Querier）** 发 **General Query**  
2. 主机启动**随机倒计时**后发 **Membership Report**  
3. **报告抑制（v1/v2）**：听到同组他人已报告 → **抑制**自己的报告，减流量  
4. **IGMPv3**：支持 **SSM（特定源组播）**，需每主机报告**源列表** → 抑制机制**弱化/禁用**

### 代际对比

| 特性 | IGMPv1 | IGMPv2 | IGMPv3 |
|------|--------|--------|--------|
| 查询 | 通用 | + **特定组**查询 | + **特定源**查询 |
| 离组 | 静默（靠超时） | **Leave Group** | 含于成员报告 |
| 核心 | 成员发现 | 降低离组延迟 | **SSM** |

**MLD**：IPv6 侧等价物，基于 **ICMPv6**（与 ND 同属 ICMPv6）→ [ch08 §8.2](../03_network_layer/ch08_icmpv4_icmpv6.md#ch08-2)

### Querier 选举

子网上 **IP 最小** 的路由器/设备常成为 **Querier**。

<a id="ch09-5"></a>

## 9.5 安全：IGMP / MLD 相关攻击

| 攻击 | 说明 |
|------|------|
| **放大（Smurf 等）** | 定向/受限广播 + 伪造源 IP → 大量主机向受害者回包 |
| **虚假成员报告 DoS** | 海量 Join → 耗尽路由器**组播状态表** |
| **查询器欺骗** | 伪造低 IP 的 Query 抢占 **Querier** |

### 防御清单

1. **组播边界**（接入端口）  
2. **每端口组播组数量上限**  
3. **`no ip directed-broadcast`**（默认关闭定向广播转发）  
4. 与 [ch07](../03_network_layer/ch07_firewall_nat.md#ch07-7) 边界策略联动

<a id="ch09-exam"></a>

## 9.6 总结与考点

从 **L2 广播** → **L3 组播映射** → **IGMP/MLD 信令** 构成完整「受控大规模分发」链路。

### 单播 vs 广播 vs 组播

| 指标 | 单播 | 广播 | 组播 |
|------|------|------|------|
| 地址 | A/B/C 等 | 子网全 1 / 255.255.255.255 | D 类 / **ff00::/8** |
| 范围 | 一个接口 | 子网**全部**主机 | **加入组**的主机 |
| 协议依赖 | 基本无 | 链路层特性 | **IGMP/MLD** 软状态 |
| 可扩展性 | 高（点对点） | **低**（单子网） | **高**（可跨域，需 PIM 等） |
| CPU | 仅目标 | **全员解析** | 过滤后仅成员 |

### 易混速记

| 问题 | 要点 |
|------|------|
| 255.255.255.255 vs x.x.x.255 | **受限** vs **定向**广播 |
| 32:1 映射 | 32 个 IP 组播 → 1 个 MAC，需 **L3 再过滤** |
| IGMPv2 vs v3 抑制 | v3 **SSM** 需源信息，抑制不同 |
| v6 无广播 | 用 **ff02::** 等链路本地组播（ND、DHCPv6） |
| UDP/TCP | **UDP** 可组播；**TCP** 仅单播连接 |

### 工程联系

CDN、视频会议路由、**mDNS**、IPv6 **ND/SLAAC** 均依赖组播过滤与成员发现。
