# 4.4 SDN 软件定义网络 与 OpenFlow

> 章级精读：[§4.4 Match+Action](../study.md#ch4-4) · 控制平面 SDN：[§5.5](../../05_network_layer_control_plane/study.md#ch5-5)

## 一、传统网络痛点

- 控制平面与数据平面强耦合
- 每台设备单独配置，运维复杂
- 协议封闭、难以全局流量调度

## 二、SDN 核心思想

**控制平面与数据平面彻底解耦**

1. **转发设备（交换机）**：只负责纯粹数据转发
2. **集中式 SDN 控制器**：全局统一计算路由、下发流表

## 三、SDN 三层架构

1. **应用层**：网络业务 APP（负载均衡、流量工程）
2. **控制层**：SDN 控制器（OpenDaylight、Floodlight）
3. **数据层**：OpenFlow 交换机

## 四、OpenFlow 协议

OpenFlow 是 SDN 控制器与交换机之间的**南向接口**协议。

### 核心概念

- **流表（Flow Table）**：多条流表项组成
- 流表项：**匹配字段** + 计数器 + **动作指令**
- 匹配：源/目的 IP、端口、VLAN 等
- 动作：转发、丢弃、修改、排队

### 工作流程

交换机收到未知数据包 → 上报控制器 → 控制器计算下发流表 → 交换机后续直接匹配转发

## 五、SDN 优势

- 全局网络视图、灵活可编程
- 统一管控、自动化运维
- 快速创新业务
