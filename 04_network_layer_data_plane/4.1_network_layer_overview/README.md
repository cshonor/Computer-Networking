# 4.1 — network layer overview

## 知识点速记

- **数据平面**：局部、高速**转发**；**控制平面**：全局**路由选择**与表项生成。  
- **转发 vs 路由**：立交选出口 vs 出发前规划全程。  
- **SDN**：控制外移、数据平面按表 **Match+Action**。  
- **Best-effort**：不保带宽/时序/不丢；换**可扩展**与端系统复杂度上移。

## 与后端开发的联系

- 理解「包为什么这样走」：VPC 路由、容器 CNI、云厂商 ELB 与 NAT 网关，都叠在 IP 转发语义之上。
