# 4.1 网络层概述

> 章级精读（数据平面）：[总览](../study.md#ch4-dp-topdown) · [FIB](../study.md#ch4-fib) · [控制平面](../../05_network_layer_control_plane/study.md#ch5-control-plane-basics)

## 一、网络层核心定位

网络层是 TCP/IP 模型第 3 层，核心职责：

1. **端到端传输**：将源主机的分组，跨越多个网络送达目的主机
2. **寻址**：全局唯一 IP 地址规划
3. **路由选择**：选择最优传输路径（**控制平面**）
4. **分组转发**：将数据包从路由器入端口送到出端口（**数据平面**）

## 二、网络层两大核心平面（重中之重）

| 平面 | 核心职责 | 执行者 |
|------|----------|--------|
| **数据平面**（Data Plane） | 查表、转发数据包、本地处理 | 路由器/交换机硬件 |
| **控制平面**（Control Plane） | 计算路由、生成维护路由表、协议交互 | 路由协议、SDN 控制器 |

## 三、网络层提供的服务模型

1. **虚电路服务**：面向连接，保证顺序、可靠、拥塞控制（ATM、帧中继）
2. **数据报服务（互联网主流）**：无连接、尽力而为、不保证顺序/可靠/时延

## 四、与上下层关系

- **上层**：运输层（TCP/UDP），为其提供主机到主机交付能力
- **下层**：数据链路层，为其提供链路到链路交付能力
