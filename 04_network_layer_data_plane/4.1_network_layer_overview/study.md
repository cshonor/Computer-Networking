# 4.1 网络层概述

> 章级精读（数据平面）：[总览 #ch4-dp-topdown](../study.md#ch4-dp-topdown) · [FIB](../study.md#ch4-fib) · 控制平面：[05 章 #ch5-control-plane-basics](../../05_network_layer_control_plane/study.md#ch5-control-plane-basics)

## 本节核心目标

掌握网络层**定位**、**数据平面 vs 控制平面**、**虚电路 vs 数据报**，以及 **FIB 与路由表** 的关系。

---

## 一、网络层核心定位（必背）

网络层是 TCP/IP 的**网际层（第 3 层）**，负责**主机到主机**跨越**异构网络**的分组交付。

| # | 职责 | 说明 |
|---|------|------|
| 1 | **端到端传输** | 源主机分组 → **跨多个网络** → 目的主机 |
| 2 | **寻址** | **全局唯一 IP 地址**，标识主机 / 路由器**接口** |
| 3 | **路由选择** | 计算路径、生成路由表（**控制平面**） |
| 4 | **分组转发** | 入端口 → 查转发表 → 出端口（**数据平面**） |

一句话：**网络层 = 寻址 + 选路 + 转发**。

---

## 二、网络层两大核心平面（重中之重）

![控制平面 RIB/路由表 → 下发 → 数据平面 FIB 转发](../assets/rib_fib_control_data_plane.png)

<a id="ch4-1-diagram-planes"></a>

### 1）数据平面（Data Plane）—— 执行层

| 项 | 内容 |
|----|------|
| **职责** | **查表、高速转发、本地处理** |
| **执行者** | 路由器 / 交换机**硬件**（ASIC / TCAM 等） |
| **核心表** | **FIB（转发表）**，由控制平面生成 |
| **特点** | **高速、线速、按表执行**（教材常称相对「无状态」转发） |
| **工作** | 分组到达 → **查 FIB（LPM）** → 从出端口发出 |

→ 转发六步：[章级 #ch4-dp-topdown](../study.md#ch4-dp-topdown)

### 2）控制平面（Control Plane）—— 决策层

| 项 | 内容 |
|----|------|
| **职责** | **计算路由、维护拓扑、生成路由表 → 下发 FIB** |
| **执行者** | **OSPF / BGP / RIP** 等路由协议；**SDN 控制器** |
| **核心表** | **路由表 / RIB**（路由信息库） |
| **特点** | **全局视野、智能决策**（分布式或集中式） |
| **工作** | 交换拓扑与可达性 → 算最优 / 可行路径 → 写入路由表 → **安装到 FIB** |

→ 控制平面详读：[第 5 章](../../05_network_layer_control_plane/study.md)

### 3）对比表（必背）

| 平面 | 核心职责 | 执行者 | 核心表 | 特点 |
|------|----------|--------|--------|------|
| **数据平面** | **转发**分组 | 硬件 | **FIB**（转发表） | 高速、执行 |
| **控制平面** | **选路**、算路由 | 协议 / 控制器 | **路由表 / RIB** | 智能、决策 |

记忆：**控制算路，数据转发；路由表是蓝图，FIB 是执行表**。

**易错**：**转发（数据平面）≠ 路由选择（控制平面）**；**路由表 ≠ FIB**（内容可经策略转换，转发只看 FIB）。

## 三、网络层提供的服务模型（必背）

### 1）虚电路服务（面向连接）

| 项 | 内容 |
|----|------|
| 特点 | **先建连接、固定路径、按序、网络侧保证**（依实现） |
| 过程 | 建立 → 传输 → 释放 |
| 地址 | 建链用**完整地址**；传输用**虚电路号 VC#** |
| 典型 | ATM、帧中继、X.25 |

### 2）数据报服务（Internet 主流，无连接）

| 项 | 内容 |
|----|------|
| 特点 | **无连接**；每分组**独立选路**；**尽力而为** |
| 不保证 | 顺序、可靠、时延、带宽 |
| 可靠性 | 由**运输层（TCP）**等端系统实现 |
| 典型 | **IP**（互联网标准） |

### 3）为什么互联网选数据报（必考）

1. 网络**异构、规模极大** → 虚电路**建链 / 状态**开销大  
2. **端系统智能强** → 可靠、拥塞等交给 **TCP** 更灵活  
3. **抗故障**：分组可**动态绕开**故障链路  
4. **资源利用率高**：无需全程预留，**按需**占用  

### 4）对比表（超高频）

| 特性 | **虚电路** | **数据报（IP）** |
|------|------------|------------------|
| 连接 | 面向连接（建 / 释） | **无连接** |
| 路径 | **固定**同一路径 | 每分组**独立**选路 |
| 地址 | 建链完整地址；传输 **VC#** | 每分组带**完整 IP** |
| 可靠性 | 常由**网络层**保证 | **运输层（TCP）** |
| 典型 | ATM、帧中继 | **IP** |

## 四、与上下层关系

| 层 | 交付范围 | 关系 |
|----|----------|------|
| **运输层**（TCP/UDP） | **进程 ↔ 进程** | 网络层提供**主机 ↔ 主机** |
| **网络层** | **主机 ↔ 主机**（跨网） | 本层 |
| **数据链路层** | **相邻节点**（一跳） | 为网络层提供**链路交付** |

一句话：**链路层负责一跳，网络层负责全程，运输层负责进程**。

→ 封装顺序：[章级 #ch4-encapsulation](../study.md#ch4-encapsulation) · [第 3 章](../03_transport_layer/study.md)

## 五、本节核心考点（必背清单）

1. **数据平面 vs 控制平面**：职责、执行者、**FIB / 路由表**  
2. **网络层 vs 运输层**：主机到主机 vs 进程到进程  
3. **虚电路 vs 数据报**：连接、路径、可靠性、典型协议  
4. **互联网为何选数据报**：异构、端智能、抗故障、利用率  
5. **FIB 与路由表**：控制平面生成路由表 → **下发** → 数据平面 **FIB 转发**

## 六、考试 / 面试速记

### 5 行终极口诀

1. **网络层 = 寻址 + 选路 + 转发；交付主机到主机**  
2. **控制算路、数据转发；路由表蓝图，FIB 执行**  
3. **虚电路：建链、固定路径、VC 号；数据报：无连接、IP 尽力**  
4. **互联网选数据报：异构规模大、端智能、抗故障、利用率高**  
5. **链路一跳、网络全程、运输进程；转发 ≠ 路由**  

### 30 字版

**寻址选路转发；控制RIB数据FIB；数据报无连接IP尽力；虚电路固定VC；转发非路由。**
