# 4.2 路由器工作原理 · 考点速记

> 章级完整版：[../study.md#ch4-2](../study.md#ch4-2)

## 核心一句

**路由器 = 控制平面（算路）+ 数据平面（高速转发）**

## 四大件（必背）

1. **输入口**（数据/硬）：LPM + **TCAM**，TTL−1  
2. **交换结构**（数据/硬）：内存慢 / 总线堵 / **Crossbar** 并行（[图](../assets/crossbar_switching_fabric.png)）  
3. **输出口**（数据/硬）：排队调度 → 发出  
4. **路由处理器**（控制/软）：OSPF/BGP → 路由表 → **转发表下发**

## 排队

- **输入**：**HOL 排头阻塞**  
- **输出**：超线速 → **尾部丢包**

## 缓冲

`B ≈ RTT×R`；多流 `B ≈ RTT×R/√N`；过大 **Bufferbloat**

## 调度

FIFO / 优先级 / **WFQ**

## 易混

路由表（控制）≠ 转发表（数据）；转发 ≠ 路由；背板 ≠ 端口速率之和
