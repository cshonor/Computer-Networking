# 4.2 路由器内部工作原理

> 章级精读：[§4.2 四大件](../study.md#ch4-2) · [输入口与 MAC](../study.md#ch4-input-port-mac) · [Crossbar](../study.md#ch4-2-crossbar)

## 一、路由器核心硬件组成

1. **输入端口**：物理层、数据链路层、**查转发表（FIB）**
2. **交换结构（Switching Fabric）**：内部高速转发，连接输入与输出端口
3. **输出端口**：分组缓存、调度、发送到链路
4. **路由处理器**：运行路由协议、计算路由、生成路由表（**控制平面**，非每包转发路径）

## 二、路由器完整转发流程（数据平面）

1. 端口接收链路帧 → 解封装拿到 IP 分组
2. 提取目的 IP 地址
3. 查询**转发表**（最长前缀匹配 LPM）
4. 通过交换结构转发到对应输出端口
5. 输出端口排队、调度、重新封装发送

→ [逐跳转发全流程](../study.md#ch4-packet-walkthrough)

## 三、三种典型交换结构

1. **内存交换**：早期低速路由器，CPU 转发
2. **总线交换**：共享总线，存在带宽瓶颈
3. **纵横矩阵交换（Crossbar）**：并行高速，高端设备主流

## 四、缓冲区与队列丢包

- 输出端口队列溢出 → **尾部丢弃**
- 队列管理：RED、WFQ 等拥塞避免算法

## 五、本节易错点

- **路由表 RIB**（控制平面生成）≠ **转发表 FIB**（数据平面转发用）
- 路由器隔离广播域、分隔冲突域；二层交换机**不能**隔离广播域
