# 4.2 — router internal working

## 知识点速记

- **四块**：输入（LPM/TCAM）→ 交换结构（内存/总线/Crossbar）→ 输出（队列/调度）→ 控制 CPU。  
- **输入/输出排队**与 **HOL 阻塞**概念。  
- **调度**：FIFO、优先级、**WFQ**。  
- **缓冲**：警惕 Bufferbloat；经验式 **`B ≈ (RTT·R)/√N`** 仅作量级直觉（见章内说明）。

## 与后端开发的联系

- 云上「同区延迟」与「跨区 RTT」、队列丢包导致 TCP 吞吐塌陷，都与路由器/交换机排队与缓冲策略相关。
