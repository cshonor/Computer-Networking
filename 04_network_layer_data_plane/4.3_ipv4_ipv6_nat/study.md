# 4.3 IPv4、IPv6 与 NAT

> 章级精读：[§4.3 IP 转发](../study.md#ch4-3)

## 一、IPv4 协议核心

1. IPv4 地址：32 位，点分十进制表示
2. IP 分组头部：版本、TTL、源 IP、目的 IP、协议号、校验和
3. 地址分类：A/B/C/D/E 类（现已淘汰，主流无类 **CIDR**）
4. CIDR 与子网划分、最长前缀匹配

## 二、IPv4 局限性

- 地址空间枯竭
- 头部设计僵化
- 缺乏原生安全性、移动性支持

## 三、NAT 网络地址转换

### 核心作用

让多个内网私有 IP，共用少量公网 IP 访问互联网，缓解 IPv4 地址不足。

### 三种类型

1. **静态 NAT**：私有 IP ↔ 公网 IP 一对一固定
2. **动态 NAT**：从公网 IP 池动态分配
3. **NAPT/PAT（主流）**：IP + 端口号复用，多主机共用一个公网 IP

### NAT 优缺点

- 节约公网地址、内网隐藏安全
- 破坏端到端连通、P2P/IPsec 等协议兼容差

## 四、IPv6 核心升级

1. 128 位地址，海量地址空间
2. 简化头部，转发效率更高
3. 原生支持 IPsec、自动地址配置、更好的移动性
4. 不再需要 NAT

## 五、过渡技术

- 双栈、隧道技术（6to4）、NAT64

## 六、本节核心考点

- 私有 IP 地址段（`10/8`、`172.16/12`、`192.168/16`）
- NAT 工作原理与端口映射
- IPv4 vs IPv6 核心差异
