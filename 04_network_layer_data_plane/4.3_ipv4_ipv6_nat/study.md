# 4.3 IPv4、IPv6 与 NAT

## 一、IPv4 协议核心

> 首部结构图：[§4.3 IPv4 首部](../study.md#ch4-ipv4-header)

![IPv4 数据报首部](../assets/ipv4_datagram_header.png)

1. IPv4 地址：32 位，点分十进制表示
2. **IP 数据报** = 首部（常 20B）+ 数据；被**以太网帧**封装逐跳传输
3. 首部关键字段：版本、首部长度、**TTL**、**协议号**、**首部校验和**、**源/目的 IP**（后两者端到端不变）
4. 地址分类：A/B/C/D/E 类（现已淘汰，主流无类 **CIDR**）
5. CIDR 与子网划分、最长前缀匹配（路由器 **LPM** 查表）

## 二、IPv4 局限性

- 地址空间枯竭
- 头部设计僵化
- 缺乏原生安全性、移动性支持

## 三、NAT 网络地址转换

### 核心作用

让多个内网私有 IP，共用少量公网 IP 访问互联网，缓解 IPv4 地址不足。

### 三种类型

1. **静态 NAT**：私有 IP ↔ 公网 IP 一对一固定
2. **动态 NAT**：从公网 IP 池动态分配
3. **NAPT/PAT（主流）**：IP + 端口号复用，多主机共用一个公网 IP

### NAT 优缺点

- 节约公网地址、内网隐藏安全
- 破坏端到端连通、P2P/IPsec 等协议兼容差

## 四、IPv6 核心升级

1. 128 位地址，海量地址空间
2. 简化头部，转发效率更高
3. 原生支持 IPsec、自动地址配置、更好的移动性
4. 不再需要 NAT

## 五、过渡技术

- 双栈、隧道技术（6to4）、NAT64
