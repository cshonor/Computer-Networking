# 4.3 — ipv4 ipv6 nat

## 知识点速记

- **IPv4**：首部字段、**TTL**、分片与 **PMTUD** 倾向。  
- **CIDR** 与**子网划分**；**DHCP** Discover/Offer/Request/ACK。  
- **NAT**：缓解地址枯竭；破坏端到端透明。  
- **IPv6**：128 位、首部简化；**隧道**穿越 IPv4 网络。

## 与后端开发的联系

- K8s Service、SNAT/DNAT、双栈与 Happy Eyeballs；排障时核对 **MTU/MSS** 与分片。
