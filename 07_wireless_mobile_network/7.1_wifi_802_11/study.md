# 7.1 WiFi 与 802.11 协议

> 章级精读：[§7.1–7.3](../study.md#ch7-1)

## 一、802.11 协议栈定位

- 工作在链路层，是无线局域网（WLAN）的主流标准
- 物理层：不同标准对应不同调制技术（802.11a/b/g/n/ac/ax）
- MAC 层：CSMA/CA + ACK 确认机制

## 二、802.11 网络架构

- **有中心架构**（基础设施模式）：AP（接入点）+ 无线客户端
- **无中心架构**（Ad-Hoc 模式）：客户端之间直接通信，无需 AP
- **BSS**（基本服务集）：一个 AP 及其连接的客户端组成的网络
- **ESS**（扩展服务集）：多个 BSS 通过 DS（分发系统）互联，组成大网络

## 三、MAC 层核心：CSMA/CA 工作流程

> 与有线 **CSMA/CD** 对比 → [§6.3 · CSMA 专节](../../06_link_layer_and_lan/study.md#ch6-csma)

1. 发送前监听信道，等待 DIFS 时间，信道空闲则发送
2. 发送 RTS（请求发送）帧，预约信道时间
3. 接收方回复 CTS（允许发送）帧，确认预约
4. 发送方发送数据帧
5. 接收方回复 ACK 确认

- 核心目的：解决无线环境下的**隐藏终端**问题

## 四、802.11 帧结构

- **管理帧**：Beacon、Probe Request/Response、Association Request/Response
- **控制帧**：RTS、CTS、ACK
- **数据帧**：承载上层 IP 数据

## 五、典型 WiFi 标准演进

| 标准 | 频段 | 核心技术 | 速率 |
|------|------|----------|------|
| 802.11b | 2.4GHz | DSSS | 11Mbps |
| 802.11g | 2.4GHz | OFDM | 54Mbps |
| 802.11n | 2.4/5GHz | MIMO | 600Mbps |
| 802.11ac | 5GHz | MU-MIMO | 3.5Gbps |
| 802.11ax | 2.4/5GHz | OFDMA | 9.6Gbps |
