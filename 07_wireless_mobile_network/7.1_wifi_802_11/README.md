# 7.1 — wifi 802 11

## 说明

本目录名强调 **802.11**；精读中 **§7.1 概述** 与 **§7.2 无线链路特征** 为 Wi‑Fi 的上下文，一并链到下方。

## 知识点速记

- **无线 vs 移动**；四大组件：主机、AP/基站、无线链路、骨干。  
- **SNR/BER、多径、隐藏终端**；无线难 CD → **CSMA/CA**。  
- **RTS/CTS**、四地址字段、**WPA3/SAE**。

## 与后端开发的联系

- 办公网漫游、弱网下的 API 超时与重试风暴；理解 **RSSI、信道、CCA** 有助于排障。
