# 7.2 — 4g 5g lte

## 知识点速记

- **EPC**：MME（控制）、S-GW / P-GW（用户面与外网）。  
- **5GC**：AMF / SMF / UPF 等对应演进。  
- **RLC**：分段、ARQ，无线段纠错。  
- **5G**：MIMO、毫米波、**网络切片**（eMBB / URLLC 等）。

## 与后端开发的联系

- 移动网络 NAT、专用 APN、边缘 UPF 与 MEC 对时延敏感业务的影响。
