# 3.2 — multiplexing demultiplexing

## 知识点速记

- **多路分解**：按首部字段把报文段交给正确套接字。
- **UDP**：常用模型为 **(目的 IP, 目的端口)** 二元组分发（与 TCP 不同）。
- **TCP**：**四元组**唯一标识连接；**监听套接字**与 **accept 得到的连接套接字**分离。

## 与后端开发的联系

- 同一机器多服务靠**不同端口**；连接风暴、端口耗尽、`TIME_WAIT` 占满本地端口，都与四元组与状态机相关。
