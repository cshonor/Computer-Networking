# 3.1 — transport service intro

## 知识点速记

- **进程到进程**：网络层到主机，运输层到**套接字/进程**。
- **Segment**：运输层 PDU；屏蔽核心网细节，提供逻辑端到端信道。
- **IP 不可靠**：TCP 在其上构建可靠、有序字节流（及流控、拥塞控制）。
- **TCP vs UDP**：重量级可靠 vs 轻量尽力而为。
- **TCP 六条主线**（握手/可靠/rwnd/cwnd/首部/场景）：[§3.1 TCP 完整版](../study.md#ch3-1-tcp-conn)

## 与后端开发的联系

- 选 **TCP/UDP/QUIC**、调 **连接池、超时、重试**，都建立在对运输层语义的理解上。
