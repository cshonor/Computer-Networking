# 3.1 运输层服务概述

> 章级精读：[../study.md#ch3-1](../study.md#ch3-1) · 首部结构：[第 1 章 TCP/UDP](../01_network_basics/1.5_protocol_layer_architecture/study.md#ch1-5-tcp-udp) · 分用细节：[3.2](../3.2_multiplexing_demultiplexing/study.md)

## 本节核心目标

建立运输层整体定位：**网络层管主机到主机，运输层管进程到进程**。

---

## 一、运输层的作用（必背）

**运输层 = 端到端、进程到进程的数据交付**

| 要点 | 说明 |
|------|------|
| 位置 | **应用层 ↔ 网络层之间**（五层模型第四层） |
| 升级 | 把 IP 的 **主机到主机** → **进程到进程** |
| 实现位置 | **只在端系统（主机）**；**路由器不处理**运输层首部 |

一句话：**网络层找主机，运输层找程序。**

---

## 二、复用与分用（必考）

![发送方复用、接收方分用：TCP/UDP → IP 数据报](../assets/transport_multiplexing_demultiplexing.png)

### 读图

| 侧 | 过程 | 图中标签 |
|----|------|----------|
| **发送** | 多应用 → **端口** → TCP/UDP **复用** → **IP 复用** → 一个 IP 数据报 | 发送方左侧 |
| **接收** | IP 数据报 → **IP 分用** → TCP/UDP **分用** → **端口** → 对应应用 | 接收方右侧 |

### 概念

**复用（Multiplexing）** — 发送端 **多进一**

- 多个应用进程的数据，经各自**端口**进入运输层  
- TCP 段、UDP 用户数据报再 **IP 复用** 成**一个** IP 数据报发出  
- 例：浏览器、微信、游戏**共用**同一网卡、同一源 IP  

**分用（Demultiplexing）** — 接收端 **一进多**

- 从网络层收到 IP 数据报 → 按 **协议号** 交给 TCP/UDP → 按 **端口号** 交给正确进程  
- 例：目的端口 **80** → 浏览器；**443** → HTTPS  

一句话：**发送多进一，接收一进多。**

→ 深化：[3.2 复用与分用](../3.2_multiplexing_demultiplexing/study.md)

## 三、端口号（必背）

**端口（Port）**：主机内区分应用进程的标识（**16 位**，0～65535）

- **Socket 地址** = **IP（主机）+ 端口（进程）**
- **四元组**唯一标识 TCP 连接：`{源IP, 源端口, 目的IP, 目的端口}`

| 端口 | 用途 |
|------|------|
| **80** | HTTP |
| **443** | HTTPS |
| **22** | SSH |
| **53** | DNS |
| **25** | SMTP |

一句话：**IP 找电脑，端口找程序。**

---

## 四、TCP 与 UDP（两类核心服务，必考）

| | **TCP** | **UDP** |
|--|---------|---------|
| 连接 | **面向连接**（三次握手） | **无连接** |
| 可靠 | **可靠**：确认、重传、按序 | **不可靠**：可能丢/乱序 |
| 控制 | **流量控制** + **拥塞控制** | 无 |
| 开销 | 大、延迟较高 | 小、**低延迟** |
| PDU | **段** Segment | **用户数据报** |
| 适用 | 网页、文件、邮件、数据库（**稳**） | 直播、视频会议、游戏、DNS（**快**） |

一句话：**TCP 稳而慢，UDP 快而险。**

→ 与 [2.1 选 TCP/UDP](../02_application_layer/2.1_network_application_principle/study.md#ch2-1-exam) 一致；机制见 [章级 §3.1 TCP/UDP](../study.md#ch3-1)

## 五、考试 / 面试速记

| 点 | 口诀 |
|----|------|
| 定位 | 网络层 **主机**，运输层 **进程** |
| 复用/分用 | 发 **多进一**，收 **一进多** |
| 地址 | **IP + 端口** = Socket |
| 协议 | **TCP 稳**，**UDP 快** |

### 易错

| 易混 | 纠正 |
|------|------|
| 路由器处理运输层？ | **否**；只在**端系统** |
| 端口在 IP 头里？ | 在 **TCP/UDP 首部** |
| TCP/UDP 都可靠？ | 只有 **TCP** 可靠 |

### 30 字终极版

**运输层进程到进程；IP找机端口找程序；复用多进一分用一进多；TCP稳UDP快。**

---

## 个人总结（直接背）

**网络层负责主机到主机，运输层负责程序到程序。**
