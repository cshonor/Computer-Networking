# 3.6 — tcp flow control

## 知识点速记

- **流量控制**：接收方通过 **`rwnd`** 告知剩余缓存，限制发送方**未确认数据**规模，防止撑爆接收端。
- **与拥塞控制区别**：`rwnd` 是**接收能力**；`cwnd` 是**网络承载**（见 `3.7` 与 [§3.6–3.7](../study.md#ch3-6)）。

## 与后端开发的联系

- 大文件上传、慢客户端：若发送无视 `rwnd`，会丢包或内核缓冲异常；零窗口探测（persist）等行为可结合抓包理解。
