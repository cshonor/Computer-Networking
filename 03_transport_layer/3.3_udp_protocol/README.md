# 3.3 — udp protocol

## 知识点速记

- **无连接、无状态**：低开销；适合 DNS、实时媒体等（应用自建可靠性）。
- **首部 8 字节**：源/目的端口、长度、检验和。
- **检验和**：IPv4 可选、IPv6 强制；差错多**丢弃**。
- **QUIC**：在 UDP 之上做用户态传输创新。

## 与后端开发的联系

- 日志、监控、游戏、RTC；以及 **HTTP/3** 网关与防火墙对 UDP 的策略。
