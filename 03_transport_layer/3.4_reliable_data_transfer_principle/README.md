# 3.4 — reliable data transfer principle

## 知识点速记

- **rdt**：ACK/NAK、序号、超时重传；2.2 常用仅 ACK。
- **停等利用率**：`U ≈ (L/R)/(RTT+L/R)`，高带宽时极低 → **流水线**。
- **GBN**：累计确认，可能大量重传；**SR**：单独确认、缓存乱序。
- **SR 窗口**：`W_s+W_r ≤ 2^k`；常取 **`W ≤ 2^(k-1)`** 防序号歧义。

## 与后端开发的联系

- 自定义协议、MQ、QUIC 内部逻辑，都复用「序号 + 窗口 + 重传」这套抽象。
