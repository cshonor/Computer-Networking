## 2.1 Python 解释器

### 核心知识点

Python 是**解释型语言**；解释器运行时**同一时间只执行一条语句**。

### 细节

| 项 | 说明 |
|----|------|
| **启动** | 终端键入 `python` → 标准解释器，提示符 `>>>` |
| **交互** | 在 `>>>` 后逐行输入、即时执行 |

### 关键逻辑

标准 `python` 可用，但**数据分析 / 科学计算**领域更常用 **IPython** 或 **Jupyter notebook** 等强化环境。

### 2.2.1 运行 IPython 命令行

| 项 | 说明 |
|----|------|
| **启动** | 终端输入 `ipython` |
| **提示符** | `In:` / `Out:` 带序号（区别于标准 `>>>`） |

| **跑脚本** | `%run script.py` — 同一进程内执行 `.py` 文件 |

**关键逻辑**：IPython 是加强版交互终端，支持任意代码块与完整脚本；也是 **Jupyter 开源项目的核心组件**。

### 2.2.3 Tab 补全

| 场景 | 用法 |
|------|------|
| **命名空间** | 输入表达式后按 **Tab** → 匹配变量、对象、函数，下拉展示 |
| **文件路径** | 字符串输入时 Tab 补全文件系统路径 |
| **关键字参数** | 函数调用时补全参数名（含 `=`） |
| **私有属性** | 默认**隐藏** `_` 开头的方法/魔术属性；需先键入 `_` 再 Tab |

**关键逻辑**：Tab 补全是交互式编程提效的核心习惯。

### 2.2.4 自省（Introspection）

| 用法 | 效果 |
|------|------|
| `obj?` | 显示对象常规信息（类型、字符串形式） |

## 2.3 Python 语法基础

Python 设计强调**可读、简洁、清晰**（常被称作「可执行的伪代码」）。

---

<a id="ch02-3-1"></a>

### 2.3.1 语法的语义

#### 代码结构

| 规则 | 说明 |
|------|------|
| **缩进** | 空白字符（Tab / 空格）组织代码块，**不用大括号**；推荐 **4 空格** |
| **分号** | 语句末尾**不必**分号；同一行多条语句可用 `;`（不推荐） |

#### 变量与引用（数据分析必懂）

| 概念 | 说明 |
|------|------|
| **绑定** | 赋值是变量**绑定到对象**，不是复制数据 |
| **共享引用** | `b = a` → 两变量引用**同一内存对象** |
| **传参** | 函数参数传递的是**引用** |
| **动态引用** | 变量无固有类型；对象自带类型信息 |
| **强类型** | **无随意隐式转换**（如 `str + int` 报错） |
| **鸭子类型** | 少关心具体类型，关心是否有所需方法（如 `iter(obj)` 判可迭代） |

#### 导入、比较、可变性

| 主题 | 要点 |
|------|------|
| **import** | `import module` · `from module import xx` · `as` 重命名 |
| **身份比较** | `is` / `is not` 判是否**同一对象**；判 `None` 用 `is None` |
| **可变** | **list、dict、NumPy 数组** |
| **不可变** | **str、tuple** |
| **修改副作用** | 可变≠必须改；随意 in-place 修改常带来副作用 |

**关键逻辑**：理解**何时、为何、如何复制数据**对处理大数据集极其重要；误解引用会导致**原始数据被意外修改**。

### 2.3.2 标量类型

Python 内置**单值**标量类型：

| 类型 | 说明 |
|------|------|
| **`None`** | Python 的 null；**全局唯一实例** → 用 `is None` |
| **`str`** | 字符串，不可变 |
| **`bytes`** | 字节串 |
| **`int`** | 任意精度整数 |
| **`float`** | 双精度 **64 bit** |
| **`bool`** | 布尔 |

#### 数值运算

| 运算符 | 含义 |
|--------|------|
| `/` | 真除法，**结果恒为 float** |
| `//` | C 风格整除，**丢弃小数** |

#### 日期与时间（`datetime` 模块）

| API | 用途 |
|-----|------|
| `strftime` | 时间 → 格式化字符串 |
| `strptime` | 字符串 → 时间对象 |
| `timedelta` | 时间偏移 / 时间差 |

### 2.3.3 控制流

#### 条件

- `if` / `elif` / `else`
- `and` / `or`：**短路**求值（结果确定后不再算后续）
- **链式比较**：`4 > 3 > 2 > 1` 合法

#### 循环

| 结构 | 要点 |
|------|------|
| **`for`** | 迭代集合 / 迭代器；`continue` 跳过本次 · `break` 跳出最内层 |
| **拆包** | `for a, b, c in iterator:` 直接解包序列元素 |
| **`while`** | 条件为 True 持续执行，直到 False 或 `break` |
| **`pass`** | 占位，满足缩进语法、暂不实现 |

#### `range`

```python
range(start, stop, step)  # stop 不包含；step 可为负
```

- 内存占用极小，常用于**索引迭代**与生成大整数序列

**关键逻辑**：熟练 **`for` + `range`** 是 Python 基本功，尤其在需要索引或大序列场景。

## 高频考点速记卡

```text
┌────────────── 环境与工具 ──────────────┐
│ python → >>> ；数据分析用 ipython / jupyter │
│ IPython：In/Out 提示符、%run、? 自省、Tab 补全 │
│ Jupyter：.ipynb；关标签≠关进程 → Close and Halt │
└────────────────────────────────────────┘

┌────────────── 语法核心 ────────────────┐
│ 赋值=绑定引用；b=a 共享对象；传参也是引用 │
│ 强类型+动态引用；is None 判空           │
│ 可变：list/dict/ndarray；不可变：str/tuple │
│ / 真除法得 float；// 整除丢小数          │
└────────────────────────────────────────┘
```

| 易混 | 纠正 |
|------|------|
| `b = a` 是复制？ | **否**；共享**同一对象**引用 |
| 关 Jupyter 标签 = 关 Python？ | **否**；需 **Close and Halt** |
| `is` vs `==` | `is` 判**同一对象**；`==` 判**值相等** |
| `/` vs `//` | `/` 浮点结果；`//` **整除** |
| `range(5)` 含 5？ | **不含**终点值 |
