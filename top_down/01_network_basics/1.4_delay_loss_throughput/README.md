# 1.4 — delay loss throughput

## 知识点速记

- **总时延**：`d_proc + d_queue + d_trans + d_prop`；常简化 `≈ L/R + d/s`
- **排队**：**La/R**；I→1 时延爆炸；I≥1 丢包；**卡顿主因**
- **传输 vs 传播**：L/R（带宽、包长）vs d/s（距离）；升级带宽只主要降前者
- **丢包**：缓冲区满；TCP 重传拉低有效吞吐
- **吞吐量**：`min{Rᵢ}` 瓶颈链路（木桶）

## 与后端开发的联系

- 排障会估：**RTT、带宽、队列、丢包** 如何影响接口耗时与重传；接入网常为瓶颈
