# 1.1 — internet overview

## 知识点速记

- **双视角**：具体构成（主机、链路、分组交换机）vs 服务（为分布式应用提供通信能力）。
- **基础设施之上的基础设施**：不止物理连接，更是通用服务框架。
- **Socket**：应用与运输层之间的接口；类比「邮政规则」——格式与地址不对，交付失败。
- **协议**：报文格式、顺序、事件与动作的规范；**对等端须语义兼容**，否则通信失败。

## 与后端开发的联系

- 写任何网络程序前先想清楚：**对端协议栈是否一致**（HTTP 版本、TLS、序列化格式等）。
- **Socket** 是后端接触因特网服务的入口；后续第 2、3 章会反复用到。
