# 6.2 差错检测与纠正

> 章级精读：[§6.2](../study.md#ch6-2) · **速记对比**：[#ch6-2-compare](#ch6-2-compare) · [易错点](#ch6-2-exam) · CRC 例题：[#ch6-2-crc-example](#ch6-2-crc-example)

## 本节核心目标

掌握**奇偶校验、校验和、CRC、FEC** 的原理与检错/纠错能力；能区分**典型层次**（链路层 CRC vs IP/TCP 校验和）；记住考试易错点。

---

<a id="ch6-2-simple"></a>

## 〇、一句话总览

> **检错**：奇偶（最弱）→ 校验和（IP/TCP/UDP 头）→ **CRC（链路层最强）**；**纠错**：FEC（无线）。  
> **CRC 只检错不纠错**；能纠错的是 **FEC**（汉明、LDPC 等）。

| 技术 | 纠错？ | 典型层/协议 |
|------|--------|-------------|
| 奇偶校验 | ❌ | 串口、简单链路 |
| 校验和 | ❌ | **IP / TCP / UDP 头部** |
| **CRC** | ❌ | **以太网 FCS、PPP、WiFi** |
| **FEC** | ✅ | WiFi、4G/5G、ECC 内存 |

---

## 一、传输差错的来源

- 噪声、信号衰减、干扰 → **比特翻转**
- 常见：**单比特错**、**突发多比特错**（连续多位）

---

## 二、常用差错检测技术

<a id="ch6-2-parity"></a>

### 1. 奇偶校验（Parity Check）

| 项 | 说明 |
|----|------|
| **原理** | 数据后加 **1 位校验位**，使整体「1」的个数为**奇数（奇校验）**或**偶数（偶校验）** |
| **例子** | 数据 `10110001`（4 个 1）→ 奇校验位 **1**（共 5 个 1）；偶校验位 **0**（共 4 个 1） |
| **检错** | **只能检奇数个比特错**；**偶数个错完全检不出** |
| **纠错** | **不能** |
| **优点** | 极简单，开销 **1 位** |
| **缺点** | 漏检率高 |
| **应用** | RS-232 串口、简单嵌入式、早期内存 |

---

<a id="ch6-2-checksum"></a>

### 2. 校验和（Checksum，因特网校验和）

| 项 | 说明 |
|----|------|
| **原理** | ① 数据分成 **16/32 位**小段；② **反码求和**；③ 和取反 → **校验和**附在头部 |
| **接收** | 数据 + 校验和再求和 → 结果为 **全 1（模 2¹⁶）** → 认为无错 |
| **应用** | **IP、TCP、UDP 头部校验**（**只校验头部**，不校验载荷数据） |
| **纠错** | **不能** |
| **缺点** | 漏检率**高于 CRC**；不能检所有多比特错（对称翻转可能抵消） |

→ IP 首部：[4.3 IPv4](../../04_network_layer_data_plane/4.3_ipv4_ipv6_nat/study.md) · TCP/UDP：[第 3 章](../../03_transport_layer/study.md)

---

<a id="ch6-2-crc"></a>

### 3. 循环冗余校验 CRC（Cyclic Redundancy Check）

**原理（多项式 + 模 2 除法）**

1. 约定**生成多项式 G(x)**（如 CRC-32，33 位）  
2. 发送：数据后补 **r 个 0**（r = G 的最高次幂）→ 用 G(x) **模 2 除** → **余数 r 位**作 CRC，替换补的 0  
3. 接收：用 G(x) 除 **数据+CRC** → **余数 = 0** 无错；否则有错  

**检错能力（很强）**

- 所有**单比特、双比特**错  
- 所有**奇数个比特**错  
- 大部分**突发错**（长度 ≤ r 位）  

| 项 | 说明 |
|----|------|
| **纠错** | **不能**（只检错） |
| **优点** | 漏检率极低；**硬件高效**（移位寄存器） |
| **应用** | **以太网 FCS、PPP、WiFi、USB、ZIP/PNG** |

→ 以太网 FCS：[6.4](../6.4_ethernet_arp_switch_vlan/study.md) · 章级推导：[§6.2.2 CRC 例题](../study.md#ch6-2)

<a id="ch6-2-crc-example"></a>

#### CRC 极简手算例题

数据 **D = 101110**，生成多项式 **G = 1001**（阶 **r = 3**）：

```text
1. D 后补 3 个 0：101110000
2. 模 2 除 G=1001 → 余数 R = 011
3. 发送：101110011
4. 接收方用 G 整除「数据+011」，余数 0 → 通过
```

## 三、差错纠正（FEC，前向纠错）

<a id="ch6-2-fec"></a>

| 项 | 说明 |
|----|------|
| **思想** | 发方加**冗余** → 收方**直接纠正**少量错，**无需重传** |
| **特点** | **能纠错**；冗余更高、计算更复杂 |
| **适用** | **高误码、长延迟、难重传**的链路（**无线**） |
| **常用** | **汉明码**（纠 1 位、检 2 位，ECC 内存）；**卷积码、Turbo、LDPC**（WiFi、4G/5G、卫星） |

**和 CRC 区别**：CRC **只检错**；FEC **能纠错**，开销更大。

→ 无线链路：[7.1 WiFi](../../07_wireless_mobile_network/7.1_wifi_802_11/study.md)

<a id="ch6-2-exam"></a>

## 四、易错点（考试必背）

1. **奇偶校验**：只查**奇数个错**；**偶数个查不出**；**无纠错**。  
2. **校验和**：IP/TCP/UDP **只校验头部**；漏检率 **> CRC**。  
3. **CRC**：**检错最强、硬件最快**；以太网/链路层标配；**不能纠错**。  
4. **FEC**：**能纠错**；无线常用；**开销大**。  
5. **层次区分**（常考）：

| 技术 | 典型层次 |
|------|----------|
| 奇偶校验 | 物理层 / 简单链路 |
| **CRC** | **数据链路层**（以太网、PPP、WiFi 帧） |
| **校验和** | **网络层 / 传输层**（IP、TCP、UDP 头） |
| **FEC** | 物理层 / **无线链路** |

6. **两层独立**：TCP/UDP **校验和** 与链路层 **CRC** 各检各的，**互不替代**。

<a id="ch6-2-compare"></a>

## 五、快速对比表（好记）

| 技术 | 检错能力 | 纠错？ | 开销 | 典型位置 |
|------|----------|--------|------|----------|
| 奇偶校验 | 奇数个错 | ❌ | 最低（1 位） | 串口、简单链路 |
| 校验和 | 一般（易漏检） | ❌ | 低 | **IP/TCP/UDP 头部** |
| **CRC** | **极强**（单/双/突发） | ❌ | 中 | **以太网、PPP、WiFi** |
| FEC（汉明/LDPC） | 强 | ✅ | 高 | 无线、4G/5G、ECC |

### 30 字

**奇偶检奇数个错；校验和检 IP/TCP 头；CRC 链路最强只检错；FEC 无线能纠错。**

### 口诀

```text
奇偶：1位、奇数个错、偶数个漏
校验和：16位反码和、IP/TCP/UDP头、漏检比CRC高
CRC：模2除、以太网FCS、检错强不纠错
FEC：加冗余直接纠、无线4G5G、开销大
层次：CRC在二层、校验和三四层、FEC在无线
```
