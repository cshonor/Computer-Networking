# 6.2 — error detection correction

## 知识点速记

- **奇偶 / 二维奇偶**：检错/纠错能力有限。  
- **检验和**：TCP/UDP；软件友好。  
- **CRC**：链路硬件首选；模 2 除生成冗余位；强突发检错。
