# 7.3 移动性管理

> 章级精读：[§7.5–7.8](../study.md#ch7-5)

## 一、移动性管理的核心问题

当主机在不同网络/基站之间移动时，如何保证通信不中断，IP 地址不变，上层业务无感知？

## 二、移动 IP（Mobile IP）基本原理

- 核心角色：移动节点、家乡代理、外部代理
- 核心概念：
  - **家乡地址**：移动节点的永久 IP 地址，上层应用可见
  - **转交地址**：移动节点在外部网络获得的临时 IP 地址
- 工作流程：
  1. 移动节点向家乡代理注册转交地址
  2. 通信对端发送的数据先到达家乡代理
  3. 家乡代理将数据封装转发到移动节点的转交地址
  4. 移动节点直接回复数据给通信对端

## 三、蜂窝网络中的移动性管理

### 1. 位置管理

- **位置更新**：移动节点定期向网络更新自己的位置信息
- **寻呼**：网络根据位置信息，向移动节点发送寻呼消息，建立通信

### 2. 切换管理

- **硬切换**：先断开与原基站的连接，再连接新基站（传统 2G/3G）
- **软切换**：同时连接多个基站，数据合并接收，无中断（CDMA）
- **无缝切换**：5G/4G 中通过快速重定向、多连接技术，降低切换时延

## 四、WiFi 中的移动性管理

- **802.11r** 快速漫游：减少 AP 切换时的认证时间，降低漫游时延
- **802.11k** 邻居发现：让客户端提前获取周边 AP 信息，优化漫游决策
