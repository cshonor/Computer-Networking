# 第7章 无线网络和移动网络：从链路特征到全球漫游架构

无线与移动已从「边缘补充」发展为**全球互联的核心形态**。物理层的**路径损耗、衰落、干扰与多径**使链路误码与速率剧烈波动，对 **TCP** 等假设「丢包≈拥塞」的协议构成系统性挑战。本章从链路特征到 **802.11**、**蜂窝网**、**移动性管理** 及对高层的影响，串起无线架构逻辑。

## 7.1 无线网络与移动网络概述（Overview）

### 无线 vs 移动

- **无线（Wireless）**：强调**物理媒介**为电磁波传播。  
- **移动（Mobility）**：强调端系统在**切换接入点 / 子网**时，如何保持**会话连续性**（IP、TCP 状态等）。

### 无线网络核心组件

1. **无线主机**：手机、IoT、笔记本等。  
2. **基站 / AP**：基础设施模式下的边缘锚点，连接无线与有线骨干。  
3. **无线链路**：受频段、信道、干扰与移动性影响。  
4. **网络基础设施**：连接基站的有线核心与因特网。

### 有线 vs 无线（对比直觉）

| 维度 | 有线（如以太网） | 无线（如 802.11） |
|------|------------------|-------------------|
| 衰减 | 线缆约束，相对稳定 | 随距离与遮挡变化大 |
| 干扰 | 主要为 EMI 等 | 同频、邻频、雷达、家电等多源 |
| 多径 | 通常可忽略 | 反射导致符号间干扰，需均衡等 |
| 链路可靠性 | BER 通常极低 | BER 波动大 |

**So What?** 基础设施模式下，**基站/AP** 不仅是比特中继，还承担功率控制、调度、同步等；**自组网（Ad hoc）** 缺乏集中协调，协议复杂度显著上升。

## 7.2 无线链路和网络特征（Wireless Links and Network Characteristics）

无线链路**低可靠、强时变**，链路层常需 **ARQ / FEC** 等尽量在本地修复误码。

### 物理层相关概念

- **SNR 与 BER**：高 SNR 可用更高阶调制提高吞吐；低 SNR 需降阶，速率回退。  
- **多径（Multipath）**：多副本不同时到达，造成符号失真，需信道估计与均衡。  
- **隐藏终端（Hidden Terminal）**：A 与 C 对 AP 可达但彼此侦听不到，**载波侦听不可靠**。

### 为何无线难以做「碰撞检测（CD）」？

发送时本机发射功率远高于接收到的潜在碰撞能量，**难以在同一射频前端同时可靠侦听冲突**，因此 802.11 等从 **CSMA/CD** 思路转向 **CSMA/CA（冲突避免）**。

**So What?** 高密度 Wi‑Fi / 5G 部署中，**链路层重传与调度**直接影响上层 **QoE**。

## 7.3 WiFi：802.11 无线局域网

802.11 族围绕 **BSS（基本服务集）** 组织；演进至 **Wi‑Fi 6/7** 等在 OFDMA、MU-MIMO 等方向增强（依版本）。

### MAC：CSMA/CA 与 RTS/CTS

- **退避**：侦听信道忙后进入**随机退避**，降低碰撞概率。  
- **RTS/CTS**：发送 **RTS**，AP 回 **CTS**，在范围内站点获知**信道预约**，缓解隐藏终端；对小包可能不划算，长帧更有价值。

### 802.11 帧地址（四地址字段）

1. **Addr1**：接收方（本跳无线接收端）。  
2. **Addr2**：发送方（本跳无线发送端）。  
3. **Addr3**：**BSS 与分布式系统桥接**关键字段，常承载与以太网侧转发相关的 **LAN 目的/源 MAC**（教材图示多为 AP 与路由器之间以太网段的 MAC 语义），使 802.11 与 802.3 互通。  
4. **Addr4**：多用于 **WDS / 自组网** 等 AP 间中继场景；基础设施 STA↔AP 常见为空。

### 安全：WPA3

相对 WPA2，**WPA3** 引入 **SAE** 等，增强弱口令场景下的认证强度与**前向安全**等目标（具体威胁模型与实现细节见标准与厂商说明）。

**So What?** 802.11 在非授权频谱上通过 **MAC 设计 + 功率/信道管理** 追求「尽量确定」；**Addr3** 使 Wi‑Fi 能无缝桥接以太网生态。

## 7.4 蜂窝网络：4G 与 5G（Cellular Networks）

蜂窝网从语音中心演进为**全 IP 数据**架构。

### 4G LTE 核心网（EPC）实体（教学名）

- **MME**：控制面；鉴权、移动性管理、会话建立信令等。  
- **S-GW**：用户面锚点之一；跨 eNB 切换等场景的数据转发。  
- **P-GW**：与外部 PDN（如因特网）连接；IP 分配、策略与计费接口等。

> **5G 核心网（5GC）** 中角色分拆为 **AMF / SMF / UPF** 等，职责与 EPC 有对应关系但接口与状态模型不同；精读以教材 LTE 叙述为主，对比时记住「**用户面下沉、控制面服务化**」即可。

### RLC 层

LTE/5G 在接入网协议栈中设有 **RLC**：分段/重组、**ARQ** 等，在无线段尽量修复差错，减轻 TCP 对无线随机丢包的误判压力（仍非万能）。

### 5G：MIMO、毫米波与网络切片

**Massive MIMO、毫米波（覆盖与穿透受限）** 等提升容量与峰值。**网络切片**在同一物理基础设施上为 **eMBB / URLLC** 等提供隔离的 QoS 与资源视图（依赖核心网与 RAN 的协同实现）。

## 7.5 移动性管理原理（Mobility Management Principles）

网络层移动性目标之一：在子网变化时尽量保持**对上层可见的 IP 连续性**（或透明代理/隧道实现等价效果）。

### 移动 IP 直觉（教材模型）

- **归属网络 / 归属代理（HA）**：维护设备「家」位置与转发。  
- **外地网络 / 外地代理（FA）** 与 **转交地址（COA）**：漫游到访问网络获得的转交点。

### 间接路由 vs 直接路由

| 维度 | 间接路由 | 直接路由 |
|------|----------|----------|
| 模式 | 通信方先发 HA，再隧道到 COA | 查询 COA 后尽量直达移动主机 |
| 路径 | 易出现 **三角路由**（绕经归属点） | 路径更优，但需额外信令与对端支持 |
| 透明性 | 对通信方较透明 | 通信方需参与位置解析等 |

**三角路由**：即使通信方与移动节点地理上很近，分组仍可能先回**归属代理**再折返，增加时延与骨干负载。

## 7.6 实践中的移动性管理（Mobility Management in Practice）

蜂窝 **切换（Handoff）** 典型步骤（LTE 语境，5G NR 类似但接口名演进）：

1. **测量与判决**：UE 测量邻区，信号优于阈值则触发。  
2. **基站协作**：LTE 常用 **X2** 在源/目标 eNB 间交换上下文；5G NR 多用 **Xn**（概念延续）。  
3. **路径更新**：核心网用户面锚点（如 S-GW / UPF）更新下行路径；源侧缓存分组转发给目标，力求**少丢、少乱序**。

**工程权衡**：切换阈值过易 → **乒乓**；过晚 → 链路质量差、掉话/掉线风险上升。

<a id="ch7-7"></a>

## 7.7 无线和移动性对高层协议的影响

### TCP 在无线下的「误判」

经典 TCP 常把**丢包**当作**拥塞信号**；无线链路随机丢包时，**cwnd** 可能被不必要地削减，**吞吐塌陷**而带宽仍空闲。

### 架构缓解思路

1. **链路层重传**：802.11 ACK、蜂窝 **RLC** 等，在到达 TCP 前吃掉大量无线丢包。  
2. **分段 TCP / 代理**：在基站或 PE 侧终结 TCP，分别优化有线段与无线段（引入语义与信任边界，需审慎）。  
3. **应用层自适应**：流媒体等通过**缓冲与码率自适应**吸收切换抖动。

## 总结

无线协议设计在**灵活性、可靠性与效率**间持续权衡：从 **802.11 的 CSMA/CA** 到 **5G 切片与 RLC**，核心目标都是在开放物理媒介上构建**尽可能稳健的比特管道**，支撑全球范围的移动数字化业务。
