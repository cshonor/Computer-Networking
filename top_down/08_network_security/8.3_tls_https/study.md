# 8.3 TLS 与 HTTPS

> 章级精读：[§8.5 邮件安全](../study.md#ch8-5) · [§8.6 TLS](../study.md#ch8-6)

## 一、TLS/SSL 定位

- 位于应用层与运输层之间，为应用层协议提供安全传输服务
- 典型应用：**HTTPS**（HTTP over TLS）、SMTP over TLS 等
- 版本演进：SSL 1.0/2.0/3.0 → TLS 1.0/1.1/1.2/**1.3**（主流 TLS 1.2/1.3）

## 二、TLS 核心目标

1. 机密性：传输数据被加密，第三方无法窃听
2. 完整性：数据在传输中未被篡改
3. 身份认证：客户端验证服务器身份，防止中间人攻击

## 三、TLS 协议结构

- **记录协议**（Record Protocol）：对上层数据进行分段、压缩、加密、校验
- **握手协议**（Handshake Protocol）：协商加密套件、交换密钥、验证服务器身份

## 四、TLS 握手流程（简化版）

1. 客户端发送 Client Hello，支持的 TLS 版本、加密套件、随机数
2. 服务器回复 Server Hello，选定 TLS 版本、加密套件、随机数，并发送服务器证书
3. 客户端验证服务器证书的合法性
4. 客户端生成预主密钥，用服务器公钥加密后发送给服务器
5. 双方使用预主密钥和随机数，计算会话密钥
6. 后续通信使用会话密钥进行对称加密

## 五、HTTPS 工作原理

- HTTP 协议数据被封装在 TLS 层中传输，端口号 **443**
- 客户端与服务器建立 TCP 连接后，先完成 TLS 握手，再传输 HTTP 数据
- 优势：防止数据窃听、篡改和钓鱼网站伪装

## 六、本节核心考点

- TLS 握手过程的关键步骤
- HTTPS 与 HTTP 的核心区别
- 服务器证书在 TLS 中的作用
