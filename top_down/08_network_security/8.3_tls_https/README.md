# 8.3 — tls https

## 说明

目录名强调 **TLS/HTTPS**；精读中 **§8.5 安全电子邮件** 为同类「报文层安全」铺垫，建议先略读再深入 TLS。

## 知识点速记

- **PGP/S-MIME**：端到端邮件加密与签名。  
- **TLS 1.3**：(EC)DHE、证书、HKDF、AEAD；**0-RTT** 与重放权衡。  
- **1.2 vs 1.3 密钥**：分立 MAC/加密 vs **AEAD 统一** 的教学对照。

## 与后端开发的联系

- 强制 HTTPS、HSTS、mTLS、证书透明度（CT）、ALPN 与 HTTP/2/3。
