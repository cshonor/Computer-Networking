# 8.4 IPsec 与 VPN

> 章级精读：[§8.7 IPsec/VPN](../study.md#ch8-7)

## 一、IPsec 定位

- 工作在**网络层**，为 IP 数据报提供安全保护
- 典型应用：**VPN**（虚拟专用网络），实现跨公网的安全通信
- 标准协议，厂商互通性好

## 二、IPsec 两大核心协议

### 1. AH 认证头（Authentication Header）

- 提供数据完整性和身份认证
- **不提供加密**，无法防止数据窃听
- 已逐渐被 ESP 取代

### 2. ESP 封装安全载荷（Encapsulating Security Payload）

- 同时提供加密、完整性、身份认证
- 主流协议，支持多种加密算法（AES、3DES）和认证算法（HMAC-SHA256）

## 三、IPsec 两种工作模式

### 1. 传输模式（Transport Mode）

- 仅加密 IP **数据部分**，IP 头部明文传输
- 适用场景：主机到主机的端到端安全通信

### 2. 隧道模式（Tunnel Mode）

- 加密整个 IP 数据报（包括头部），新增一个 IP 头部
- 适用场景：站点到站点的 VPN 连接（如企业分支互联），隐藏真实 IP 地址

## 四、IPsec VPN 工作流程

1. **IKEv1/IKEv2** 协商阶段：双方协商加密算法、认证算法，交换密钥材料，建立 SA（安全联盟）
2. **IPsec SA** 建立阶段：协商 ESP/AH 的 SA 参数
3. **数据传输阶段**：使用协商好的 SA 参数对 IP 数据进行加密/认证传输

## 五、其他常见 VPN 技术

- **SSL VPN**：基于 TLS 协议，用户通过浏览器即可接入，适合远程办公
- **MPLS VPN**：运营商级 VPN，基于 MPLS 标签转发，适合企业专线互联

## 六、本节核心考点

- AH 与 ESP 的区别与适用场景
- 传输模式 vs 隧道模式 的差异与应用场景
