# 8.5 — firewall ids

## 说明

目录名侧重**防火墙/IDS**；精读 **§8.8 无线与蜂窝安全** 与 **§8.9 运行安全**、章末总结一并列于下方。

## 知识点速记

- **WPA3 / SAE**；蜂窝 **AKA** 与双向鉴别直觉。  
- **SSID 隐藏 ≠ 安全**；用强认证与加密。  
- **状态防火墙**、**DPI**、**IDS/IPS**（签名 vs 异常）。

## 与后端开发的联系

- WAF、云安全组、eBPF 观测、SOC 告警与业务误报治理。
