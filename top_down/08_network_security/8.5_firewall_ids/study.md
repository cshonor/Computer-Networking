# 8.5 防火墙与 IDS/IPS

> 章级精读：[§8.8 无线/蜂窝安全](../study.md#ch8-8) · [§8.9 防火墙/IDS](../study.md#ch8-9) · [总结](../study.md#ch8-10)

## 一、防火墙（Firewall）

- 核心作用：位于网络边界，控制内外网之间的访问流量，隔离非法访问
- 分类：
  1. **包过滤防火墙**（网络层）：基于 IP 地址、端口号、协议类型过滤数据包，如 iptables
  2. **状态检测防火墙**：跟踪 TCP/UDP 会话状态，只允许合法会话的流量通过，主流技术
  3. **应用层网关**（代理防火墙）：对应用层协议进行解析和过滤，控制粒度更细
- 典型部署：企业网出口、数据中心边界

## 二、IDS 入侵检测系统（Intrusion Detection System）

- 核心作用：监控网络/主机流量，发现可疑攻击行为并告警
- 分类：
  1. **网络型 IDS（NIDS）**：部署在网络关键节点，监控全网流量
  2. **主机型 IDS（HIDS）**：部署在服务器上，监控主机行为
- 工作模式：
  - **误用检测**：基于攻击特征库匹配已知攻击
  - **异常检测**：基于正常行为模型，发现偏离正常模式的行为

## 三、IPS 入侵防御系统（Intrusion Prevention System）

- 与 IDS 的区别：IDS 仅告警，**IPS 可主动阻断**攻击流量
- 核心作用：实时检测并阻断入侵行为，防止攻击成功实施
- 典型部署：串联在网络流量路径中，如数据中心核心交换机旁

## 四、防火墙 vs IDS/IPS

| 设备 | 核心能力 | 部署方式 | 缺点 |
|------|----------|----------|------|
| 防火墙 | 访问控制，基于五元组过滤 | 串联在网络边界 | 无法识别应用层攻击 |
| IDS | 攻击检测，告警 | 旁路部署 | 无法阻断攻击，存在告警风暴 |
| IPS | 攻击检测 + 阻断 | 串联部署 | 误封合法流量会影响业务 |
