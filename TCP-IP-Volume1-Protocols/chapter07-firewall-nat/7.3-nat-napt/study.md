# 7.3 网络地址转换 (NAT)

> 章级精读：[../study.md#ch07-3](../study.md#ch07-3) · 精读：[04 §4.3 NAT](../../../04_network_layer_data_plane/4.3_ipv4_ipv6_nat/study.md#ch4-3-nat)

## 本节核心目标

掌握 **基本 NAT**、**NAPT**、**Hairpin**、**ALG** 与 **EIM/ADF** 类型（P2P 必考）。

---

## 基本 NAT vs NAPT

| 类型 | 行为 |
|------|------|
| **基本 NAT** | 私网 IP ↔ 公网 IP（一对一或池） |
| **NAPT（最常见）** | 多内网主机共享**一个公网 IP**，靠 **端口映射** 区分 |

---

## Hairpin / NAT 环回

- 内网主机用**公网 IP** 访问**同网段**另一内网服务 → 需路由器**发夹转发**支持。

---

## ALG（应用层网关）

- 载荷里嵌**内网 IP**（如 **FTP PORT**）→ NAT 设备改写为公网地址。
- 与现代加密协议（TLS）冲突 → 催生 **被动 FTP / 专用穿透**。

---

## NAT 映射类型（P2P）

| 类型 | P2P 友好度 |
|------|------------|
| **端点独立 (EIM)** | 较易打洞 |
| **地址相关 (ADF)** | 较难；对称型 NAT 常需 **TURN** |

→ 详见 [7.4 NAT 穿越](7.7-nat-traversal/study.md)
