# 7.5 配置包过滤防火墙和 NAT

> 章级精读：[../study.md#ch07-5](../study.md#ch07-5)

## 本节核心目标

理解 **ACL 匹配顺序** 与 **UPnP / NAT-PMP / PCP** 动态映射。

---

## ACL 逻辑

- 规则表通常 **自上而下**，**首个命中即生效**（First Match）。
- 设计时把**更具体**规则放前，默认 **deny** 收尾。
- 典型顺序：**黑名单 → 拒外网 SYN → 允许 80/443 → 默认 DROP** → [7.2 §规则顺序](7.2-packet-filter-firewall.md#ch07-2-rules-order)

---

## 动态端口映射（“Open NAT”）

| 协议 | 用途 |
|------|------|
| **UPnP IGD** | 应用请求路由器映射入站端口 |
| **NAT-PMP / PCP** | 更现代的端口控制协议 |

- 游戏、BT、部分 VoIP 依赖此机制；企业网常**禁用**以降低风险。
