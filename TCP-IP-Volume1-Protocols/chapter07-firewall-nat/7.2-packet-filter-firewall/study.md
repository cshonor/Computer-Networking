# 7.2 防火墙

> 章级精读：[../study.md#ch07-2](../study.md#ch07-2) · 有状态：[#ch07-2-state](../study.md#ch07-2) · 自顶向下：[§8.5](../../08_network_security/8.5_firewall_ids/study.md)

## 本节核心目标

区分 **包过滤** 与 **应用代理**，理解**有状态检查**。

---

## 包过滤（无状态 / 有状态）

| 类型 | 工作层 | 依据 |
|------|--------|------|
| 无状态 | L3/L4 | IP、端口、协议、ACL |
| **有状态** | L3/L4 + **连接表** | 首包建状态，**回程自动放行** |

- 示例：`iptables`/`nftables`、商用防火墙策略。

---

## 代理防火墙（应用层）

- 客户端只连**代理**，代理再连目标 → **无底层直连**。
- 可深度解析 HTTP 等；**安全高、延迟与成本高**。

---

## 易混

- 有状态防火墙看的是**五元组会话**，不是单包孤立判决。
