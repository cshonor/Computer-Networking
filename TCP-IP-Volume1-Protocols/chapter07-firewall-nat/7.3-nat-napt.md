## NAT 基础五要点（速记）

| # | 要点 |
|---|------|
| 1 | **作用**：私网复用公网 IP，**隐藏内网**、缓解 IPv4 地址枯竭 |
| 2 | **本质**：改写 **IP 首部**（源/目的 IP）+ 维护**状态映射表** |
| 3 | **对象**：**基本 NAT** 只改 **IP**（一对一/多对多）；**NAPT** 改 **IP+端口**（多对一，最常见） |
| 4 | **位置**：部署在网络**边界网关**（路由器/防火墙）；**数据平面**改写包，**控制平面**维护表项 |
| 5 | **状态**：内网**五元组** ↔ 公网**五元组**；**老化超时**释放映射 |

→ 出站/入站分步：[04 §4.3 工作过程](../../../top_down/04_network_layer_data_plane/4.3_ipv4_ipv6_nat.md#ch4-3-nat-flow)

**通俗**：NAT = 前台总机 — 外面只看到一个公网号码，内网很多分机靠**端口/映射表**区分。

<a id="ch07-3-napt-compare"></a>

## 基本 NAT vs NAPT（必背）

| 类型 | 行为 | 映射关系 | 公网 IP 利用率 |
|------|------|----------|----------------|
| **基本 NAT**（No-PAT） | 只转换 **IP**，**不改端口** | 一对一 / 多对多（公网 IP 池） | **低** — 一会话占一公网 IP |
| **NAPT**（PAT / 重载 NAT） | 同时转换 **IP + 端口** | **多对一**（最常见） | **极高** — 一公网 IP 承载数千会话 |

| 场景 | 常用类型 |
|------|----------|
| 家庭 / 公司上网 | **NAPT** |
| 内网服务器对外提供服务 | **静态 NAT** / **端口映射**（静态 PAT） |

→ 与防火墙关系：NAT 常集成在同一边界盒 → [7.2](7.2-packet-filter-firewall.md)

<a id="ch07-3-hairpin"></a>

## Hairpin / NAT 环回（发夹）

| 项 | 说明 |
|----|------|
| **场景** | **内网主机用公网 IP** 访问**同网段**另一内网服务（或访问映射到本机的公网 IP） |
| **问题** | 普通 NAT 回包源 IP 不匹配 → **连接失败** |
| **原理** | 网关同时做 **DNAT**（目的转内网 IP）+ **SNAT**（源转网关 IP），流量「**发夹式**」转回内网 |
| **用途** | 内外网**统一用公网域名/IP** 访问服务 |

```text
内网 A ──(目的=公网IP)──► NAT 网关 ── DNAT+SNAT ──► 内网 B
                              └── 发夹，不真正出公网
```

→ [study §7.3.4 Hairpinning](./study.md#ch07-3)

<a id="ch07-3-alg"></a>

## ALG（应用层网关）

| 项 | 说明 |
|----|------|
| **背景** | NAT **只改 IP 头**；**FTP/SIP/RTSP** 等协议**载荷里嵌内网 IP/端口** → 对端仍连私网地址 → 失败 |
| **作用** | **解析应用层载荷**，把里面的私网 IP/端口改成**公网 IP/端口** |
| **典型** | **FTP 主动模式**（PORT 命令）、**SIP**、**RTSP** |
| **冲突** | **TLS 加密**后 ALG **无法解析**载荷 → 催生**被动 FTP**、**STUN/TURN** 穿透 |

**易混**：NAT **ALG**（改载荷）≠ 防火墙 **应用层代理**（拆双连接）→ [7.2 §代理](7.2-packet-filter-firewall.md#ch07-2-proxy)

<a id="ch07-3-mapping-types"></a>

## NAT 映射类型（P2P 穿透）

按 **RFC 3489 / 5389** 四类（STUN 语境）；**P2P 友好度从高到低**：

| # | 类型 | 行为 | 打洞难度 |
|---|------|------|----------|
| 1 | **全锥 / Full Cone**（端点独立 EIM + 宽松过滤） | 内网 `IP:Port` → **固定**公网 `IP:Port`；**任意**外网 IP 可回连 | **最易** |
| 2 | **限制锥 / Restricted Cone**（EIM + 地址相关 ADF） | 固定公网映射；仅**曾主动访问过的外网 IP** 可回连 | 较易 |
| 3 | **端口限制锥 / Port-Restricted** | 固定公网映射；仅**曾访问过的外网 IP:Port** 可回连 | 较难 |
| 4 | **对称型 / Symmetric NAT**（ADM） | 内网 `IP:Port` + **不同目的** → **不同**公网 `IP:Port` | **最难**，常需 **TURN 中继** |

**口诀**：**全锥易、限制中、端口难、对称靠中继**

→ 与 study **EIM/ADM/EIF/ADF** 对照：[study §7.3.2–7.3.3](./study.md#ch07-3) · 穿透协议：[7.4 NAT 穿越](7.4-nat-traversal.md)

| 本书术语 | STUN 四类 |
|----------|-----------|
| **EIM** 映射无关目的 | Full / Restricted / Port-Restricted 的前半 |
| **ADM** 映射随目的变 | **Symmetric** |
| **EIF vs ADF** 过滤 | 决定「谁能打进来」— **Filtering 常比 Mapping 更影响 P2P** |

<a id="ch07-3-cheat"></a>

## 一页纸考试速记卡

| # | 核心短句 | 易错 |
|---|----------|------|
| 1 | NAT = **改 IP 头 + 状态表**；边界网关；五元组映射 + **老化** | NAT 不是 L7 代理 |
| 2 | **基本 NAT** 只改 IP；**NAPT** 改 **IP+端口**，**多对一**最常见 | 家宽 = NAPT；对外服务 = **静态映射** |
| 3 | **Hairpin**：内网访问**公网 IP** 指回内网 → **DNAT+SNAT 发夹** | 无 Hairpin → 内网用公网 IP 互访失败 |
| 4 | **ALG**：改**载荷**里私网 IP（FTP/SIP）；**TLS 下失效** | ALG ≠ 防火墙代理 |
| 5 | P2P：**全锥易 → 对称需 TURN**；**Filtering（ADF）** 常是瓶颈 | 对称 NAT 每目的不同映射 |

**顺序背诵**：作用隐藏 · 改头+表 · NAPT 多对一 · Hairpin 发夹 · ALG 改载荷 · 四类 NAT 打洞
