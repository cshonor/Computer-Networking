## NAT 基础五要点（速记）

| # | 要点 |
|---|------|
| 1 | **作用**：私网复用公网 IP，隐藏内网 |
| 2 | **本质**：改写 IP 首部 + **状态映射表** |
| 3 | **对象**：基本 NAT 改 IP；**NAPT** 改 IP+端口 |
| 4 | **位置**：边界网关；**数据平面改写**，控制平面**管表** |
| 5 | **状态**：内网五元组 ↔ 公网五元组，**老化超时** |

→ 出站/入站分步：[04 §4.3 工作过程](../../../04_network_layer_data_plane/4.3_ipv4_ipv6_nat.md#ch4-3-nat-flow)

## 基本 NAT vs NAPT

| 类型 | 行为 |
|------|------|
| **基本 NAT** | 私网 IP ↔ 公网 IP（一对一或池） |
| **NAPT（最常见）** | 多内网主机共享**一个公网 IP**，靠 **端口映射** 区分 |

---

## Hairpin / NAT 环回

- 内网主机用**公网 IP** 访问**同网段**另一内网服务 → 需路由器**发夹转发**支持。

---

## ALG（应用层网关）

- 载荷里嵌**内网 IP**（如 **FTP PORT**）→ NAT 设备改写为公网地址。
- 与现代加密协议（TLS）冲突 → 催生 **被动 FTP / 专用穿透**。

---

## NAT 映射类型（P2P）

| 类型 | P2P 友好度 |
|------|------------|
| **端点独立 (EIM)** | 较易打洞 |
| **地址相关 (ADF)** | 较难；对称型 NAT 常需 **TURN** |
