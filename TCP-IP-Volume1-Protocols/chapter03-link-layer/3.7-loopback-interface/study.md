# 3.7 环回 (Loopback)

> 章级精读：[../study.md#ch03-7](../study.md#ch03-7)

## 本节核心目标

理解 `127.0.0.1` / `::1` 的**软件环回**语义与开发用途。

---

## 核心要点

- **环回接口**：纯软件虚拟接口，**不经过物理网卡**。
- 发往环回地址的 IP 数据报在**本机协议栈内折返**。
- 典型用途：本机服务联调、健康检查、进程间“网络”通信。

---

## 考点

| 版本 | 常用地址 |
|------|----------|
| IPv4 | `127.0.0.0/8`，常用 `127.0.0.1` |
| IPv6 | `::1` |

- 环回流量**不出主机**，抓包需在环回接口或本机代理处观察。
