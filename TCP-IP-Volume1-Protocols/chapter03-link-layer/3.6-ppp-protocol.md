## PPP（Point-to-Point Protocol）

**IETF** 制定的**面向字节**点到点链路层协议：全双工链路上承载**多协议**数据报；互联网**最广**的广域网点对点协议之一。

### 核心组成

| 组件 | 职责 |
|------|------|
| **LCP**（链路控制协议） | 建立/配置/测试/拆除链路；协商 **MTU（MRU）**、认证方式、魔术字等 |
| **NCP**（网络控制协议） | 为各网络层配置参数；**IPCP** 等可**自动协商 IP 地址** |
| **认证** | **PAP**（明文，两次握手）· **CHAP**（挑战-响应，不传明文密码，更安全） |

### 建立流程

```text
物理层 up → LCP 协商 → PAP/CHAP（可选）→ NCP/IPCP 分配 IP → 传 IP 等载荷
```

### PPP 帧格式（基于 HDLC 改造）

```text
| Flag 0x7E | Addr 0xFF | Ctrl 0x03 | Protocol 2B | Info | FCS 2B | Flag 0x7E |
```

| 字段 | 说明 |
|------|------|
| **Flag** | `0x7E`，帧定界 |
| **Address** | 固定 `0xFF`（点到点无多站） |
| **Control** | 固定 `0x03` |
| **Protocol（PPP 特有 2B）** | 上层协议，如 **`0x0021` = IPv4**、LCP、IPCP |
| **Info** | 可变载荷 |
| **FCS** | 2 字节 CRC |

**要 MAC 吗？** 不需要；仅一个对端。

### PPP 特点

| ✅ | ❌ |
|----|-----|
| **异步**（Modem 拨号）+ **同步**（E1/SDH 专线） | **无链路层序号/确认**，可靠靠 **TCP 等上层** |
| 认证、IP 协商、链路质量检测 | |
| 可扩展 → **PPPoE**（以太网承载 PPP） | |

## HDLC（High-Level Data Link Control）

**ISO** 基于 IBM SDLC 的**面向比特**同步链路层协议：点到点或**点到多点**。

### HDLC 帧格式

```text
| Flag 01111110 | Address 1B | Control 1B | Info | FCS 2B | Flag |
```

| 字段 | 说明 |
|------|------|
| **Control** | **I 帧**（带序号/确认）· **S 帧**（监督）· **U 帧**（无编号控制） |
| **Address** | 从站地址，支持多点 |

**透明传输**：**0 比特插入**（bit stuffing），可传任意比特模式。

### HDLC 特点

| ✅ | ❌ |
|----|-----|
| 链路层**序号、确认、流量控制、差错恢复** | **仅同步**，不支持异步拨号 |
| 全双工、效率高 | **无认证、无 IP 协商**（地址手工配） |
| | 配置复杂；多用于 **SDH/E1、帧中继、电信专线** |

---

## PPP vs HDLC（必背对比）

| 对比项 | **PPP** | **HDLC** |
|--------|---------|----------|
| 制定 | **IETF**（互联网） | **ISO**（电信） |
| 面向 | **字节** | **比特** |
| 链路 | **异步 + 同步** | **仅同步** |
| 认证 | **PAP / CHAP** | 无 |
| IP 协商 | **NCP / IPCP** | 无 |
| **协议字段** | **有（2B）** | 无 |
| 链路可靠 | **无**（靠上层） | **有**（序号/确认） |
| 典型应用 | 拨号、**PPPoE**、路由器 WAN | SDH/E1、帧中继、电信网 |

**关系**：PPP 帧**脱胎于 HDLC** — 简化固定 Addr/Ctrl，**增加 Protocol 字段**；用链路层可靠性换**灵活性、认证与多协议**。

## 一页背诵清单（考点速记）

### 帧格式口诀

```text
PPP：  7E FF 03 [协议2B] 数据 FCS 7E     协议 0021=IP
HDLC： 7E 地址 控制 数据 FCS 7E         控制里带序号/ACK
```

### 三句话定位

1. **PPP** = 互联网 WAN 主力；**LCP 链路 + NCP 网络层 + PAP/CHAP**。
2. **HDLC** = 电信同步专线；**链路层可靠**，但不帮你在链路上谈 IP。
3. **PPPoE** = 在以太网上跑 PPP（发现 + 会话），宽带常见。

### 易错 5 条

| # | 陷阱 | 正解 |
|---|------|------|
| 1 | PPP 有链路层重传 | **无**；丢包靠 IP/TCP |
| 2 | HDLC 能自动拿 IP | **不能**；无 NCP |
| 3 | PAP 比 CHAP 安全 | **CHAP** 不传明文密码 |
| 4 | PPP 需要 MAC | **不需要**（点对点） |
| 5 | PPP 与 HDLC 无关 | PPP **基于 HDLC 帧结构改造** |
