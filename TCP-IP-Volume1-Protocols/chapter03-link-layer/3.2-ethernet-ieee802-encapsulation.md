## 一、介质访问机制演进（大白话）

### 1）经典共享式以太网（Hub 时代）

| 项 | 说明 |
|----|------|
| **组网** | 总线型 / **集线器 Hub** 星型；**半双工** |
| **机制** | **CSMA/CD**（载波侦听多路访问 + **冲突检测**） |

**CSMA/CD 四步（考试简答）**

1. **先听后发**：发送前侦听信道是否空闲  
2. **边发边听**：发送中持续检测是否冲突  
3. **冲突停发**：发现冲突立即停止，发**阻塞信号**  
4. **随机重传**：**二进制指数退避**后重试  

**冲突域**：**全网所有设备在同一个冲突域**——多人同时发帧会撞车，**带宽共享、效率低**。

### 2）现代交换式以太网（Switch，当前主流）

| 项 | 说明 |
|----|------|
| **组网** | **交换机**星型；端口常 **全双工** |
| **机制** | 端口**点对点**；基于 **MAC 地址表** 转发，**不再靠 CSMA/CD 协调整网** |

1. 交换机查 **MAC 表**，只向目标端口转发（不是 Hub 那样所有端口都收到）  
2. 全双工时**收发物理分离**，可同时发+收，**无信号冲突**  

**冲突域**：**每个交换机端口 ≈ 独立冲突域**（常缩小到单个端点）；交换网内**基本无经典冲突**。

### 3）核心对比（直接背）

| | **共享式（Hub）** | **交换式（Switch）** |
|---|-------------------|----------------------|
| 设备 | 集线器 Hub | 交换机 Switch |
| 双工 | **半双工** | **全双工**（常见） |
| MAC 机制 | **CSMA/CD** | **无需 CSMA/CD**（端口隔离） |
| 冲突域 | **1 个大冲突域** | **每端口独立** |
| 带宽 | **共享** | 端口**独享** |

> **口诀**：Hub 半双工 CSMA/CD 一大域 · Switch 全双工 MAC 表 端口各一域

→ WiFi 用 **CSMA/CA**（避免冲突，不是 CD）→ [3.5](./3.5-wireless-80211.md) · [自顶向下 §6.3](../../../top_down/06_link_layer_and_lan/6.3_mac_protocol/study.md#ch6-3-csma-local)

## 二、以太网帧（必背）

| 字段 | 作用 |
|------|------|
| 目的 / 源 **MAC** | L2 寻址 |
| **类型/长度** | EtherType（如 **0x0800** = IPv4）→ 上层分用 |
| 载荷 | 常为 **IP 数据报**（受 **MTU** 限制，常见 1500 B） |
| **FCS** | CRC **检错**（以太网一般**不重传**，坏帧丢弃） |

**Ethernet II**

```text
| 目的 MAC 6B | 源 MAC 6B | 类型 2B | 数据 46–1500B | FCS 4B |
```

## 三、进阶（802.1 族）

- **802.1Q VLAN**：虚拟局域网，隔离**广播域**（冲突域早已由交换机拆开）→ [3.4](./3.4-bridge-switch-stp.md)  
- **802.1p/q**：优先级与 QoS 标记  
- **802.1AX**：链路聚合（LACP），带宽与冗余

<a id="ch03-2-exam"></a>

## 四、30 秒写卷子 + 易混

**共享式**：Hub · 半双工 · **CSMA/CD** · **一个冲突域** · 带宽共享  
**交换式**：Switch · 全双工 · **MAC 表转发** · **每端口一域** · 无经典冲突  

| 易混 | 纠正 |
|------|------|
| 帧 vs 分组 | **帧** = 链路层；**IP 分组** = 网络层；MTU 限制进帧的 IP 载荷 |
| CSMA/CD vs CA | **CD** = 有线以太网（检测冲突）；**CA** = WiFi（避免冲突） |
| 冲突域 vs 广播域 | 交换机拆**冲突域**；**VLAN** 才拆**广播域** |

## 五、自测（3 题）

1. Hub 组网为何必须用 CSMA/CD？交换机为何可以取消？  
2. 全双工交换端口是否还与邻居「抢信道」？  
3. CSMA/CD 四步各是什么？

<details>
<summary>答案</summary>

1. Hub **所有端口同一冲突域**，同时发必冲突，需 **CSMA/CD** 协调；交换机**端口隔离** + 常全双工，**无共享介质竞争**。  
2. **不会**（正常全双工点对点）；收发分开，无半双工意义上的冲突。  
3. 先听后发 → 边发边听 → 冲突停发 → 二进制指数退避重传。

</details>
