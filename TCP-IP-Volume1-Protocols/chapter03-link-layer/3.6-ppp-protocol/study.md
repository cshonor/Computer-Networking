# 3.6 点到点协议 (PPP)

> 章级精读：[../study.md#ch03-6](../study.md#ch03-6)

## 本节核心目标

掌握 PPP 的 **LCP / NCP** 分工与 **PAP / CHAP** 认证差异。

---

## 结构

| 协议 | 职责 |
|------|------|
| **LCP** | 链路建立、维护、拆除、选项协商 |
| **NCP**（如 IPCP） | 协商**网络层**参数（IP 地址等） |

---

## 认证

| 方式 | 特点 |
|------|------|
| **PAP** | 明文用户名/密码，简单不安全 |
| **CHAP** | 质询-响应，不在线路上传明文密码 |

---

## 场景

- 早期拨号、部分 **DSL/专线**；现代接入多被以太网 + PPPoE 等替代，但 WAN 概念仍考。
