# 3.2 以太网与 IEEE 802 局域网/城域网标准

> 章级精读：[../study.md#ch03-2](../study.md#ch03-2) · 自顶向下：[§6.4 以太网/交换](../../../06_link_layer_and_lan/study.md#ch6-4)

## 本节核心目标

掌握**以太网帧格式**、共享式到交换式的演进，以及 VLAN/QoS/链路聚合要点。

---

## 机制演进

| 时代 | 机制 |
|------|------|
| 经典共享以太网 | **CSMA/CD**（侦听 + 冲突检测） |
| 现代交换式 | 全双工交换机端口，**无冲突域**（冲突域缩小到端点） |

---

## 以太网帧（必背）

| 字段 | 作用 |
|------|------|
| 目的 / 源 **MAC** | L2 寻址 |
| **类型/长度** | EtherType（如 0x0800=IPv4）→ 上层分用 |
| 载荷 |  often **IP 数据报** |
| **FCS** | CRC 检错 |

---

## 进阶

- **802.1Q VLAN**：虚拟局域网隔离广播域。
- **802.1p/q**：优先级与 QoS 标记。
- **802.1AX**：链路聚合（LACP），带宽与冗余。

---

## 易混

- **帧**（链路层）vs **IP 分组**（网络层）：封装关系，MTU 限制的是 IP 载荷进帧的大小。
