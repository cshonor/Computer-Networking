# 3.9 隧道基础

> 章级精读：[../study.md#ch03-9](../study.md#ch03-9) · 网关隧道：[HTTP 书 ch08 概念](../../HTTP-The-Definitive-Guide/chapter08-gateway-tunnel/study.md)（应用层对照）

## 本节核心目标

理解**在一种协议载荷里再封装另一种协议**的隧道思想（VPN 雏形）。

---

## 典型形式

| 类型 | 说明 |
|------|------|
| **IP-in-IP** | 新 IP 头包旧 IP 数据报，跨异构网透传 |
| **GRE** | 通用路由封装，可载多种上层协议 |

---

## 要点

- 外层包头负责**穿越**当前网络；内层包头在隧道端点**解封**后继续转发。
- 与 **NAT、MTU** 强相关：隧道常**缩小有效 PMTU** → 结合 [3.8 PMTUD](3.8-mtu/study.md)。

---

## 易混

- **隧道**（再封装）vs **NAT**（改写头字段）vs **代理**（应用层语义）— 排障时先分清层次。
