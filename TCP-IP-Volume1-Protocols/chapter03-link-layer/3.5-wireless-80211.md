# 3.5 无线局域网 — IEEE 802.11 (Wi-Fi)

> 章级精读：[../study.md#ch03-5](../study.md#ch03-5) · 自顶向下：[§6.3 多路访问](../../../top_down/06_link_layer_and_lan/study.md#ch6-3) · [§7.1 Wi-Fi](../../../top_down/07_wireless_mobile_network/7.1_wifi_802_11.md)

## 本节核心目标

理解 **CSMA/CA**、802.11 帧与关联流程，以及无线安全演进。

---

## CSMA/CA（冲突避免）

- 无线电**难以像网线那样可靠检测冲突** → 用退避与可选 **RTS/CTS** 缓解**隐藏终端**。

---

## 帧与管理

- 帧可含**多达 4 个 MAC 地址**（AP/站点/转发场景）。
- **BSS、SSID**：扫描 → 关联 → 认证（与 802.1X/WPA 衔接）。

---

## 安全演进

| 代际 | 评价 |
|------|------|
| **WEP** | 已破解，禁用 |
| **WPA / WPA2** | 802.11i；**AES-CCMP** 为主流 |
| **WPA3** | 后续强化（实践查设备支持） |

---

## 易混

- **Wi‑Fi 链路 MTU** 常大于以太网 1500 的“感知”，但跨网仍受路径 **PMTUD** 约束 → [3.8](3.8-mtu.md)。
