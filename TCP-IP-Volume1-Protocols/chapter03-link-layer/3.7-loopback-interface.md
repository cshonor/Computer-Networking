# 3.7 环回 (Loopback)

> 章级精读：[../study.md#ch03-7](../study.md#ch03-7) · Ch2 特殊地址：[2.5](../chapter02-ip-address-architecture/2.5-special-ipv4-blocks.md) · 自顶向下：[§6.6 环回](../../../top_down/06_link_layer_and_lan/study.md)

## 本节核心目标

理解环回**软件接口**、`127.0.0.1` / `::1` 地址范围、**不可路由**与 **Router-ID / 远程管理** 等考点。

---

<a id="ch03-7-core"></a>

## 一、核心要点（环回接口 / 地址）

| 点 | 大白话 |
|----|--------|
| **是什么** | **纯软件虚拟接口**，无物理网卡/端口 |
| **状态** | **永远 Up**（不受网线、物理口影响） |
| **流量去哪** | 发往环回地址的包**只在协议栈内折返**，**不经过物理链路** |
| **干什么用** | 本机服务测试、健康检查、进程间「走网络栈」通信、设备自检 |

```text
应用 send → IP 认 localhost → 进链路层前“转弯” → IP 输入 → recv
（无真实网线信号）
```

---

<a id="ch03-7-addr"></a>

## 二、地址与掩码（必背）

### IPv4

| 项 | 内容 |
|----|------|
| **保留网段** | **127.0.0.0/8**（整个 A 类段给环回） |
| **最常用** | **127.0.0.1**（localhost） |
| **有效范围** | **127.0.0.1 – 127.255.255.255** 均可作环回 |
| **掩码** | 主机常配 **/8**；路由器/三层设备上环回口常配 **/32**（255.255.255.255）作**设备标识** |

### IPv6

| 项 | 内容 |
|----|------|
| **地址** | **::1**（完整 `0:0:0:0:0:0:0:1`） |
| **前缀** | **/128**（仅此一个环回地址） |

---

<a id="ch03-7-features"></a>

## 三、关键特性（高频）

1. **永远 Up**：稳定性强，不依赖物理链路。  
2. **不可路由**：环回流量**仅本机**；**路由器不转发**到外网/其他主机。  
3. **抓包**：要在**环回接口**或本机代理处抓；**物理网卡上看不到**环回本机流量。  
4. **设备「身份证」**：  
   - **OSPF / BGP**：常用环回口 IP 作 **Router-ID**，物理口变也不影响邻居关系。  
   - **远程管理**：用环回 IP 登录，避免某物理口 Down 后**管不上设备**。

---

<a id="ch03-7-traps"></a>

## 四、易混（避坑）

| ❌ 错 | ✅ 对 |
|------|------|
| IPv4 环回是 **127.0.0.0/24** | **127.0.0.0/8** |
| IPv6 环回是 **FE80::1** | **::1/128**（**FE80** = **链路本地**，不是环回） |
| 环回会出网卡上网 | **不出主机**，不可被路由转发 |

**localhost**：多是主机名，经 **hosts/DNS** 解析到 **127.0.0.1**（名字 ≠ 地址本身）。

---

<a id="ch03-7-exam"></a>

## 五、五句背诵（专抄）

1. 环回 = **软件虚拟口**，**永远 Up**，流量**不出物理链路**。  
2. IPv4：**127.0.0.0/8**，常用 **127.0.0.1**；IPv6：**::1/128**。  
3. **不可路由**，仅本机；抓包用**环回口**，非物理网卡。  
4. 路由协议常用环回 IP 作 **Router-ID**；远程管理绑环回更稳。  
5. 别混：**/8 不是 /24**；**::1 不是 FE80::1**。

---

## 六、自测

1. 为何 `ping 127.0.0.1` 不需要插网线？  
2. 127.0.0.2 算不算环回？  
3. OSPF Router-ID 为何常选环回地址？

<details>
<summary>参考答案</summary>

1. 包在**本机协议栈内折返**，不经物理网卡。  
2. **算**（整个 **127.0.0.0/8** 保留给环回）。  
3. 环回口**稳定、不随物理口 Down**，邻居关系不因某条链路 flap 而变 ID。

</details>
