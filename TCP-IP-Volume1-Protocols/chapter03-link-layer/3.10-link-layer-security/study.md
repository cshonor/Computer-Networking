# 3.10 与链路层相关的攻击

> 章级精读：[../study.md#ch03-10](../study.md#ch03-10)

## 本节核心目标

认识链路层**默认互信**带来的典型威胁与管控思路。

---

## 典型攻击

| 攻击 | 说明 |
|------|------|
| **MAC 泛洪** | 撑爆交换机 CAM 表 → 退化为泛洪，便于嗅探 |
| **STP 劫持** | 伪造 BPDU 争根桥，操纵转发路径 |
| **无线嗅探 / WEP 破解** | 空中明文或弱加密 → 见 [3.5](3.5-wireless-80211/study.md) |
| **ARP 欺骗** | 虽属 L2/L3 交界，常在接入层实施 → [ch04](../../chapter04-arp-protocol/study.md) |

---

## 防护原则

- **物理与逻辑隔离**：端口安全、802.1X、VLAN 划分、监控 STP。
- **不信任接入交换机**：关键服务器用静态 CAM、私有 VLAN 等（视规模）。

---

## 与端到端安全

- 链路层加固**不能替代** TLS/IPsec（[ch18](../../chapter18-network-security/study.md)）。
