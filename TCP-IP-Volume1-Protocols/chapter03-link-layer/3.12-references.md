# 3.12 参考文献

> 章级导读：[../study.md](../study.md)

## 本节说明

IEEE **802.3 / 802.11 / 802.1Q** 等标准与 **PPP RFC**；精读时按需查阅。

---

## 建议检索

| 主题 | 方向 |
|------|------|
| 以太网 | IEEE 802.3 |
| Wi‑Fi | IEEE 802.11 |
| STP | 802.1D / 802.1w (RSTP) |
| PPP | RFC 1661 等 |
| MTU/PMTUD | 与 RFC 1191、ICMPv6 PTB 联动 |
