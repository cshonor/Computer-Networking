# 集线器（Hub）核心知识点

> 与交换式以太网对照：[3.2 §一 介质访问演进](./3.2-ethernet-ieee802-encapsulation.md#ch03-2-mac-evolution) · 交换机：[3.4](./3.4-bridge-switch-stp.md) · 章级：[study.md#ch03-2](../study.md#ch03-2) · 嗅探场景：[Wireshark §2.3.2 Hubbing](../../../wireshark-packet-analysis/chapter-02-traffic-monitor/03-sniff-on-switched-network.md)

## 本节核心目标

掌握 Hub 的**工作层级、转发规则、冲突域/广播域、CSMA/CD** 及与交换机的对比；理解为何已被交换机取代、为何抓包教材仍常提到 Hub。

---

## 一、基础属性

| 项 | 说明 |
|----|------|
| **工作层级** | **物理层**设备；只处理电/光信号，**不识别 MAC、不解析帧** |
| **本质** | 多端口中继器：**信号放大、整形、转发** |
| **拓扑** | 物理**星型**，逻辑**总线型**——所有端口共用一条总线 |

---

## 二、核心工作特点

### 1）转发规则

收到信号后**向除入端口外的所有端口广播泛洪**，不区分目标设备 → **本网段主机都能收到**（天然利于嗅探，见 [混杂模式](../../../wireshark-packet-analysis/chapter-02-traffic-monitor/01-promiscuous-mode.md)）。

### 2）冲突域与广播域

| 概念 | Hub |
|------|-----|
| **冲突域** | 整台 Hub **所有端口 = 1 个冲突域**；多机同时发 → 信号冲突 |
| **广播域** | 整台 Hub = **1 个广播域** |

### 3）传输模式与带宽

| 项 | 说明 |
|----|------|
| **双工** | 默认 **半双工**——同一端口不能同时收发 |
| **带宽** | **全体端口共享**（如 10Mbps Hub → 所有设备瓜分 10Mbps） |

---

## 三、配套机制：CSMA/CD

共享信道必须靠 **CSMA/CD** 规避冲突（交换式以太网端口全双工后基本不再需要）：

1. **载波监听**：发送前检测信道是否空闲  
2. **冲突检测**：发送中持续监听，发现冲突立即停止  
3. **阻塞 + 退避**：发阻塞信号通知全网，**随机延时**后重传  

→ 四步详述：[3.2 §一](./3.2-ethernet-ieee802-encapsulation.md#ch03-2-mac-evolution)

---

## 四、优缺点

### 优点

- 结构简单、价格低廉；早期小型组网。

### 缺点

- 冲突频发，主机越多效率越低；  
- 流量**全网可见**，**安全性极差**，易嗅探；  
- 半双工 + 共享带宽，性能瓶颈明显；  
- **已被交换机全面替代**（MAC 泛洪攻击可让交换机「退化」为类似 Hub 的泛洪行为 → [3.10](./3.10-link-layer-security.md)）。

---

## 五、Hub 与交换机（Switch）核心对比

| 对比项 | 集线器（Hub） | 交换机（Switch） |
|--------|---------------|------------------|
| **工作层** | 物理层 | 数据链路层 |
| **转发方式** | 全网广播 | 基于 **MAC 表** 精准转发 |
| **冲突域** | 整设备 **1 个** | **每端口独立**（全双工下常无冲突） |
| **广播域** | 1 个 | 1 个（未划 VLAN 时）；VLAN 可再分 |
| **带宽** | 所有端口**共享** | 单端口**独享**额定带宽 |
| **双工** | **半双工**为主 | **全双工**常见 |
| **CSMA/CD** | **必须** | 基本**不需要** |

---

## 六、一句话总结

集线器是老旧**物理层**共享总线设备：泛洪转发、一大冲突域、半双工、带宽共享、安全性差；现代网络由**交换机**替代，考试与抓包仍须理解 Hub 逻辑（含 **Hubbing Out** 嗅探与 **MAC 泛洪→伪 Hub**）。

## 疑问与总结

- **Hub vs 交换机**：Hub **不识 MAC**；交换机 **学 MAC、按端口转**。  
- **Hub vs 路由器**：Hub 在 **L1**；路由器在 **L3**，改 IP 路径。  
- 抓包：**真 Hub** 串入目标线路可见双向流量；**假 Hub**（实为交换机）无效 → [§2.3.2](../../../wireshark-packet-analysis/chapter-02-traffic-monitor/03-sniff-on-switched-network.md)。
