## 一、交换机工作原理（考试标准版）

### 1）学习（Learning）

- 每收到一帧：提取 **源 MAC + 入端口**
- 写入/更新 **MAC 地址表**（**MAC ↔ 端口** 映射）

### 2）转发 / 过滤（Forwarding / Filtering）

查 **目的 MAC**：

| 目的类型 | 行为 |
|----------|------|
| **已知单播** | 仅从**对应唯一端口**转发 |
| **未知单播** | **泛洪**（除入端口外所有端口） |
| **广播、组播** | **泛洪**（除入端口外所有端口） |

### 3）隔离冲突域

- **每个端口 = 独立冲突域**
- **全双工**下基本**无冲突**，**不用 CSMA/CD** → [3.2](./3.2-ethernet-ieee802-encapsulation.md#ch03-2-mac-evolution) · [3.3](./3.3-full-duplex-autoneg.md)

### 4）广播域

- 默认：**所有端口同一广播域**
- 划分：**VLAN（802.1Q）** 隔离广播域 → [3.2 VLAN](./3.2-ethernet-ieee802-encapsulation.md#ch03-2-vlan-tci)

> **一句话**：**查 MAC 表精准转发，隔离冲突域，VLAN 隔离广播域。**

### 简答题标准答案（可直接抄）

1. **学习**：收帧记 **源 MAC–入端口**，维护 **MAC 地址表**。  
2. **转发**：查目的 MAC — **已知单播** → **单端口转发**；**未知单播/广播/组播** → **泛洪**（不含入端口）。  
3. **冲突域**：**每端口独立**；全双工**无 CSMA/CD**。  
4. **广播域**：默认**同一广播域**；**802.1Q VLAN** 划分隔离。  
5. 总结：交换机 = **L2 按 MAC 转发**；**拆冲突域、VLAN 拆广播域**。

## 二、STP / RSTP 生成树（考试极简背诵版）

### 1）问题：物理环路危害

交换机冗余互联形成**物理环路**会导致：

- 数据帧**无限泛洪**
- **广播风暴**
- **MAC 地址表震荡**（不断改写学习结果）

### 2）STP（802.1D 传统生成树）

**核心思路**：选举**根桥**，**阻塞冗余端口**，逻辑上**无环树型拓扑**（物理线可仍在，逻辑不转发）。

**选举四步（必背）**

| 步骤 | 内容 |
|------|------|
| 1 **根桥** | **Bridge ID**（**优先级 + MAC**）**最小**者为根；**优先级数字越小越优先** |
| 2 **根端口 RP** | 每个**非根桥**选到根路径**开销最小**的端口 |
| 3 **指定端口 DP** | 每条网段选**离根最近**的交换机上的端口负责转发 |
| 4 **阻塞端口 BP** | **其余端口阻塞**，不转发，**消除环路** |

| 术语 | 说明 |
|------|------|
| **BPDU** | 交换机之间交换 STP 拓扑信息的**配置报文** |

**缺点**：收敛慢，常见 **30–50 秒**，链路故障切换卡顿。

### 3）RSTP（802.1w 快速生成树）

| 项 | 说明 |
|----|------|
| 兼容 | 与 STP **兼容** |
| 收敛 | **约 1–2 秒**（远快于 STP） |
| 端口角色 | 根端口、指定端口、**替代端口**、**备份端口**（更细） |
| 机制 | 减少依赖计时器，**握手协商**快速切换端口状态 |

### 4）一句话对比

- **STP**：阻塞冗余口 → **无环树** → **慢收敛**  
- **RSTP**：同样防环 → **快收敛**、故障切换快

<a id="ch03-4-stp-exam"></a>

### 简答题标准答案（可直接抄）

1. **环路危害**：无限泛洪、广播风暴、MAC 表震荡。  
2. **STP 目的**：逻辑上**切断环路**，形成**生成树**。  
3. **四步**：根桥（最小 Bridge ID）→ 根端口 RP → 指定端口 DP → **阻塞端口 BP**。  
4. **STP 缺点**：收敛 **30–50 s**。  
5. **RSTP**：802.1w，**1–2 s** 收敛，握手快速切状态。  
6. **BPDU**：交换机间传递 STP/RSTP 信息。

## 三、与路由器的边界

| | 交换机 | 路由器 |
|---|--------|--------|
| 层次 | **L2**，按 **MAC** | **L3**，按 **IP**（改 TTL 等） |
| 域 | 冲突域/VLAN 广播域 | 分割**广播域**、连接不同 IP 网段 |

## 四、实战与易混

## 五、自测（5 题）

1. 交换机收到目的 MAC 不在表中的单播帧，如何处理？  
2. 交换机能否隔离广播域？默认情况下呢？  
3. 为何交换端口一般不需要 CSMA/CD？  
4. STP 解决什么问题？四步选举各选什么？  
5. STP 与 RSTP 在收敛时间上的主要区别？

<details>
<summary>答案</summary>

1. **泛洪**到除入端口外的**所有端口**（未知单播）。  
2. **能**（用 **VLAN**）；**默认不能**，所有端口**同一广播域**。  
3. **每端口独立冲突域** + 常**全双工**，无共享介质竞争。  
4. **二层物理环路** → 广播风暴等；**根桥 → RP → DP → BP 阻塞**。  
5. **STP** 约 **30–50 s**；**RSTP** 约 **1–2 s**，握手快速收敛。

</details>
