# 4.2 一个例子（直接交付与间接交付）

> 章级精读：[../study.md#ch04-2](../study.md#ch04-2) · 自顶向下：[§6.7 Web 路径](../../../top_down/06_link_layer_and_lan/study.md#ch6-7)

## 本节核心目标

用访问 Web 服务器场景区分**同子网直接交付**与**经路由器间接交付**。

---

## 直接交付（同子网）

- 目的 IP 与本机在同一前缀 → ARP **广播**询问「该 IP 的 MAC？」
- 目标主机 **单播应答** → 发送方封装以太网帧发往该 MAC。

---

## 间接交付（跨子网）

- 目的 IP 在远端 → 本机 ARP 解析的是**默认网关** MAC。
- 帧发往网关；网关再按路由对**下一跳**做 ARP/IP 转发 → [ch05](../../chapter05-ip-protocol/study.md)。

---

## 易混（必背）

| 字段 | 同子网 | 跨子网 |
|------|--------|--------|
| IP 目的地址 | 服务器 IP | 服务器 IP |
| 以太网目的 MAC | **服务器 MAC** | **网关 MAC** |
