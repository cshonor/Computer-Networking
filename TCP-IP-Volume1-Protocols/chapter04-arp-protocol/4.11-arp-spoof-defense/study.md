# 4.11 与 ARP 相关的攻击

> 章级精读：[../study.md#ch04-6](../study.md#ch04-6) · [ch18 安全](../../chapter18-network-security/study.md)

## 本节核心目标

理解 **ARP 欺骗/中毒** 根因与工程缓解方向。

---

## ARP 欺骗 (Spoofing / Poisoning)

- 协议**无认证**：主机倾向接受**最新** ARP 应答。
- 攻击者伪造「IP X → 攻击者 MAC」→ 受害者流量经 **MITM**。

---

## 后果

- 窃听、篡改、会话劫持（若上层无 TLS）。
- 结合 **DHCP 劫持** 可扩大局域网危害。

---

## 缓解（工程）

| 手段 | 说明 |
|------|------|
| **DAI**（交换机） | 校验 ARP 与 DHCP 绑定 |
| **静态邻居** | 关键服务器固定 IP–MAC |
| **802.1X** | 控制接入 |
| **TLS / IPsec** | 端到端，不依赖 ARP 可信 |

---

## Go/Rust 开发侧

- **不要**在应用层假设「局域网邻居可信」；敏感通道必须 **TLS**。
