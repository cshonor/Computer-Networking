# 4.4 ARP 帧格式

> 章级精读：[../study.md#ch04-4](../study.md#ch04-4)

## 本节核心目标

掌握 **28 字节 ARP 报文** 与以太网 **0x0806** 封装。

---

## 关键字段

| 字段 | 典型值 |
|------|--------|
| 硬件类型 | 1（以太网） |
| 协议类型 | 0x0800（IPv4） |
| 硬件/协议地址长度 | 6 / 4 |
| **操作码** | **1**=请求，**2**=应答 |
| 发送方 MAC + IP | 请求方 |
| 目标 MAC + IP | 请求时目标 MAC 常为全 0 |

---

## 封装位置

```text
以太网：[ 目的 MAC ][ 源 MAC ][ 0x0806 ][ ARP 28B ][ FCS ]
```

- ARP **不**放在 IP 数据报内。
