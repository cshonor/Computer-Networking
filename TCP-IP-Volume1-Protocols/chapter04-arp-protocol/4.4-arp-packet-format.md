# 4.4 ARP 帧格式

> 章级精读：[study.md#ch04-4](./study.md#ch04-4) · EtherType：[ch01 §分用](../chapter01-overview/study.md#ch01-layering) · 抓包：[4.5](4.5-arp-tcpdump-example.md)

## 本节核心目标

掌握 **28 字节 ARP 报文**结构，以及以太网帧中用 **0x0806** 标识 ARP 类型。

---

<a id="ch04-4-payload"></a>

## 一、ARP 报文格式（28 字节，不含以太网头）

| 字段 | 长度(B) | 典型值 | 说明 |
|------|---------|--------|------|
| **硬件类型** | 2 | **1** | 以太网（Ethernet） |
| **协议类型** | 2 | **0x0800** | IPv4 |
| **硬件地址长度** | 1 | **6** | MAC 长度 |
| **协议地址长度** | 1 | **4** | IPv4 长度 |
| **操作码 Opcode** | 2 | **1**=请求，**2**=应答 | |
| **发送方 MAC** | 6 | 本机 MAC | 发送方硬件地址 |
| **发送方 IP** | 4 | 本机 IP | 发送方协议地址 |
| **目标 MAC** | 6 | 请求时 **全 0** | 应答时填目标 MAC |
| **目标 IP** | 4 | 待解析 IP | 要查询的 IP |

> **总长度**：2+2+1+1+2+6+4+6+4 = **28 字节**

→ 与 [ch01 Protocol vs EtherType](../chapter01-overview/study.md#ch01-layering)：ARP 载荷内 **0x0800** 表示「要解析的是 IPv4」；帧头 **0x0806** 表示「载荷是 ARP」。

---

<a id="ch04-4-eth"></a>

## 二、以太网封装（完整 ARP 帧）

```text
[目的 MAC(6)][源 MAC(6)][类型(2)][ARP 报文(28)][FCS(4)]
                          ↑ 0x0806
```

| 项 | 说明 |
|----|------|
| **EtherType** | **0x0806** = ARP 帧 |
| **位置** | ARP **不封装在 IP 数据报内**，直接作为以太网**数据段**载荷 |

→ [ch03 §3.2 EtherType](../chapter03-link-layer/3.2-ethernet-ieee802-encapsulation.md#ch03-2-frame)

<a id="ch04-4-request-reply"></a>

## 三、请求 vs 应答（关键行为）

### ARP 请求（Opcode = 1）

| 层 | 字段 | 值 |
|----|------|-----|
| **ARP 载荷** | 目标 MAC | `00:00:00:00:00:00`（全 0，未知） |
| **以太网帧** | 目的 MAC | `FF:FF:FF:FF:FF:FF`（**广播**） |

### ARP 应答（Opcode = 2）

| 层 | 字段 | 值 |
|----|------|-----|
| **ARP 载荷** | 目标 MAC | 请求方真实 MAC |
| **以太网帧** | 目的 MAC | **单播**到请求方 |

→ 广播请求、单播应答：[4.2 §ARP 循环](4.2-arp-basic-operation.md#ch04-2)

<a id="ch04-4-cheat"></a>

## 四、速记卡

| 易记 | 内容 |
|------|------|
| **28 B** | 不含以太网头/FCS |
| **1 / 0x0800 / 6 / 4** | 以太网 + IPv4 组合 |
| **1 / 2** | 请求 / 应答 |
| **0x0806** | 帧类型 = ARP |
| **请求** | 帧广播 + ARP 目标 MAC 全 0 |
| **不在 IP 里** | 链路层直接承载 |

<a id="ch04-4-capture"></a>

## 五、抓包与过滤

| 过滤器 | 用途 |
|--------|------|
| `arp` | 所有 ARP |
| `arp.opcode == 1` | 仅 **请求** |
| `arp.opcode == 2` | 仅 **应答** |

→ 实操：[4.5 tcpdump](4.5-arp-tcpdump-example.md) · [Wireshark §7.1 ARP](../../wireshark-packet-analysis/chapter-07-network-layer-proto/01-arp-protocol.md)
