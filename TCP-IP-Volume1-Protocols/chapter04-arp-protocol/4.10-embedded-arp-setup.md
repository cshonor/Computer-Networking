# 4.10 使用 ARP 设置嵌入式设备 IPv4 地址

> 章级精读：[../study.md#ch04-6](../study.md#ch04-6)

## 本节核心目标

了解无屏无键盘设备通过 **静态 ARP + 诱导报文** 绑定 IP 的底层技巧。

---

## 思路（概念）

1. 在 PC 上用 `arp -s <新IP> <设备MAC>` 建立静态映射。
2. 向该 IP 发送特定流量（如 **ICMP**），设备栈可能据此**采纳**该地址（实现因厂商而异）。

---

## 注意

- 属**引导/产测**类技巧，非日常 DHCP 替代。
- 生产环境优先 **DHCP 保留** 或 **SLAAC/DHCPv6** → [ch06](../../chapter06-dhcp-config/study.md)。
