# 4.3 ARP 缓存

> 章级精读：[../study.md#ch04-3](../study.md#ch04-3) · 超时机制：[4.6](4.6-arp-cache-timeout.md)

## 本节核心目标

理解 ARP **缓存表** 如何避免每次通信都广播。

---

## 核心要点

- 近期 **IP ↔ MAC** 映射保存在内核**邻居/ARP 缓存**。
- 命中缓存 → **无需**再发 ARP 请求，降低广播与延迟。
- 查看：`arp -a`（Windows/传统）或 `ip neigh`（Linux）。

---

## 状态（Linux `ip neigh` 常见）

| 状态 | 含义 |
|------|------|
| REACHABLE | 近期确认可达 |
| STALE | 需验证仍有效 |
| INCOMPLETE | 已发请求、未收到应答 |

---

## 实践

- 首 ping 常多一次 RTT：**先发 ARP 再发 ICMP**。
