# 2.7 单播地址分配

> 章级精读：[../study.md#ch02-6](../study.md#ch02-6) · DHCP：[ch06](../../chapter06-dhcp-config/study.md)

## 本节核心目标

理解从**单机 / 家庭 NAT+DHCP** 到**企业多宿主**的地址规划。

---

## 典型拓扑

| 场景 | 常见做法 |
|------|----------|
| 单主机 | 公网或私网 + 默认网关 |
| 家庭 LAN | **RFC1918** + **NAT** + **DHCP** 自动配址 |
| 企业 | 划分 VLAN/子网、汇总路由、DHCP 池规划 |

---

## 多宿主 (Multihoming)

- 同时接入**多个 ISP** → 高可用、策略路由。
- **PI（提供商独立）** vs **PA（提供商聚合）**：
  - **PI**：自有可携带前缀，换 ISP 仍宣告同前缀（成本高、需 RIR 分配）。
  - **PA**：用 ISP 分的前缀，换 ISP 往往需**重编地址**或重宣告。

---

## 考点

- 多宿主解决的是**可用性/策略**，不是免费增加带宽（需 ECMP/策略路由设计）。
