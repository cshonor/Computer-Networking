## 本节说明

原书列出 CIDR、IPv6、地址分配、多宿主等 **RFC 与文献**；按需检索，精读时回填编号。

---

## 建议优先查阅

| 主题 | 检索方向 |
|------|----------|
| CIDR | RFC 4632 及前身 1519 |
| 私有地址 | RFC 1918 |
| IPv6 地址架构 | RFC 4291、5952（文本表示） |
| 源地址过滤 | BCP 38 (RFC 2827) |
| 任播 | RFC 7098 等 |
