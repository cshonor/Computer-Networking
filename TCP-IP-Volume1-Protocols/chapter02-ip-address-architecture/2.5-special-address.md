# 2.5 特殊用途地址

> 章级精读：[../study.md#ch02-5](../study.md#ch02-5) · 组播：[ch09](../chapter09-broadcast-multicast/study.md) · NAT/过渡：[ch07](../chapter07-firewall-nat/study.md) · [2.2 IPv6 映射](./2.2-ip-address-representation.md#ch02-2-ipv6-chunks)

## 本节核心目标

区分 **私有 / 环回 / 链路本地 / 组播 / 任播 / 文档 / 过渡地址**；掌握 IPv4、IPv6 对应块；辨析**组播 vs 广播**、**任播 vs 单播**。

---

<a id="ch02-5-ipv4"></a>

## 一、IPv4 特殊地址（RFC 1918 / RFC 6890）

### 1）私有地址（内网，NAT，**不上公网**）

| 块 | 范围 |
|----|------|
| **10.0.0.0/8** | 10.0.0.0 – 10.255.255.255 |
| **172.16.0.0/12** | 172.16.0.0 – 172.31.255.255 |
| **192.168.0.0/16** | 192.168.0.0 – 192.168.255.255 |

### 2）环回 Loopback（本机，**不经物理网卡出站**）

- **127.0.0.0/8**（常用 **127.0.0.1**）

### 3）链路本地 APIPA（DHCP 失败自动）

- **169.254.0.0/16**

### 4）组播 Multicast（一对多，D 类）

- **224.0.0.0/4**（224–239）
  - **224.0.0.1**：本网段所有主机
  - **224.0.0.2**：本网段所有路由器

### 5）广播（**仅 IPv4**）

- **255.255.255.255/32**：受限广播（不跨路由）

### 6）文档 / 测试（**公网不可路由**）

- **192.0.2.0/24**（TEST-NET，RFC 5737）

### 其他（章级表 2-7）

- **0.0.0.0/8**：本网络「本主机」语义（启动/DHCP 等）

<a id="ch02-5-ipv6"></a>

## 二、IPv6 特殊前缀（RFC 4193 / 3849 / 6890）

| 类型 | 前缀 | 说明 |
|------|------|------|
| **环回** | **`::1/128`** | 等价 `127.0.0.1` |
| **未指定** | **`::/128`** | 地址缺失 |
| **ULA 私有** | **`fc00::/7`** | 常用 **`fd00::/8`**（本地唯一，随机） |
| **链路本地** | **`fe80::/10`** | 每接口必有；**仅链路内** |
| **组播** | **`ff00::/8`** | **`ff02::1`** 链路所有节点；**`ff02::2`** 所有路由器 |
| **文档** | **`2001:db8::/32`** | 教材/示例，**勿上公网** |
| **IPv4 映射** | **`::ffff:0:0/96`** | 见 [2.2](./2.2-ip-address-representation.md) |

### 任播 Anycast

- **无单独前缀**；**与单播同格式**，多机共享同一地址，路由选**拓扑最近**应答（DNS 根、CDN）。

## 三、IPv4 ↔ IPv6 过渡地址（联动 ch07 NAT）

| 机制 | 前缀 / 格式 | 说明 |
|------|-------------|------|
| **IPv4-mapped** | **`::ffff:0:0/96`** | 例 `::ffff:192.168.1.1` |
| **NAT64** | **`64:ff9b::/96`** | 无状态翻译，嵌入 IPv4 |
| **6to4** | **`2002::/16`** | 由公网 IPv4 生成前缀 |
| **Teredo** | **`2001::/32`** | NAT 后 IPv6 穿透 |

## 四、分类速记表（直接背）

| 类型 | IPv4 | IPv6 | 用途 |
|------|------|------|------|
| 私有 | 10/8、172.16/12、192.168/16 | fc00::/7（fd00::/8） | 内网 + NAT |
| 环回 | 127.0.0.0/8 | ::1/128 | 本机自测 |
| 链路本地 | 169.254/16 | fe80::/10 | APIPA / 邻居发现 |
| 组播 | 224.0.0.0/4 | ff00::/8 | 一对多（IGMP/MLD） |
| 任播 | 无单独块 | 共享单播前缀 | 同址多机，就近 |
| 文档 | 192.0.2.0/24 | 2001:db8::/32 | 示例，不上公网 |
| 过渡 | — | ::ffff:/96、64:ff9b::/96、2002::/16 | v4↔v6 |

<a id="ch02-5-exam"></a>

## 五、易混辨析（必考）

| 对比 | 要点 |
|------|------|
| **组播 vs 广播** | 广播（v4）= 本网**所有**主机；组播 = **加入组**才收（IGMP/MLD） |
| **任播 vs 单播** | 单播一对一；任播**同 IP 多机**，路由选**最近**一台应答 |
| **IPv6 无广播** | 用 **`ff02::1`** 等组播替代 |

---

## 六、30 秒写卷子

**IPv4 必背三块私有**：`10/8`、`172.16/12`、`192.168/16` · 环回 `127/8` · 组播 `224/4` · APIPA `169.254/16`  
**IPv6**：环回 `::1` · 链路本地 `fe80::/10` · 组播 `ff00::/8` · 文档 `2001:db8::/32` · 映射 `::ffff:x.x.x.x`  
**无广播**：v6 用 `ff02::1`

---

## 七、自测（2 题）

1. `ff02::1` 与 `224.0.0.1` 分别等价于什么场景？  
2. `2001:db8::1` 能当公网服务器地址吗？

<details>
<summary>答案</summary>

1. **`ff02::1`**：IPv6 **链路本地所有节点**组播；**`224.0.0.1`**：IPv4 **本网段所有主机**组播（非广播）。  
2. **不能**。`2001:db8::/32` 为**文档专用**，公网不可路由。

</details>
