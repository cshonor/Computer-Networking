# 2.5 特殊用途地址

> 章级精读：[../study.md#ch02-5](../study.md#ch02-5) · 组播：[ch09](../../chapter09-broadcast-multicast/study.md)

## 本节核心目标

区分**私有/环回/组播/任播**等特殊块及 IPv4–IPv6 过渡地址。

---

## 分类速记

| 类型 | 要点 |
|------|------|
| **私有地址 (RFC1918)** | 10/8、172.16/12、192.168/16；内网 + NAT |
| **过渡机制** | NAT64、IPv4-mapped 等（与 [ch07 NAT](../../chapter07-firewall-nat/study.md) 联动） |
| **组播 Multicast** | 一对多；v4 **224.0.0.0/4**；v6 **ff00::/8**；ASM / SSM |
| **任播 Anycast** | 同址多机，路由到**拓扑最近**节点（DNS 根、CDN） |

---

## 易混

- **组播** vs **广播**：组播有组成员管理（IGMP/MLD）。
- **任播** vs **单播**：同 IP 多台设备，由路由选最近一台应答。
