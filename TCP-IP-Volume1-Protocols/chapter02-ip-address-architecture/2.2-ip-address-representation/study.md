# 2.2 表示 IP 地址

> 章级精读：[../study.md#ch02-2](../study.md#ch02-2)

## 本节核心目标

掌握 IPv4 / IPv6 的**书写规范**与常见表示陷阱。

---

## IPv4：点分四组

- **32 bit** → 4 字节，点分十进制，每段 **0–255**。
- 例：`165.195.130.107`。

---

## IPv6：块/字段

- **128 bit** → 8 组 **16 bit 十六进制**，组间 `:`。
- **零压缩**：连续全 0 组可用 **`::` 替代，且整条地址中仅能用一次**。
- **内嵌 IPv4**：末 32 bit 可写 IPv4 形式，便于过渡（如 `::ffff:192.0.2.1`）。

| 规则 | 说明 |
|------|------|
| `::` 次数 | **≤ 1** |
| 前导零 | 组内可省略（实现与 RFC 5952 书写建议见章级精读） |

---

## 易混考点

- 把 IPv6 当“更长 IPv4”背十进制 — 考试/抓包以 **十六进制块** 为准。
- `::` 用两次 → **非法** 表示。
