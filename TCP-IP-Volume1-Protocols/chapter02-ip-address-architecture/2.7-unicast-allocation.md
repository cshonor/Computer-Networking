# 2.7 单播地址分配

## 本节核心目标

理解 **单机 / 家庭 NAT+DHCP → 企业子网规划 → 多宿主高可用** 的单播分配逻辑；掌握 **PA / PI** 区别与适用场景。

<a id="ch02-7-unicast"></a>

## 一、单播地址基础（必考）

### 定义

**单播地址**：唯一标识**一个网络接口**，用于**一对一**通信（主机、服务器、路由器接口）。

→ 与广播/组播对比：[2.3 §二](./2.3-basic-ip-structure.md#ch02-unicast-vs-broadcast)

### IPv4 可用范围（历史分类，考试仍考）

| 类 | 范围（示意） |
|----|--------------|
| A | 1.0.0.0 – 126.255.255.255 |
| B | 128.0.0.0 – 191.255.255.255 |
| C | 192.0.0.0 – 223.255.255.255 |

**排除**：网络地址（主机位全 0）、广播（主机位全 1）、[私有/环回/组播](./2.5-special-address.md)。

> 现网编址以 **CIDR `/x`** 为准 → [2.4](./2.4-cidr-aggregation.md)

### IPv6 全球单播

- **全球路由前缀**：**`2000::/3`**
- 常见结构：**全球路由前缀(48) + 子网 ID(16) + 接口 ID(64)** → [2.3 IID](./2.3-basic-ip-structure.md#ch02-broadcast-iid)

<a id="ch02-7-scenarios"></a>

## 二、典型场景与分配做法

| 场景 | 地址 | 核心做法 |
|------|------|----------|
| **单主机** | 公网或私网 | **1 个单播地址 + 默认路由** |
| **家庭 LAN** | RFC1918 私有 | **NAT** + 路由器 **DHCP**（IP/掩码/网关/DNS） |
| **企业内网** | 私有 + 多子网 | **VLAN 划分子网**、**DHCP 池**、**路由汇总** |
| **企业外网** | **PA** 或 **PI** | 边界路由；单 ISP 常用 PA，多 ISP 常用 PI+BGP |

### 企业规划原则

- 内网：私有地址 + 分 VLAN 的 DHCP 池  
- 外网：PA/PI + 边界宣告  
- **连续网段、便于汇总、预留扩展**

<a id="ch02-7-multihoming"></a>

## 三、多宿主 Multihoming（重点）

### 定义

网络/边界路由器**同时接入多个 ISP** → **链路冗余、高可用、策略路由**。

### PA（Provider-Aggregatable，提供商可聚合）

| 项 | 说明 |
|----|------|
| 来源 | ISP 从**自家地址块**分给客户 |
| 特点 | **绑定 ISP**；换 ISP 常需**重编址/重宣告**；易聚合，**路由表压力小** |
| 适用 | 中小企业、单 ISP 为主 |

### PI（Provider-Independent，提供商独立）

| 项 | 说明 |
|----|------|
| 来源 | **RIR 直接分配**（见 [2.6](./2.6-address-allocation.md)），不属于某 ISP |
| 特点 | **可携带**（换 ISP 地址不变）；多 ISP **同时宣告同一前缀**；**难聚合、表项成本高** |
| 适用 | 大型企业、云厂商、关键业务 |

### 多宿主考点（必背）

| | 说明 |
|---|------|
| **解决** | **可用性/冗余**、策略选路 |
| **不解决** | 免费翻倍带宽（需 **ECMP/负载均衡** 设计） |
| **技术** | **BGP** 宣告、多链路、故障切换 |

## 四、速记对比表

| 场景 | 地址类型 | 核心做法 |
|------|----------|----------|
| 单主机 | 公网/私网 | 1 地址 + 默认网关 |
| 家庭 LAN | RFC1918 | NAT + DHCP |
| 企业内网 | 私有 | VLAN + DHCP + 汇总 |
| 企业外网 | PA / PI | 单 ISP（PA）/ 多 ISP（PI+BGP） |
| 多宿主 | **PI 首选** | 多 ISP + BGP 同一前缀 |

<a id="ch02-7-exam"></a>

## 五、易混 + 30 秒背诵

| 易混 | 纠正 |
|------|------|
| 单播 ≠ 公网 | **私有地址也是单播**，只是不能公网路由 |
| PA/PI | 只针对**公网单播**；内网无此区分 |
| 多宿主 ≠ 多网卡 | 主机多网卡 = 多归属主机；**多 ISP 接入** = 多宿主**网络** |

**背诵**：家庭私网+NAT+DHCP；企业划子网汇总；**PA 绑 ISP、PI 可携带**；多宿主靠 **BGP+PI**，为可用性不为白嫖带宽。

## 六、自测（2 题）

1. 小企业只连一家 ISP，一般用 PA 还是 PI？换 ISP 时地址通常怎样？  
2. 多宿主能否在不跑 BGP 的情况下让全球都按你的策略选路？

<details>
<summary>答案</summary>

1. 一般用 **PA**；换 ISP 往往要**换地址块或重新从新房主 ISP 宣告**（除非另有 PI）。  
2. **不能**。全球选路依赖 **BGP 宣告与运营商接受你的前缀**；无 BGP 至多本地冗余，无法保证全球一致策略。

</details>
