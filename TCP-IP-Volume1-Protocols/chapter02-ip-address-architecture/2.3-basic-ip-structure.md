# 2.3 基本的 IP 地址结构

> 章级精读：[../study.md#ch02-3](../study.md#ch02-3) · **一页速记**：[编址演进 + 广播/IID](./ip-addressing-evolution-cheatsheet.md)

## 本节核心目标

串起 **分类寻址 → 子网/VLSM → CIDR → IPv6**，并掌握 **IPv4 广播** 与 **IPv6 IID（EUI-64）**。

---

## 演进脉络（极简）

| 阶段 | 一句话 |
|------|--------|
| **分类 A/B/C/D/E** | 网络/主机边界**固定** → 浪费、路由表大 |
| **子网 + 掩码 (FLSM)** | 主机号划子网；**全网掩码相同** |
| **VLSM** | **同主网不同前缀**；点对点 /30，省地址 |
| **CIDR** | 无类 `IP/x` + **路由聚合** → [2.4](./2.4-cidr-aggregation.md) |
| **IPv6** | 128 位；**/64 + IID**；**无广播** |

→ 展开 + 自测：[ip-addressing-evolution-cheatsheet.md](./ip-addressing-evolution-cheatsheet.md#ch02-evolution)

---

## 广播（IPv4）

- **主机位全 1**（在给定掩码下）。
- **子网广播**：如 `192.168.1.255/24`。
- **受限广播**：`255.255.255.255`（**不跨路由**）。

→ 计算与对比：[速记卡 §二](./ip-addressing-evolution-cheatsheet.md#ch02-broadcast-iid)

---

## IPv6 接口标识（IID）

- 单播常见：**64 bit 前缀 + 64 bit IID**。
- **EUI-64**：MAC → 插 `FF:FE` → U/L 位取反。
- **隐私扩展**：随机 IID。
- IPv6 **无广播** → **`ff02::1`** 等组播替代。

---

## 易混

| 易混 | 纠正 |
|------|------|
| 子网掩码 vs `/x` | 同一语义两种写法 |
| VLSM vs FLSM | 可变长 vs 定长 |
| IPv4 广播 vs IPv6 | v6 **无广播**，用组播 |
| IPv4 兼容 `::1.2.3.4` | 已废弃 → 用 **`::ffff:x.x.x.x`** 映射 |
