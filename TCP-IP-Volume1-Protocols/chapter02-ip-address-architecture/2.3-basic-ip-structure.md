# 2.3 基本的 IP 地址结构

> 章级精读：[../study.md#ch02-3](../study.md#ch02-3) · 精编：[04 §4.3 有类/CIDR](../../../04_network_layer_data_plane/4.3_ipv4_ipv6_nat.md#ch4-3-classful)

## 本节核心目标

串起 **分类寻址 → 子网/VLSM** 的演进，并理解 IPv6 **IID / EUI-64**。

---

## 演进脉络

| 阶段 | 要点 |
|------|------|
| **分类寻址 (A/B/C/D/E)** | 网络号 + 主机号边界固定 → **浪费**、表项膨胀 |
| **子网 + 掩码** | 主机号再划子网，隔离广播域 |
| **VLSM** | 同一网络内**不同前缀长度**，灵活点对点/汇聚 |

---

## 广播与 IPv6 接口标识

- **广播地址**：主机位全 1（结合掩码计算网络/广播）。
- **IPv6 IID**：接口标识；常由 **EUI-64**（MAC 扩展）或隐私扩展生成。

---

## 易混

- **子网掩码** vs **前缀长度 /x**：同一语义两种写法。
- **VLSM** vs **FLSM**：可变长 vs 全网同一掩码。
