## 2.1 引言

### 战略背景

- IP 地址**屏蔽底层物理网络**（以太网、Wi-Fi 等）差异，类似电话号但**层级更强**。
- 从 ARPANET 到全球规模：需同时应对**地址枯竭**与**路由表爆炸（ROAD）**。

### 专业名词

| 术语 | 定义 |
|------|------|
| **IP 地址** | 分配给**网络接口**的逻辑标识；IPv4 **32 bit**，IPv6 **128 bit** |
| **路由器** | 网络层节点：维护路由表，按**目的 IP** 转发，互联异构网络 |

### 底层原理

- **寻址自治**：网络层地址**独立于 MAC**；拓扑变化不必换网卡 → Internet 可独立扩展。
- **DNS**：人机界面是域名；协议栈实际交互的是**数字 IP**（DNS 把意图映射为地址）。

## 2.2 表示 IP 地址

### IPv4：点分四组（Dotted-decimal）

32 bit → 4 字节，每字节十进制 **0–255**。  
→ 极简推导 + **3 道练习**：[2.2 §IPv4](./2.2-ip-address-representation.md#ch02-2-ipv4-dotted) · [练习](./2.2-ip-address-representation.md#ch02-2-ipv4-practice)

| 点分四组 | 二进制（示意） |
|----------|----------------|
| 0.0.0.0 | 全 0 |
| 1.2.3.4 | `00000001 00000010 00000011 00000100` |
| 10.0.0.255 | … |
| 165.195.130.107 | … |
| 255.255.255.255 | 全 1 |

### IPv6：块/字段（Chunks）

128 bit → **8 块 × 16 bit**，十六进制，冒号分隔。  
→ 极简 + **4 道练习**：[2.2 §IPv6](./2.2-ip-address-representation.md#ch02-2-ipv6-chunks) · [练习](./2.2-ip-address-representation.md#ch02-2-ipv6-practice)

### IPv6 规范化（RFC 5952）

1. **省略前导零**：`00ad` → `ad`
2. **`::` 压缩**：连续全零块用 `::` 替代 — **全地址仅允许一次 `::`**，优先压缩最长/最左全零块
3. **十六进制小写**：`a–f` 用小写
4. **IPv4 映射**：`::ffff:192.168.1.1` — 前 80 bit 为 0，次 16 bit 为 `ffff`，后 32 bit 为 IPv4

| 十六进制示例 | 说明 |
|--------------|------|
| `5f05:2000:80ad:5800:58:800:2023:1d71` | 完整单播示例 |
| `::1` | 环回 |
| `::ffff:1.2.240.1` | IPv4 映射 |

### 常见错误

- **`::` 不能用两次** → 重组歧义。
- **IPv4 兼容地址** `::1.2.3.4` 已废弃（RFC 4291）→ 用 **IPv4 映射** `::ffff:x.x.x.x`。

**Go/Rust**：`net.ParseIP`、`std::net::IpAddr`；输出 IPv6 时注意规范化库行为。

## 2.3 基本 IP 地址结构

> 演进 + 广播/IID 背诵：[ip-addressing-evolution-cheatsheet.md](ip-addressing-evolution-cheatsheet.md)

### 2.3.1 分类寻址（Classful，历史）

按**固定高位**划分五类（现已由 CIDR 取代，考试仍考）：

| 类 | 固定高位 | 地址范围（示意） | 网络号位数 | 主机数（约） |
|----|----------|------------------|------------|--------------|
| **A** | `0` | 0.0.0.0 – 127.x | 8 bit | ~16M |
| **B** | `10` | 128.0 – 191.255 | 16 bit | ~65K |
| **C** | `110` | 192.0 – 223.255 | 24 bit | 254 |
| **D** | `1110` | 224.0 – 239.255 | — | 组播 |
| **E** | `1111` | 240.0 – 255.255 | — | 保留/实验 |

### 2.3.2 子网寻址

从**主机号**中「借位」作**子网号**；对外仍是一个主网络，站内用掩码细分。

### 2.3.3 子网掩码（Subnet Mask）

**IP AND 掩码** → 提取网络/子网前缀。

**IPv4 掩码示例**

| 点分十进制 | 十六进制 | 前缀 |
|------------|----------|------|
| 128.0.0.0 | 0x80000000 | /1 |
| 255.0.0.0 | 0xFF000000 | /8 |
| 255.255.0.0 | 0xFFFF0000 | /16 |
| 255.255.255.0 | 0xFFFFFF00 | /24 |
| 255.255.255.252 | 0xFFFFFFFC | /30 |

**IPv6 掩码示例**

| 高 64 bit | 低 64 bit | 前缀 |
|-----------|-----------|------|
| ffff:ffff:ffff:ffff | 0…0 | /64 |
| ff00:…0 | 0…0 | /8 |

### 2.3.4 VLSM（可变长子网掩码）

同一自治系统内，不同链路可用**不同前缀长度**。

| 特性 | FLSM（固定长度） | VLSM |
|------|------------------|------|
| 灵活性 | 低（子网同规模） | 高（按主机数定制） |
| 浪费 | 严重（点对点占 /24） | 低（点对点 /30、/31） |
| 路由协议 | RIPv1 等 | **OSPF、IS-IS、BGP** 等无类别协议 |

### 2.3.5 广播地址

| 类型 | 形式 | 行为 |
|------|------|------|
| **定向广播** | 主机位全 1（如 x.x.x.255/24） | 子网内所有主机 |
| **受限广播** | 255.255.255.255 | **仅本地链路**，路由器不转发 |

### 2.3.6 IPv6 与接口标识符（IID）

单播地址常 **/64 前缀 + 64 bit IID**。

**EUI-48 → EUI-64（从 MAC 生成 IID）**

1. 48 bit MAC 拆为两个 24 bit 块  
2. 中间插入 **FF:FE**  
3. 第 1 字节 **第 7 位（u 位）取反**（全局/本地语义）

## 2.4 CIDR 与聚合

### 背景：ROAD 问题

- **B 类地址枯竭**
- **路由表条目**激增

### CIDR 核心

- **取消 A/B/C 固定类界**
- 前缀长度 **0–32** 任意（记法 `a.b.c.d/x`）
- **路由聚合（超网）**：多条同下一跳前缀合并为更短前缀 → 减轻核心路由器负担

### 拓扑敏感分配（图 2-8 文字复刻）

```text
A) 随机分配（难聚合）              B) 拓扑敏感（易聚合）
核心表：多条 /24 → 不同路由器       核心表：一条 /22 → 聚合路由器
  190.154.27.0/24 → R1                190.154.24.0/22 → R_AGG
  190.154.24.0/24 → R5                    ├─ .24.0/24
  190.154.25.0/24 → R3                    ├─ .25.0/24
  190.154.26.0/24 → R2                    ├─ .26.0/24
                                          └─ .27.0/24
```

## 2.5 特殊用途地址（必背）

### IPv4（表 2-7 精要）

| 地址块 | 用途 |
|--------|------|
| 0.0.0.0/8 | 本网络「本主机」 |
| **10.0.0.0/8** | 私有 |
| **127.0.0.0/8** | 环回 |
| **169.254.0.0/16** | 链路本地（APIPA） |
| **172.16.0.0/12** | 私有 |
| **192.168.0.0/16** | 私有 |
| 224.0.0.0/4 | 组播 |
| 255.255.255.255/32 | 受限广播 |

### IPv6（表 2-8 精要）

| 前缀 | 用途 |
|------|------|
| ::/128 | 未指定 |
| **::1/128** | 环回 |
| ::ffff:0:0/96 | IPv4 映射 |
| 2001:db8::/32 | 文档示例 |
| **fe80::/10** | 链路本地 |
| ff00::/8 | 组播 |

**Go/Rust**：`10.x` / `192.168.x` 内网；`127.0.0.1` 环回；容器/K8s 大量 `/24`、`/16` 规划。

## 2.6 全球分配与 WHOIS/RDAP

**层级（必背）**：**IANA → RIR（APNIC/ARIN/RIPE/LACNIC/AFRINIC）→ LIR/ISP → 用户**；IANA **不直分用户**；**APNIC = 亚太含中国**。

**溯源**：**WHOIS**（文本）· **RDAP**（HTTPS+JSON，**优先**）→ 归属、abuse、**BGP Origin ASN**。

**常考**：**分得前缀 ≠ 全球可达** → 须 ISP **BGP 宣告/聚合**。

→ 展开 + 自测：[2.6-address-allocation.md](2.6-address-allocation.md)

## 2.7 单播地址分配与策略（站点/多宿主）

| 场景 | 连通性 | 地址来源 | 聚合与韧性 |
|------|--------|----------|------------|
| 单 ISP、单网络 | 单归属 | ISP 分配 | 聚合好，无冗余 |
| 单 ISP、多网络 | 单归属 | ISP 地址块 | 聚合好，管理灵活 |
| 多 ISP、多网络 | **多宿主** | PI 或多厂商地址 | 韧性高，**全球 BGP 表压力**大 |

- **PI（Provider Independent）**：企业自有前缀进全球表 → 可用性↑、表项↑。

## 2.8 与 IP 地址相关的攻击

| 攻击 | 原理 |
|------|------|
| **IP 欺骗** | 路由器按**目的**转发，源地址可伪造 |
| **DoS** | 伪造大量源 → 响应耗尽目标；溯源难 |
| **扫描/嗅探** | ICMP、TCP/UDP 探测活跃主机 |

**防御**：网络层无内在源认证 → **BCP 38 入站过滤**（uRPF 等）等补丁式方案。→ [ch18 安全](../chapter18-network-security/study.md)

## 2.9 总结与考点

### 演进脉络

**僵化分类** → **子网/VLSM** → **CIDR 聚合**；IPv4 延寿，IPv6 以海量空间 + RFC 5952 + /64 分层应对物联网规模。

### 考点速记

| 主题 | 要点 |
|------|------|
| 表示 | IPv4 点分四组；IPv6 `::` **仅用一次** |
| 掩码 | AND 得前缀；**/x** 与点分掩码等价表述 |
| VLSM vs FLSM | 可变长 vs 固定长；点对点用 **/30、/31** |
| CIDR | 无类前缀 + **路由聚合** 解 ROAD |
| 分配层级 | IANA→RIR→ISP→用户；**分配≠BGP可达** |
| WHOIS/RDAP | 归属/abuse/路由；**RDAP 优先** |
| 私有地址 | 10/8、172.16/12、192.168/16 |
| 多宿主 | 高可用 vs 全球路由表膨胀 |

### 易混

1. **MAC vs IP**：L2 vs L3，ARP 做映射（[ch04 ARP](../chapter04-arp-protocol/study.md)）  
2. **定向广播 vs 255.255.255.255**  
3. **IPv4 兼容 vs IPv4 映射**  
4. **DNS 名 ≠ 1 个 IP**（负载均衡、CDN）
