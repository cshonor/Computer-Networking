# 5.5 移动 IP（Mobile IP）

> 章级精读：[study.md#ch05-5](./study.md#ch05-5) · 间接交付：[ch04 §4.2](../chapter04-arp-protocol/4.2-arp-basic-operation.md#ch04-2) · IP 隧道：[ch03 §3.9](../chapter03-link-layer/3.9-tunnel-basics.md) · IPv6 路由头：[5.3](5.3-ipv6-extension-headers.md#ch05-3-types)

## 本节核心目标

理解移动 IP 的 **MN / HA / CoA** 三角角色、**间接寻址（indirection）** 与 **IP 隧道**转发机制，以及与现代 **LTE / PMIPv6** 的关系。

<a id="ch05-5"></a>

---

<a id="ch05-5-roles"></a>

## 一、核心角色

| 术语 | 全称 | 作用 |
|------|------|------|
| **MN** | 移动节点（Mobile Node） | 可跨网络漫游的终端；对外**固定使用家乡地址**通信 |
| **HA** | 家乡代理（Home Agent） | 部署在 MN **家乡网络**；流量**锚点**；维护 MN 位置映射 |
| **CoA** | 转交地址（Care-of Address） | MN 接入**外地网络**时获得的**临时 IP**；标识当前物理位置 |

```text
通信方 ──(目的=家乡地址)──► 家乡网络 ──► HA 截获
                                              │
                                    IP 隧道封装（外层目的=CoA）
                                              ▼
                                         MN @ 外地网络
```

---

<a id="ch05-5-design"></a>

## 二、核心设计思路

| # | 要点 |
|---|------|
| 1 | **通信地址不变**：无论 MN 漫游到哪，对外始终用**家乡地址** → 上层应用**无感知** |
| 2 | **流量转发机制**：HA 与 MN 间建立**双向 IP 隧道** → 往来流量经隧道转发至 MN 当前 **CoA** |
| 3 | **核心思想**：**地址间接寻址（indirection）** — 屏蔽终端网络位置变化 |

**与常规路由对比**：正常 IP 寻址 = 目的地址即物理可达位置；Mobile IP = 目的地址**固定在家乡**，真实位置由 **CoA + 隧道**间接到达。

→ 隧道封装：[ch03 §3.9 隧道基础](../chapter03-link-layer/3.9-tunnel-basics.md)

---

<a id="ch05-5-flow"></a>

## 三、基础工作流程

| # | 步骤 |
|---|------|
| 1 | MN 在**外地网络**上线，获取本地 **CoA**，向 **HA 注册**当前 CoA |
| 2 | HA 记录映射：**家乡地址 ↔ CoA** |
| 3 | 通信方发往 MN **家乡地址**的报文，路由至家乡网络，由 **HA 截获** |
| 4 | HA 将报文**封装进 IP 隧道**（如 IP-in-IP），外层目的 = **CoA**，转发至外地 |
| 5 | MN **回程**报文可**直连**通信方，或同样经隧道回传（**双向隧道**） |

### 咖啡馆案例（MN 离开公司）

1. MN 在外地通过 DHCP 获 **CoA**，向 **HA** 注册  
2. 外部仍发往 MN **原 IP（家乡地址）** 的包被 **HA** 拦截  
3. HA **IP-in-IP 隧道**封装，外层目的 = **CoA** → MN 在外地收到内层原报文

<a id="ch05-5-compare"></a>

## 四、易混：Wi-Fi 漫游 vs Mobile IP

| | **Wi-Fi 漫游** | **Mobile IP** |
|---|----------------|---------------|
| **层次** | 常 **L2**（同一 ESS 内切换） | **L3** 跨网段/跨运营商 |
| **地址** | 可能换 IP（视 DHCP） | **家乡地址不变** |
| **目标** | 链路层连续覆盖 | **会话不因换网中断**（理想模型） |

---

<a id="ch05-5-modern"></a>

## 五、补充说明 & 现代演进

| 点 | 说明 |
|----|------|
| **本质** | **代理 + 隧道** → IP 地址与物理接入网络**解耦** |
| **模型定位** | 本书**基础概念模型** — 理解 **indirection** 的核心 |
| **现代实践** | 蜂窝/Wi-Fi 漫游多不再单纯用传统 Mobile IP；主流 **LTE 切换、PMIPv6（代理移动 IPv6）** 等增强方案 |

→ PMIPv6 思想：网络侧代理（类似 HA 角色）替终端维护绑定，减轻 MN 负担。

<a id="ch05-5-cellular"></a>

## 六、实例：手机蜂窝跨省漫游（对照模型）

用**湖北手机号出省上网**理解课本 Mobile IP — 好记、也对应考点。

### 1. 理论对应（Mobile IP ↔ 手机漫游）

| 移动 IP | 手机漫游（例：湖北卡） |
|---------|------------------------|
| **MN** 移动节点 | **手机** |
| **家乡网络** | **湖北**运营商网络（归属地） |
| **家乡地址** | 运营商分配、**逻辑归属湖北**的 IP / 用户身份 |
| **HA** 家乡代理 | 湖北运营商核心网关 / **漫游锚点** |
| **外地网络** | 出差所在**外省**基站网络 |
| **CoA** 转交地址 | 在外省基站拿到的**本地临时 IP** |

### 2. 网络层面（全国通用流量时代）

| # | 步骤 |
|---|------|
| 1 | 到外省，手机连当地基站 → 获**本地 CoA 临时 IP** |
| 2 | 当地基站将位置、临时 IP 上报**归属地（湖北）漫游锚点**（≈ **HA**） |
| 3 | 外网数据 → 先路由到**湖北归属网络** → 归属地**隧道封装** → 转发至当前外省 **CoA** |

```text
外网 ──► 湖北归属网(HA) ──隧道──► 外省 CoA ──► 手机(MN)
```

**一句**：工程上就是 Mobile IP 的 **间接寻址 + 隧道转发**（实现多为 **LTE/5G / PMIPv6** 类架构，非 RFC 3344 原教旨）。

### 3. 流量计费 & 归属（常问）

| 项 | 现行（三大运营商主流） |
|----|------------------------|
| **全国通用流量** | 在湖北或**任意省份**使用，**统一扣套餐通用流量**，**无额外漫游费** |
| **不存在** | 「到外地单独算一种漫游流量费」（早年规则已取消） |

| 对比 | 早年 | 现在 |
|------|------|------|
| 套餐 | **省内流量** + **国内漫游流量** 分开；出省优先扣漫游，用完加价 | 多数套餐标注**全国通用** |
| 老套餐残留 | — | 少数仍有**省内专属流量** → 出省**不能用省内包**，自动走**全国通用** |

### 4. IP 表现小细节

| 观察 | 说明 |
|------|------|
| **公网 IP 归属地** | 人在外地，上网 IP 常显示为**当前省份**出口（用当地 CoA/当地 PGW） |
| **账号 / 资费归属** | 仍是**湖北**（归属地不变）→ 对应「**逻辑家乡地址 / 身份不变**」 |

### 5. 串起来（考点）

| # | 要点 |
|---|------|
| 1 | 手机漫游 = **工程化 Mobile IP**：位置变（**CoA 变**），归属身份 / 逻辑地址**不变** |
| 2 | 运营商核心网 **HA 锚点 + 隧道** → 无缝上网 |
| 3 | 资费：**国内无跨省流量漫游额外收费**（通用流量全国通） |
| 4 | 协议演进：**PMIPv6、LTE/5G 代理移动** — 思想同课本，实现更轻量 |

**一句话**：湖北卡去外地上网，扣套餐**全国流量**不加漫游费；网络上靠运营商**漫游隧道**转发，与课本 Mobile IP **逻辑一致**。

<a id="ch05-5-cheat"></a>

## 七、速记要点

| # | 要点 |
|---|------|
| 1 | 三大角色：**MN**（终端）、**HA**（家乡锚点）、**CoA**（临时地址） |
| 2 | **家乡地址永久不变**，靠 **隧道 + CoA** 完成漫游转发 |
| 3 | 底层逻辑：**间接寻址（indirection）** |
| 4 | 现代：**LTE / PMIPv6** 演进；本节抓**概念模型** |

| 易错 | 正确 |
|------|------|
| CoA 是对外通信地址 | 对外仍是**家乡地址**；CoA 仅**当前位置** |
| HA 转发所有回程流量 | 回程常可**直连**；入向经 HA 隧道 |
| 手机 4G/5G = 传统 Mobile IP | 多为 **LTE/PMIPv6** 等，概念相通实现不同 |
| 出省上网加漫游流量费 | 现行**全国通用流量**统一扣费，**无额外漫游费**（见 [§六 蜂窝实例](5.5-mobile-ip-basic.md#ch05-5-cellular)） |

---

## 疑问与总结

**背：MN+HA+CoA；家乡地址不变；HA 隧道到 CoA；indirection。**
