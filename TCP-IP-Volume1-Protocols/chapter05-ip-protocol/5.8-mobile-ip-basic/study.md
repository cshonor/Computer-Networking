# 5.5 移动 IP

> 章级精读：[../study.md#ch05-5](../study.md#ch05-5)

## 本节核心目标

理解漫游时如何保持对**家乡地址**的可达（概念模型）。

---

## 角色

| 术语 | 角色 |
|------|------|
| **MN** 移动节点 | 漫游的设备 |
| **HA** 家乡代理 | 锚定家乡网络 |
| **CoA** 转交地址 | 当前外地网络上的 care-of 地址 |

---

## 思路

- 对通信方始终使用 **家乡 IP**。
- 数据经 **双向 IP 隧道** 送到当前 **CoA**，MN 在外地网络接入。

---

## 实践注记

- 蜂窝/Wi‑Fi 切换现代多结合 **LTE/PMIPv6** 等；本书模型是理解** indirection** 的基础。
