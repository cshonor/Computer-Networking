# 5.1 引言

> 章级精读：[../study.md#ch05-1](../study.md#ch05-1) · 上一章：[ch04 ARP](../../chapter04-arp-protocol/study.md)

## 本节核心目标

明确 **IP** 在 TCP/IP 中的核心地位与服务语义。

---

## 核心要点

| 特性 | 含义 |
|------|------|
| **无连接** | 不维护 per-flow 状态 |
| **尽力而为** | 不保证送达、不保证顺序、不保证无重复 |
| 出错/拥塞 | 常**丢弃**；可能回 **ICMP** 给上层 |

---

## 与传输层分工

- **可靠性、重传、拥塞控制** → TCP 等端系统（[ch01 端到端](../../chapter01-overview/study.md#ch01-e2e)）。
- IP 提供**统一寻址 + 逐跳转发**的“细腰”。
