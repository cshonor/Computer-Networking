# 5.6 IP 数据报的主机处理

> 章级精读：[../study.md#ch05-6](../study.md#ch05-6)

## 本节核心目标

区分**强/弱主机模型**与 IPv6 **源/目的地址选择**。

---

## 强主机 vs 弱主机

| 模式 | 接收规则（简化） |
|------|------------------|
| **强主机** | 目的 IP 必须属于**接收接口**的地址 |
| **弱主机** | 目的 IP 属于本机**任一接口**即可收 |

- 影响多网卡、VPN、环回场景下的**是否接受**入包。

---

## IPv6 地址选择（RFC 6724 思想）

- 多地址、多前缀时，出站需选**合适源地址**与**目的地址**（范围、策略、临时地址隐私等）。
- 开发跨 v6 接口服务时注意 **bind** 与策略路由。

---

## Go/Rust

- 多 `Interface` 时显式指定出站接口或源 IP，避免内核选错源。
