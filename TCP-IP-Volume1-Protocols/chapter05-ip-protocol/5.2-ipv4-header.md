# 5.2 IPv4 头部和 IPv6 头部

> 章级精读：[../study.md#ch05-2](../study.md#ch05-2) · 精编：[04 §4.3 IPv6](../../../top_down/04_network_layer_data_plane/4.3_ipv4_ipv6_nat.md#ch4-3-ipv6) · 扩展头：[5.3](5.3-ipv6-extension-headers.md)

## 本节核心目标

对比 **IPv4 可变头** 与 **IPv6 固定 40 字节头** 的核心字段。

---

## IPv4（基础 ≥ 20 B，可有选项）

| 字段 | 作用 |
|------|------|
| **TTL** | 每跳减 1，防环路 |
| **TOS / DS+ECN** | 旧服务类型；现多作 **DSCP/ECN** |
| **头部校验和** | 仅校验 IP 头 |
| **标识 / 偏移 / DF** | **分片** 控制（v6 主路径不用） |

---

## IPv6（固定 40 B）

| 变化 | 说明 |
|------|------|
| 去掉 | 头校验和、中间分片（**仅源分片**） |
| 新增 | **流标签 Flow Label**（QoS/流区分） |
| 扩展 | 选项移至 **扩展头** 链 → [5.3](5.3-ipv6-extension-headers.md) |

---
