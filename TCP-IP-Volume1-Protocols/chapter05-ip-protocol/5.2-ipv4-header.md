## Protocol 字段（三层 → IP 载荷分用）

| 项 | 说明 |
|----|------|
| **位置** | IPv4 首部 **第 9 字节**（TTL 与首部校验和之间） |
| **作用** | 标明 **IP 载荷**是 ICMP、TCP 还是 UDP |
| **与 EtherType 区别** | EtherType 管 **二层→三层**；Protocol 管 **三层→内层** — **口诀：二层定三层，三层定内层** |

| 值 | 载荷 | 层次 |
|----|------|------|
| **1** | **ICMP** | 网络层（须封装在 IP 内，**不写进 EtherType**） |
| **6** | **TCP** | 传输层 |
| **17** | **UDP** | 传输层 |

IPv6 用 **Next Header** 承担同类职责（ICMPv6 = **58**；含扩展头链 → [5.3](5.3-ipv6-extension-headers.md)）。

**ICMP 分两步识别**（收包）：`EtherType 0x0800` → 只知 IPv4 → `Protocol = 1` → 才知 ICMP → [ch01 §ICMP 分用](../chapter01-overview/study.md#ch01-layering-icmp) · [ch08](../chapter08-icmpv4-icmpv6/8.1-introduction.md#ch08-1-demux)

→ 完整分层分用：[ch01 §分用](../chapter01-overview/study.md#ch01-layering) · EtherType：[ch03 §3.2](../chapter03-link-layer/3.2-ethernet-ieee802-encapsulation.md#ch03-2-ethertype-vs-protocol)

## IPv4（基础 ≥ 20 B，可有选项）

| 字段 | 作用 |
|------|------|
| **TTL** | 每跳减 1，防环路 |
| **TOS / DS+ECN** | 旧服务类型；现多作 **DSCP/ECN** |
| **头部校验和** | 仅校验 IP 头 |
| **标识 / 偏移 / DF** | **分片** 控制（v6 主路径不用） |

---

## IPv6（固定 40 B）

| 变化 | 说明 |
|------|------|
| 去掉 | 头校验和、中间分片（**仅源分片**） |
| 新增 | **流标签 Flow Label**（QoS/流区分） |
| 扩展 | 选项移至 **扩展头** 链 → [5.3](5.3-ipv6-extension-headers.md) |
