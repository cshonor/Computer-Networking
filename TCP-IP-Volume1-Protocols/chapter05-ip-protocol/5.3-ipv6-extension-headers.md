# 5.3 IPv6 扩展头部

> 章级精读：[../study.md#ch05-3](../study.md#ch05-3)

## 本节核心目标

理解 IPv6 **菊花链（daisy-chaining）** 扩展头与 **Next Header** 字段。

---

## 设计思想

- 主头 **40 B 固定** → 主干路由器默认解析极快。
- 偶尔功能（路由、分片、**ESP** 等）放在**扩展头**，按链串联。

---

## 常见扩展头（示意）

| 类型 | 用途 |
|------|------|
| 路由头 | 源路由 / 严格路由列表 |
| 分片头 | **仅源节点**分片时使用 |
| **ESP** | IPsec 载荷加密 → [ch18](../../chapter18-network-security/study.md) |

```text
IPv6 主头 → Next Header → 扩展头1 → … → UDP/TCP/ICMPv6
```

---

## 考点

- 扩展头**按需出现**；无选项的主路径转发开销低。
