# 6.1 — link layer service

## 知识点速记

- **帧**：网络层 PDU 在每跳封装为链路层帧。  
- **服务**：成帧、链路接入（MAC）、差错检测、（可选）可靠与流控。  
- **实现位置**：**NIC / 适配器** 固件与硬件。  
- **与 TCP 对比**：逐跳 vs 端到端可靠。

## 与后端开发的联系

- 容器网络 veth、VXLAN、MTU/MSS；性能问题常卡在**链路 MTU、offload、RSS**。
