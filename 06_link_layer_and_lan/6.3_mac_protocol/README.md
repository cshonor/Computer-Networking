# 6.3 — mac protocol

## 知识点速记

- **共享媒介**：需 MAC 协调，避免/处理碰撞。  
- **划分 vs 随机**：TDM/FDM/CDMA vs CSMA/CD、CSMA/CA。  
- **DOCSIS**：频分 + 上行时隙与随机接入结合的接入网范例。

## 与后端开发的联系

- Wi‑Fi 空口竞争、有线接入网的时延抖动来源理解。
