# 21.4 关于隐私的考虑

> 本章：[chapter-summary.md](./chapter-summary.md#ch21-4) · [ch11 Cookie](../chapter-11-client-id-cookie/chapter-summary.md)

## 本节核心目标

认识 HTTP 日志的**隐私风险**与管理准则。

---

<a id="ch21-4-risk"></a>

## 信息滥用风险

日志可还原：

- 用户常访站点  
- **Referer** 来源链  
- 访问时间段  

滥用可能导致歧视、骚扰、勒索。

---

<a id="ch21-4-transparency"></a>

## 透明度缺失

对终端用户，HTTP 日志记录通常是**不可见**的 — 用户往往在不知情下留下行为轨迹。

---

<a id="ch21-4-guidelines"></a>

## 管理准则

| 原则 | 说明 |
|------|------|
| **明确管控** | 收集与使用行为日志须有安全策略 |
| **事先告知** | 工作场所等**必须监视**的环境应公示并获授权 |
| **最小化** | 只保留必要字段与留存期 |

---

## 拓展（预留）

- **GDPR**、**CCPA** 对 IP、Cookie 标识、Referer 的匿名化与留存期限  
- 日志脱敏与 **PII** 分类
