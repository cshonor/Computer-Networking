## 本节核心目标

弄清服务器/代理**为何记日志**、记什么、为何不记全量首部。

---

<a id="ch21-1-purpose"></a>

## 记录目的

| 用途 | 说明 |
|------|------|
| **排障** | 错误检测、定位 4xx/5xx |
| **统计** | 容量规划、流量趋势 |
| **安全** | 入侵追踪、异常访问 |
| **计费** | 商业计量、带宽/请求计费 |

→ 服务器七步模型最后一步：[ch05.10](../chapter-05-web-server/10-logging.md)

---

<a id="ch21-1-minimal"></a>

## 精简记录

若记录**全部首部**，日处理数百万事务时数据量**失控**。

原则：只记**真正需要**的基本信息 — 一行摘要 per 事务。

---

<a id="ch21-1-fields"></a>

## 常见字段

| 字段 | 含义 |
|------|------|
| **HTTP 方法** | GET、POST 等 |
| **客户端/服务器版本** | HTTP/1.1 等 |
| **请求 URL** | 资源标识 |
| **状态码** | 200、404 等 |
| **报文尺寸** | 响应字节数（有时含请求体大小） |
| **时间戳** | 事务发生时刻 |
| **`Referer`** | 来源页 |
| **`User-Agent`** | 客户端软件标识 |
