# 2.3 URL 快捷方式（二）自动扩展

## 本节核心目标

了解浏览器**自动补全/扩展**不完整输入的机制及与**代理**的冲突。

---

<a id="ch02-3-auto"></a>

## 一、主机名扩展（Hostname Expansion）

用户只输入一个词（如 `joes`），浏览器可能自动加：

- 前缀 **`www.`**  
- 后缀 **`.com`**（或本地 TLD 习惯）  

→ 尝试 `http://www.joes.com/`

---

## 二、历史扩展（History Expansion）

根据**访问历史**做前缀匹配、自动补全地址栏。

现代 **Omnibox** 还会混合：书签、搜索建议、历史（算法各浏览器不同）。

---

## 三、易错：与代理配合

| 场景 | 问题 |
|------|------|
| **显式配置代理** | 浏览器可能**不做**主机名/历史扩展，把**缩略词原样**交给代理 |
| 结果 | 代理无法解析 → **失败** |

排障：区分「直连浏览器智能补全」与「代理后裸字符串」。
