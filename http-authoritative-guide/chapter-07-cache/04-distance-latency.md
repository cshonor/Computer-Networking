# 7.4 距离时延

> 本章：[chapter-summary.md](./chapter-summary.md#ch07-4) · [ch04 TCP 时延](../chapter-04-connection-management/01-connection-desire.md)

## 本节核心目标

理解**光速 + 路由器跳数**带来的 RTT，以及**就近缓存**如何缩短距离。

---

<a id="ch07-4-physics"></a>

## 一、物理下限

即使带宽无限，仍有：

- **光速**往返（例：波士顿↔旧金山 ~30 ms RTT）  
- 每跳**路由器处理**时延  

---

<a id="ch07-4-math"></a>

## 二、叠加示例（书）

一页 **20 张图**、**4 条并行连接**：

| 源站位置 | 仅光速 RTT 叠加量级 |
|----------|---------------------|
| 旧金山 | ~240 ms |
| 东京 | ~600 ms |

---

<a id="ch07-4-fix"></a>

## 三、对策

缓存部署在**用户附近** → 距离从数千英里 → 几十米，**大幅削减距离时延**。
