# 7.5 命中和未命中的

> 本章：[chapter-summary.md](./chapter-summary.md#ch07-5) · [ch03 状态码](../chapter-03-http-message/04-status-code.md)

## 本节核心目标

区分 **Hit / Miss / 再验证**，以及 **文档命中率 vs 字节命中率**。

---

<a id="ch07-5-basic"></a>

## 一、三种结果

| 类型 | 说明 |
|------|------|
| **Cache Hit** | 本地副本直接服务 |
| **Cache Miss** | 无副本，向**源站**取 |
| **Revalidation** | 过期/需核对，向源站**条件请求** |

---

<a id="ch07-5-reval"></a>

## 二、再验证（7.5.1）

| 源站响应 | 含义 |
|----------|------|
| **`304 Not Modified`** | 内容未变，更新新鲜度后本地提供 → **缓慢命中** |
| **`200 OK` + 新 body** | 内容已变 → 更新缓存 |
| **`404`** | 对象删除 → 缓存删除副本 |

→ 详 [7.8](./08-freshness-revalidation.md)

---

<a id="ch07-5-metrics"></a>

## 三、命中率指标

| 指标 | 含义 |
|------|------|
| **文档命中率（Hit Rate）** | 缓存服务的**请求数**占比；~**40%** 已算不错 |
| **字节命中率（Byte Hit Rate）** | 缓存提供的**字节**占比；反映**带宽**节省 |

文档命中率优化**固定开销**（如 TCP 握手）；字节命中率优化**大文件传输**。

---

<a id="ch07-5-detect"></a>

## 四、如何猜是否来自缓存

`200 OK` **无法区分**缓存 vs 源站。

| 首部 | 线索 |
|------|------|
| **`Date`** | 若明显偏旧，可能是缓存副本时间 |
| **`Age`** | 响应已在缓存/路径中「变老」的秒数 |
