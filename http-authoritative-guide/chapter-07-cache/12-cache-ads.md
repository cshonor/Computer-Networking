# 7.12 缓存和广告

> 本章：[chapter-summary.md](./chapter-summary.md#ch07-12) · [ch21 日志](../chapter-21-log-tracking/chapter-summary.md)

## 本节核心目标

理解缓存与 **PV/广告计费** 的冲突及 **Meter（RFC 2227）** 思路。

---

<a id="ch07-12-dilemma"></a>

## 7.12.1 广告商两难

热点被代理缓存 **10 万次** → 源站日志可能只 **1 次** → **按点击/PV 计费**收入受损。

---

<a id="ch07-12-busting"></a>

## 7.12.2 发布者反击（Cache Busting）

- URL 加**动态参数**  
- 强制 **不可缓存**  

→ **摧毁缓存效益**，网络更拥塞。

---

<a id="ch07-12-logs"></a>

## 7.12.3 日志迁移

缓存运营商把**命中日志**回传源站 — 体积大、格式乱、隐私与认证难，难自动化成熟。

---

<a id="ch07-12-meter"></a>

## 7.12.4 Meter 首部（RFC 2227）

| 机制 | 说明 |
|------|------|
| **`Meter` 扩展** | 缓存周期性汇报某 URL **命中次数** |
| 服务器可限 | 汇报前最多服务 N 次命中 |

调和 **提速** 与 **精确计数**。
