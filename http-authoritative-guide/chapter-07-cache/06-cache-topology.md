# 7.6 缓存的拓扑结构

> 本章：[chapter-summary.md](./chapter-summary.md#ch07-6) · [ch06 代理层次](../chapter-06-proxy/03-proxy-placement.md#ch06-3-hierarchy)

## 本节核心目标

区分**私有/公有缓存**、**父子层次**与**网状/对等**架构。

---

<a id="ch07-6-private"></a>

## 7.6.1 私有缓存

- 单用户（浏览器**临时文件**、磁盘/内存）  
- 算力/容量要求低  

---

<a id="ch07-6-public"></a>

## 7.6.2 公有代理缓存

- **共享代理**，汇聚多用户相同 URL  
- 最大化去冗余 → [ch06](../chapter-06-proxy/chapter-summary.md)

---

<a id="ch07-6-hierarchy"></a>

## 7.6.3 代理缓存层次

```text
客户端 → 子缓存（小/近）→ 父缓存（大/远）→ 源站
```

**易错**：链路过深 → 延迟与处理开销大；实践常 **≤2～3 跳**。

---

<a id="ch07-6-mesh"></a>

## 7.6.4 网状、内容路由、对等

| 概念 | 说明 |
|------|------|
| **内容路由器** | 按 URL 选父缓存或直连源站 |
| **兄弟缓存（Sibling）** | 同层互访内容；HTTP 本身不够，靠 **ICP / HTCP** |
