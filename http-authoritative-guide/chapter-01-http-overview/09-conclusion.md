## 第一章主线回顾

| 主题 | 一句话 |
|------|--------|
| **定位** | 因特网多媒体的**应用层公共语言** |
| **角色** | 客户端请求 ↔ 服务器资源 |
| **资源** | 静态/动态 + MIME + URI/URL |
| **事务** | 方法 + 状态码；一页多对象 |
| **报文** | 起始行 / 首部 / 空行 / body |
| **连接** | TCP + DNS + 端口 80 |
| **版本** | 以 **HTTP/1.1** 为主干 |
| **组件** | 代理、缓存、网关、隧道、Agent |
