# 1.10 更多信息

> 本章：[chapter-summary.md](./chapter-summary.md#ch01-10)

## 本节核心目标

知道查 **HTTP/URI 规范** 时从哪些 RFC 入手（含后续取代关系）。

---

## 书中索引的 RFC

| 文档 | 内容 |
|------|------|
| **RFC 2616** | HTTP/1.1（**已废弃**，仍常被引用） |
| **RFC 1945** | HTTP/1.0（参考） |
| **RFC 2396** | URI 通用语法（已被更新） |

---

## 现行 HTTP/1.1 规范族（补充）

RFC 2616 由下列文档**取代**，查标准时优先：

| RFC | 主题 |
|-----|------|
| **7230** | 报文语法与路由 |
| **7231** | 语义与内容 |
| **7232** | 条件请求 |
| **7233** | 范围请求 |
| **7234** | 缓存 |
| **7235** | 认证 |

URI：**RFC 3986**（统一语法）
