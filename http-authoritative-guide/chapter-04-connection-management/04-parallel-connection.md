# 4.4 并行连接

> 本章：[chapter-summary.md](./chapter-summary.md#ch04-4) · [4.5 持久连接](./05-persistent-connection.md) · [4.8 连接限制](./08-connection-limit.md)

## 本节核心目标

理解 **多条 TCP 并行多个 HTTP 事务** 的收益、局限与浏览器默认策略。

---

<a id="ch04-4-benefit"></a>

## 一、为何并行

| 效果 | 条件 |
|------|------|
| **重叠时延** | 客户端仍有**剩余带宽** |
| **体感更快** | 多个组件**同时渲染**（即使总时间相近） |

---

<a id="ch04-4-limit"></a>

## 二、并不一定更快

| 场景 | 结果 |
|------|------|
| **带宽瓶颈**（慢速链路） | 多连接**抢带宽**，无实质加速 |
| **服务器高负载** | 大量连接占内存/文件描述符，**威胁稳定性** |

---

<a id="ch04-4-browser"></a>

## 三、浏览器实践

- 默认使用**有限并行**（常见每主机约 **4～6** 条，因实现而异）  
- 常与 **持久连接** 组合 → [4.5](./05-persistent-connection.md)、[4.8](./08-connection-limit.md)
