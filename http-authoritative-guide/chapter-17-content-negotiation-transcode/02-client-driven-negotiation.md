<a id="ch17-2-how"></a>

## 实现方式

| 方式 | 说明 |
|------|------|
| **HTML 列表页** | 链出各变体及描述 |
| **`300 Multiple Choices`** | 浏览器可弹窗让用户选 |

---

<a id="ch17-2-pros-cons"></a>

## 优劣

| 优点 | 缺点 |
|------|------|
| 服务器实现**简单** | 至少 **2 次请求**（列表 + 资源）→ **时延** |
| 客户端**最懂**自己需求 | **URL 碎片化**；书签分享可能语言不对 |
