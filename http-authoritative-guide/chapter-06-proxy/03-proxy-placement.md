# 6.3 代理会去往何处

> 本章：[chapter-summary.md](./chapter-summary.md#ch06-3) · [6.4 客户端配置](./04-client-proxy-settings.md)

## 本节核心目标

掌握代理的**部署位置**、**父子层次**与**四种引流方式**。

---

<a id="ch06-3-locations"></a>

## 一、四种部署位置

| 位置 | 说明 |
|------|------|
| **出口代理（Egress）** | 内网出口，控制内→外 |
| **入口/访问代理（Ingress/Access）** | ISP 接入点，聚合客户流量、缓存 |
| **反向代理（Reverse）** | 源站前，冒用服务器名/IP |
| **交换点代理** | 对等 IX，减轻骨干拥塞 |

---

<a id="ch06-3-hierarchy"></a>

## 二、代理层次（父/子）

- **子代理**靠近客户端，**父代理**靠近服务器  
- 请求可沿链**向上转发**  
- 路由可**动态**：负载、地理、协议、服务级别 → 不同父或直连源站  

→ [ch20 负载均衡](../chapter-20-redirect-load-balance/chapter-summary.md)

---

<a id="ch06-3-traffic"></a>

## 三、如何把流量导向代理

| 方式 | 机制 |
|------|------|
| **改客户端** | 手工或 **PAC** 指定代理 |
| **改网络** | 交换/路由**拦截**（客户端无感） |
| **改 DNS** | 域名解析到反向代理 IP |
| **改服务器** | 响应 **`305 Use Proxy`**（少用） |
