# 6.1 Web的中间实体

> 本章：[chapter-summary.md](./chapter-summary.md#ch06-1) · 全书：[../README.md](../README.md) · [ch08 网关](../chapter-08-gateway-tunnel-relay/01-gateway.md)

## 本节核心目标

理解代理的**双重身份**，以及代理与**网关**的区分（及现实中的模糊地带）。

---

<a id="ch06-1-dual"></a>

## 一、双重身份

| 面向 | 代理像… |
|------|---------|
| 客户端 | **服务器** — 接连接、收请求、回响应 |
| 源站 | **客户端** — 向真实服务器发请求 |

---

<a id="ch06-1-private-public"></a>

## 二、私有与共享

| 类型 | 特点 |
|------|------|
| **私有代理** | 单用户/单客户端（常在本机，如浏览器插件） |
| **公共代理** | 多用户共享，利于**缓存**复用相同 URL → [ch07](../chapter-07-cache/chapter-summary.md) |

---

<a id="ch06-1-vs-gateway"></a>

## 三、代理 vs 网关

| | 协议关系 |
|---|----------|
| **代理（Proxy）** | 两端通常 **同协议**（HTTP→HTTP） |
| **网关（Gateway）** | **协议转换**（如 HTTP 前端 + FTP/POP 后端） |

**易错**：商业产品常**兼做**版本转换（1.0↔1.1）、SSL 卸载、FTP，边界模糊。
