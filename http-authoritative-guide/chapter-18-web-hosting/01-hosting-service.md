## Web 主机托管（Hosting）

对 Web 内容的**存储、协调、管理**职责 — 常外包给 **ISP/托管商**。

<a id="ch18-1-dedicated"></a>

## 专用托管（Dedicated）

| 项 | 说明 |
|----|------|
| **提供** | 专用服务器软硬件给单客户 |
| **优势** | 免自建机房/带宽；流量涨时**快速扩容** |
