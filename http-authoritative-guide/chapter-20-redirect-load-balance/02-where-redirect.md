# 20.2 重定向到何地

> 本章：[chapter-summary.md](./chapter-summary.md#ch20-2) · [ch06 代理](../chapter-06-proxy/chapter-summary.md) · [ch05 服务器](../chapter-05-web-server/chapter-summary.md)

## 本节核心目标

从客户端视角，弄清**谁**可以做重定向端点：**服务器、代理、缓存、网关**。

---

<a id="ch20-2-endpoints"></a>

## 四类端点

对客户端而言，以下组件特征相似，均可作为重定向目标：

| 端点 | 角色 |
|------|------|
| **Web 服务器** | 按 IP/副本处理请求 |
| **代理** | 按协议汇聚、缓存流量 |
| **缓存** | 就近提供热门文档 |
| **网关** | 协议转换、入口汇聚 |

---

<a id="ch20-2-server"></a>

## 服务器重定向

- 每台服务器处理绑定 IP 上的请求  
- LB 目标：把每条请求送到**最佳**副本（最近、负载最轻等）

→ [ch18 虚拟主机](../chapter-18-web-hosting/02-virtual-hosting.md)

---

<a id="ch20-2-proxy"></a>

## 代理重定向

- 代理按**协议**处理请求  
- 理想：附近 HTTP 流量**都经代理缓存**，常用文档本地命中，避免长路径回源

→ [ch06 代理部署](../chapter-06-proxy/03-proxy-placement.md)
