# 20.4 通用的重定向方法

## 本节核心目标

掌握服务器/代理常用的**六种通用重定向**技术及其权衡。

---

<a id="ch20-4-http"></a>

## 20.4.1 HTTP 重定向

| 项 | 内容 |
|----|------|
| **机制** | 短响应：**302**（等 3xx）+ **`Location`**，客户端对新 URL 再发请求 |
| **优势** | 重定向服务器知客户端**真实 IP**，可做精细路由 |

**易错 / 缺陷**：

- 原服务器判断成本高（接近整页处理）  
- **多一次 RTT**，时延上升  
- 重定向节点单点故障 → 全站风险 → 常与其他技术**组合**

---

<a id="ch20-4-dns"></a>

## 20.4.2 DNS 重定向

| 项 | 内容 |
|----|------|
| **机制** | 一域名多 IP；解析器返回可变地址分流 |
| **DNS 轮转** | 每次查询后轮转 IP 列表 — 最简单 LB |

**易错（DNS 缓存）**：

- OS、应用、递归 DNS **缓存** A 记录  
- 单客户端长期连**同一台**；轮转对单用户不平滑  

**高级**：最轻负载跟踪、邻接路由（最近）、故障屏蔽。

---

<a id="ch20-4-anycast"></a>

## 20.4.3 任播寻址（Anycast）

| 项 | 内容 |
|----|------|
| **机制** | 多地服务器**同一 IP**；经路由协议向骨干宣告 |
| **路由** | 骨干按**最短路径**把包送到最近节点 |

**易错**：服务器须「说路由器语言」；须防**路由泄露**。

---

<a id="ch20-4-mac"></a>

## 20.4.4 IP MAC 转发

| 项 | 内容 |
|----|------|
| **机制** | L4 交换机看 **IP + TCP 端口**（如 80），改分组**出站 MAC** 指向目标服务器/代理 |
| **局限** | MAC 点对点；目标须在交换机**一跳**内 |

---

<a id="ch20-4-nat"></a>

## 20.4.5 IP 地址转发（NAT）

| 项 | 内容 |
|----|------|
| **机制** | L4 设备改**目的 IP** 转发（NAT） |
| **对称路由** | 须管回程；设备要跟踪 TCP 连接 |

| 模式 | 做法 | 代价 |
|------|------|------|
| **完全 NAT** | 改源+目的 IP | 源站**不知真实客户端 IP**（认证/计费受影响） |
| **半 NAT** | 保留客户端源 IP | 须控制全网，防绕过交换机直连回程 |

---

<a id="ch20-4-necp"></a>

## 20.4.6 网元控制协议（NECP）

**网元（NE）** 与 **服务器元素（SE）** 交互：SE 下发负载/例外地址，NE 执行 MAC 转发、GRE 或 NAT。
