## 本节核心目标

掌握状态码**五大类**及常见码含义；理解 **100 Continue** 的用途与陷阱。

---

<a id="ch03-4-classes"></a>

## 一、五大类

| 范围 | 类别 | 含义 |
|------|------|------|
| **100～199** | 信息性 | 请求处于**中间状态** |
| **200～299** | 成功 | 请求**已成功处理** |
| **300～399** | 重定向 | 需**换位置**获取资源或使用**本地副本** |
| **400～499** | 客户端错误 | 请求**有误** |
| **500～599** | 服务器错误 | 服务器**内部**错误或限制 |

---

## 二、常见状态码（背）

### 1xx

| 码 | 含义 |
|----|------|
| **100 Continue** | 已收到**初始部分**；客户端可**继续发**实体主体 |

### 2xx

| 码 | 含义 |
|----|------|
| **200 OK** | 成功，通常带资源 |
| **201 Created** | 已创建新对象 |
| **204 No Content** | 成功但**无响应体** |
| **206 Partial Content** | 范围请求成功，返回**部分内容** |

### 3xx

| 码 | 含义 |
|----|------|
| **301 Moved Permanently** | **永久**重定向 |
| **302 Found** | **临时**重定向 |
| **304 Not Modified** | 资源未改，用**本地缓存**（配合条件请求） |

### 4xx / 5xx

| 码 | 含义 |
|----|------|
| **404 Not Found** | 资源不存在 |
| **504 Gateway Timeout** | 网关/代理**等待上游超时** |
| **505 HTTP Version Not Supported** | 不支持该 HTTP 版本 |

---

<a id="ch03-4-100-trap"></a>

## 三、易错：100 Continue

**初衷**：发大实体前，先问服务器是否愿意收 → 省带宽。

**陷阱**：若服务器要**提前结束**（如校验失败），不能只在已收部分数据时**直接发最终响应并硬关连接**，否则客户端仍在传 body → **截断/连接错误**。应遵循规范的 **Expect: 100-continue** 交互流程。
