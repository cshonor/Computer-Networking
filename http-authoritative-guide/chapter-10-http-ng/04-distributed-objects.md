---

<a id="ch10-4-doom"></a>

## 设计取向

将 Web 从「文档获取」推向 **面向对象的分布式对象模型**。

---

## 易错：为何受阻

| 问题 | 说明 |
|------|------|
| **过度复杂** | CORBA/DCOM 类系统笨重、形式化重 |
| **绑定过重** | 把 Web 与重型对象框架绑死 → 部署/互操作成本高 |

这是 HTTP-NG **未获采纳**的重要原因之一。
