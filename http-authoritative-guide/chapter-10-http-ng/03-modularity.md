## 三层架构

```text
┌─ 第三层：Web 应用层 ─── GET/POST、首部语义、WebDAV 等
├─ 第二层：远程调用层 ─── 通用请求/响应、RMI 框架
└─ 第一层：报文传输层 ─── 不透明高效传输（WebMUX）
```

| 层 | 职责 | 核心提议 |
|----|------|----------|
| **1 报文传输** | 任意底层网络上的**字节管道** | **WebMUX** → [10.8](./08-webmux.md) |
| **2 远程调用** | 与语义无关的**调用框架** | **二进制连接协议** → [10.9](./09-binary-wire.md) |
| **3 Web 应用** | HTTP/1.1 方法/首部映射为**分布式对象操作** | [10.7](./07-web-application.md) |
