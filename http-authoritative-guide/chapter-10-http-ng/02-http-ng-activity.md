## 背景与结局

| 项 | 说明 |
|----|------|
| **发起** | 1997 年 W3C **HTTP-NG**（下一代）工作组 |
| **目标** | **彻底重构** HTTP 底层架构 |
| **结果** | 改革**过于激进**，业界未广泛采纳；工作组**已解散** |

仍是历史上对 HTTP 架构**最认真的一次模块化尝试**，勾勒了分层演进方向。
