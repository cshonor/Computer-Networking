## 特征

| 特征 | 说明 |
|------|------|
| **并发复用** | 少数 TCP 连接上**并行、交错**传多条分块报文 |
| **速度适配** | 快慢流**分组复用**到同一通道，提高利用率 |

HTTP-NG 工作组在**第一层**投入最大精力之一。
