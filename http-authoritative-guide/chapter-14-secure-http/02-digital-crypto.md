## 核心术语

| 术语 | 含义 |
|------|------|
| **密码（Cipher）** | 编码算法 |
| **明文 / 密文** | plaintext / ciphertext |
| **密钥（Key）** | 改变算法行为的参数 |
| **对称加密** | 加解密**同一密钥** |
| **非对称加密** | **不同**加解密密钥 |
| **公钥加密** | 公钥加密、私钥解密 |
| **数字签名** | 防伪造/篡改的校验和 |
| **数字证书** | 可信第三方签发的身份绑定 |
