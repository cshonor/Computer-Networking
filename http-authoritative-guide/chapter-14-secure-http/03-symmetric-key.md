## 密钥长度与暴力破解

| 长度 | 说明 |
|------|------|
| **40 bit** | 可枚举 |
| **128 bit** | 实践中难暴力破解 |

<a id="ch14-3-distribution"></a>

## 致命缺陷：共享密钥

双方须**事先安全共享**同一密钥。  
N 个节点两两通信 ≈ **N²** 个密钥 → 互联网规模不可行。

→ 公钥体系 [14.4](./04-public-key.md)
