# 14.4 公开密钥加密技术

> 本章：[chapter-summary.md](./chapter-summary.md#ch14-4) · [14.5 签名](./05-digital-signature.md)

## 本节核心目标

掌握**公钥/私钥**分工与 **混合加密（会话密钥）**。

---

<a id="ch14-4-mechanism"></a>

## 工作原理

| 密钥 | 用途 |
|------|------|
| **公钥** | 公开；任何人可**加密**发给接收方 |
| **私钥** | 保密；仅接收方能**解密** |

避免 N² 个预共享对称密钥。

---

<a id="ch14-4-rsa"></a>

## 14.4.1 RSA

基于**大整数分解**困难性；有公钥+明文+密文仍难推私钥。

---

<a id="ch14-4-hybrid"></a>

## 14.4.2 混合加密与会话密钥（重点）

| 痛点 | 公钥运算**慢** |
|------|----------------|
| **HTTPS 做法** | 握手：用**公钥**安全传递临时 **会话密钥（对称）** |
| 数据阶段 | 用**对称密钥**加密大量 HTTP 流量 |
