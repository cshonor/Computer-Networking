# 14.5 数字签名

> 本章：[chapter-summary.md](./chapter-summary.md#ch14-5) · [14.6 证书](./06-digital-cert.md)

## 本节核心目标

用**私钥签、公钥验**证明作者身份与完整性。

---

<a id="ch14-5-flow"></a>

## 三步

1. 对报文做**摘要**（定长）  
2. 发送方用**私钥**对摘要**签名**  
3. 接收方用发送方**公钥**解开签名，与自算摘要比对 → 一致则**未篡改且来自私钥持有者**

（签名运算常等价于「用私钥做解码侧操作」。）
