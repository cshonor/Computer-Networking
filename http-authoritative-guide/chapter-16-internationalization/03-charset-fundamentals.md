# 16.3 多语言字符编码入门

> 本章：[chapter-summary.md](./chapter-summary.md#ch16-3)

## 本节核心目标

厘清**字符/字形/字符集/编码方案**术语及三类编码模型。

---

<a id="ch16-3-terms"></a>

## 16.3.1 核心术语（8 个）

字符、字形、编码后的字符、代码空间、代码宽度、字符库、编码后的字符集、字符编码方案。

---

<a id="ch16-3-naming"></a>

## 16.3.2 MIME charset 命名（易错）

HTTP 的 **`charset` ≠ 纯字符集**，而是 **编码方案 + 编码字符集** 的组合体。

---

<a id="ch16-3-glyph"></a>

## 16.3.3–16.3.4 字符 vs 字形

| | 说明 |
|---|------|
| **字符** | 语义原子 |
| **字形** | 具体画法；同字符可多字形（连笔 ligature 等） |

---

<a id="ch16-3-ccs"></a>

## 16.3.5 编码后的字符集

数字代码 → 字符字典：

**US-ASCII** → **iso-8859** → **JIS** → **Unicode/UCS**

---

<a id="ch16-3-ces"></a>

## 16.3.6 字符编码方案（三类）

| 类型 | 例子 | 特点 |
|------|------|------|
| **定宽** | 8-bit | 快，≤256 字符 |
| **变宽无模态** | **UTF-8** | 兼容 ASCII，推荐 |
| **变宽有模态** | iso-2022-jp | 转义序列切换字符集 |
