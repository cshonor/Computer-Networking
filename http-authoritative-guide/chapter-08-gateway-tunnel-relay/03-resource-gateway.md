<a id="ch08-3-cgi"></a>

## 8.3.1 CGI（通用网关接口）

| 项 | 说明 |
|----|------|
| **定位** | 最早、最通用的服务器扩展；Perl/C/Tcl 等 |
| **触发** | URI 含 `cgi-bin` 等路径或特定参数 |
| **流程** | 服务器**拉起进程** → 程序生成响应 |

**痛点**：**每请求 fork 新进程** → 高并发性能差。

**改进**：**FastCGI** — 持久守护进程，免反复创建。
