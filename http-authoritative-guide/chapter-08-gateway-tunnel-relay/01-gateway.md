# 8.1 网关

> 本章：[chapter-summary.md](./chapter-summary.md#ch08-1) · 全书：[../README.md](../README.md) · [ch06 代理 vs 网关](../chapter-06-proxy/01-middleman.md#ch06-1-vs-gateway)

## 本节核心目标

理解**网关**作为 HTTP 与后端资源/协议之间的**粘合剂**与**翻译器**。

---

<a id="ch08-1-role"></a>

## 一、角色定位

单一 HTTP 应用难以覆盖：数据库、动态内容、遗留系统等。

| 对外 | 对内 |
|------|------|
| 像**源站**收 HTTP 请求 | 转成**其他协议**或调用**后端应用** |
| 将结果**封装成 HTTP 响应** | 回给客户端 |

**抽象**：「如何到达资源」由网关统一表示。

---

<a id="ch08-1-naming"></a>

## 二、命名：客户端协议 / 服务器端协议

| 类型 | 记号 | 说明 |
|------|------|------|
| **服务器端网关** | **HTTP/\*** | 客户端用 HTTP；后端用 FTP、JDBC 等 |
| **客户端网关** | **\*/HTTP** | 客户端用非 HTTP；后端用 HTTP |

→ 协议网关详 [8.2](./02-protocol-gateway.md)；资源网关 [8.3](./03-resource-gateway.md)
