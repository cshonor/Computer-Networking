## SOAP（简单对象访问协议）

| 项 | 说明 |
|----|------|
| **载体** | 常跑在 **HTTP** 上 |
| **载荷** | 结构化 **XML** |
| **目的** | 跨应用、语言、平台互操作 |

现代 REST/JSON API 更常见，SOAP 仍见于企业集成、遗留系统。
