## 实用要点

| 类别 | 要求 |
|------|------|
| **身份** | 准确 **`User-Agent`**（含说明 URL）、**`From`** |
| **节制** | **条件请求**；单站**并发/频率**限制（间隔数秒级） |
| **错误处理** | 正确处理状态码与异常 |
| **防环** | 去重、黑名单、带宽监控与**日志** |
| **遵守** | 读取并尊重 **`robots.txt`** / meta |
