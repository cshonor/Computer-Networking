# 9.6 搜索引擎

> 本章：[chapter-summary.md](./chapter-summary.md#ch09-6)

## 本节核心目标

理解**搜索引擎**作为最大爬虫应用：爬取 → 索引 → 查询 → 排序。

---

<a id="ch09-6-arch"></a>

## 9.6.1–9.6.2 系统结构

```text
爬虫 ──► 全文索引库 ──► 搜索网关 ──► 用户
```

不仅是爬虫，而是**协同系统**。

---

<a id="ch09-6-index"></a>

## 9.6.3 全文索引

**倒排索引**：词 → 包含该词的文档列表，查询时**无需扫全网**。

---

<a id="ch09-6-query"></a>

## 9.6.4 发布查询

用户在表单输入词 → 浏览器 **GET/POST** 到搜索网关 → 网关转成索引查询表达式。

---

<a id="ch09-6-rank"></a>

## 9.6.5 结果排序（相关性）

结果过多 → **相关性排名**：词频 + **链接流行度**（**PageRank** 思想：被链越多越重要）。

---

<a id="ch09-6-spoof"></a>

## 9.6.6 欺诈（Spoofing）攻防

站长可能：**关键词堆砌**、假页面等刷排名 → 引擎算法持续**反作弊**（现结合 NLP 等）。
