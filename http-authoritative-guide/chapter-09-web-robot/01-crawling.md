理解爬虫如何**发现 URL、去重、防环路/陷阱**，以及常见**组合策略**。

<a id="ch09-1-root"></a>

## 9.1.1 根集（Root Set）

爬虫起点的 **URL 初始集合**。好根集应覆盖：

- 大而流行的站点  
- 新页面列表  
- 少被链到的「无名」页  

→ 尽量扩大 Web 覆盖。

## 9.1.3–9.1.4 环路与重复的危害

| 危害 | 说明 |
|------|------|
| **耗自身** | 带宽/时间重复抓同一页 |
| **拖垮服务器** | 近似 **DoS** |
| **污染库** | 搜索引擎等充满 **dups** |

必须记录**已访问** URL。

---

<a id="ch09-1-breadcrumbs"></a>

## 9.1.5 面包屑（去重数据结构）

| 技术 | 说明 |
|------|------|
| **树 / 散列表** | 精确是否访问过 |
| **有损位图** | URL 哈希到位图，省空间，有**冲突**风险 |
| **检查点** | 持久化到磁盘，防崩溃 |
| **集群分片** | 按 URL 哈希分给多台机器 |

→ 拓展：**Bloom Filter**、Scrapy-Redis

---

<a id="ch09-1-canonical"></a>

## 9.1.6–9.1.7 别名与 URL 规范化（易错）

不同形式 URL 可能**同一资源**：

- 省略 `:80`  
- 编码差异（`~` vs `%7E`）  
- 大小写（不敏感服务器）  
- **`#` 片段**  

**规范化**：补默认端口、反转义、删 `#` 等。  
**难处理**：虚拟主机、`index.html` 默认映射等**服务器特定**别名。

<a id="ch09-1-traps"></a>

## 9.1.8–9.1.9 爬虫陷阱

| 类型 | 说明 |
|------|------|
| **符号链接环路** | 目录链到父目录，深度无限 |
| **动态虚拟空间** | 日历等无限生成新 URL |

---

<a id="ch09-1-strategy"></a>

## 9.1.10 防循环组合策略

- URL **规范化**  
- **广度优先**（BFS，少陷单站深坑）  
- **节流（Throttling）**：同站频率/并发上限  
- 限制 URL **长度**  
- **黑名单**、**模式检测**（如重复 `/subdir/`）  
- 内容 **MD5 指纹**  
- **人工监视**
