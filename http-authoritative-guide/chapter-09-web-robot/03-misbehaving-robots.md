# 9.3 行为不当的机器人

> 本章：[chapter-summary.md](./chapter-summary.md#ch09-3) · [9.4 拒绝访问](./04-robots-exclusion.md)

## 本节核心目标

认识**失控/无礼**爬虫对站点与网络的危害类型。

---

<a id="ch09-3-risks"></a>

## 风险表现

| 类型 | 说明 |
|------|------|
| **失控机器人** | 逻辑错误/环路 → 海量请求，**无意 DoS** |
| **失效 URL** | 过时列表 → 大量 **404**，污染日志 |
| **超长错误 URL** | 环路拼接 → 脆弱服务器**缓冲区**风险 |
| **爱打听的机器人** | 穷举/日志泄露 → 抓到未公开敏感文件 |
| **动态网关滥用** | 反复打高开销 CGI → **CPU 耗尽** |
