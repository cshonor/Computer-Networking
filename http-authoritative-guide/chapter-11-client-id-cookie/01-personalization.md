## 无状态的痛点

| 问题 | 说明 |
|------|------|
| **匿名** | 默认不知「谁」在访问 |
| **无序列** | 无法自动关联同一用户的多次请求 |

现代 Web 需要：轨迹跟踪、个性化、购物车、登录态等。
