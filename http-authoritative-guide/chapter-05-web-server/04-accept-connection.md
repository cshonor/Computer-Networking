# 5.4 第一步——接受客户端连接

> 本章：[chapter-summary.md](./chapter-summary.md#ch05-4) · [ch04 TCP](../chapter-04-connection-management/02-tcp-connection.md)

## 本节核心目标

掌握服务器**接受 TCP**、**识别客户端** 及两项易拖慢性能的机制。

---

<a id="ch05-4-accept"></a>

## 一、处理新连接

- 建立 TCP，解析 **客户端 IP**，加入连接表  
- 可因 **IP 未授权**、恶意名单等**拒绝或立即关闭**

---

<a id="ch05-4-rdns"></a>

## 二、反向 DNS（易错）

| 用途 | 日志、访问控制显示主机名 |
|------|--------------------------|
| **代价** | **查找很慢**，拖事务 |
| **实践** | 大站点**默认关闭**（如 Apache `HostnameLookups off`），仅必要时开 |

---

<a id="ch05-4-ident"></a>

## 三、ident 协议（易错）

| 项 | 说明 |
|----|------|
| 机制 | 查客户端 **TCP 113**，问「谁发起了这条 HTTP 连接」 |
| 局限 | 家用 PC 常无 ident、防火墙拦、可伪造、隐私差 |
| 日志 | 无信息时记 **`-`** |

**公共互联网几乎不可用**，勿依赖 ident 做安全。
