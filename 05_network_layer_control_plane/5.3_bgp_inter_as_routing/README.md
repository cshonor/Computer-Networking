# 5.3 — bgp inter as routing

## 知识点速记

- **eBGP / iBGP**；路径以**策略**为先，非纯最短跳。  
- **AS-PATH**、**NEXT-HOP**、**LOCAL_PREF**、**MED**、热土豆等决策维度。  
- **Anycast**：同前缀多入口，就近入流。

## 与后端开发的联系

- 多云出口、DDoS 清洗引流、全球负载与**出网成本**都与 BGP 策略相关。
