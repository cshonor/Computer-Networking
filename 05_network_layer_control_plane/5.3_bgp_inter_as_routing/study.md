## 〇、新手易懂：BGP 是什么

**BGP = Border Gateway Protocol（边界网关协议）**

| 项 | 说明 |
|----|------|
| 类型 | **EGP** — 连接**不同 AS**（运营商/大公司） |
| 地位 | **互联网核心协议**，全球运营商靠它互通 |

**类比**

| 协议 | 比喻 |
|------|------|
| **OSPF/RIP（IGP）** | 城市**内部**交通规则（找最短/最快路） |
| **BGP** | 城市**之间**物流协议（优先政策、商业、成本，**不只看远近**） |

**终极对比一句**：**OSPF 讲效率，BGP 讲政治（策略）。**

---

<a id="ch5-3-bgp-courier"></a>

### 超通俗新手版：快递公司类比

把每个 **AS** 看成一家**独立大型快递公司**：

| 范围 | 用什么 | 比喻 |
|------|--------|------|
| **AS 内部**送货 | **OSPF / RIP（IGP）** | 自家公司内部路线 |
| **公司之间**收发包裹 | **BGP** | 不同快递公司互相通报路线、约定怎么走 |

BGP 专门管：**各家大型网络之间**互相通报路线、按规则选路。

#### 1）三个基础特点

| 特点 | 大白话 | 技术对应 |
|------|--------|----------|
| **沟通稳定** | 两家公司**打电话**（线路稳、不乱） | **TCP 179** |
| **记录全程** | 包裹路线写清经过哪些公司 | **AS-Path**（A→B→C） |
| **天生防绕圈** | 路线兜回**自家公司** → **拒收** | AS-Path **见己 AS 丢弃** |

#### 2）选路逻辑（和内网最大区别）

| | OSPF（内网） | BGP（外网） |
|---|-------------|------------|
| 看什么 | **速度最快、距离最近** | **规矩、成本、合作关系** |
| 顺序（大白话） | 算最短 | ① 自家**优先路线** → ② 经过公司**越少越好** → ③ 来源/成本 |

→ 不是近就走；**综合选最合适通路** → 精编：[#ch5-3-bgp-selection](#ch5-3-bgp-selection)

#### 3）两种邻居

| 类型 | 大白话 | 作用 |
|------|--------|------|
| **eBGP** | **跨公司**打交道 | 不同 AS 设备交换**外网**线路 |
| **iBGP** | **公司内部**互通 | 把外部路线**传遍本 AS** 所有设备 |

#### 4）五句总结

1. **管范围**：只管**不同大型网络之间**互通  
2. **核心本事**：记**完整行进路线**（AS-Path），按**商业和规则**选路  
3. **内网找近路** → OSPF/RIP  
4. **外网跨区域、按规则选路** → BGP  
5. **TCP 179 + 路径向量 + 策略优先**

**何时才用 BGP？** 数据需**跳出本 AS**（如移动访问电信/海外）→ AS **边界**才交换 BGP 路由。  
同 AS 内互访（如移动→移动）→ 全程 **IGP**，**不用 BGP** → [5.1 同AS实景](../5.1_routing_algorithm/study.md#ch5-1-same-as-scenario)

→ 与 [5.1 AS≠IGP 城市口诀](../5.1_routing_algorithm/study.md#ch5-1-as-vs-igp) 对照：**城内 IGP，城城 BGP** · **eBGP/iBGP 精编**：[#ch5-3-ebgp-ibgp](#ch5-3-ebgp-ibgp)

## 〇·二、eBGP / iBGP 精编（先读 · 超好记）

> **E = eBGP（External BGP，外部 BGP）** — **AS 与 AS 之间**打交道（跨自治系统）  
> **I = iBGP（Internal BGP，内部 BGP）** — **同一 AS 内部**，把外部路由**传进去、传全**

**一句话**：**eBGP 出国 · iBGP 国内通知 · IGP 国内导航（OSPF）**

---

### 1）为什么 BGP 要有 eBGP 和 iBGP？

| 任务 | 谁干 | 说明 |
|------|------|------|
| **AS 之间互通** | **eBGP** | 全世界不同 AS（运营商/大网）互学外网路由 |
| **AS 内同步外网路由** | **iBGP** | 一个 AS 内几十上百台路由器，**都要知道**怎么出网 |

**BGP 不只是「AS 之间交流的工具」** — 还要把 eBGP 学到的外网路由在 **AS 内部同步好**，否则内部路由器不知道怎么出去 → **路由黑洞**。

| 比喻 | 对应 |
|------|------|
| **AS** | 一个国家 |
| **eBGP** | **国与国**外交（签证、通关） |
| **iBGP** | 国家内部把「国外路线」**告诉全国所有城市** |

---

### 2）eBGP（E）vs iBGP（I）核心区别

| 对比项 | **eBGP（E，外部）** | **iBGP（I，内部）** |
|--------|---------------------|---------------------|
| **邻居** | **不同 AS**（不同运营商/公司） | **同一 AS** 内路由器 |
| **作用** | **交换外网路由**（电信↔联通） | 把 eBGP 学到的路由**在 AS 内传遍** |
| **防环** | **AS-Path** 加本 AS 号；见**己 AS** 直接丢 | **水平分割**：从 iBGP 学到的**不再发给其他 iBGP 邻居** |
| **TTL 默认** | **1**（一般要求**直连**） | **255**（可不直连，常用**环回口**建邻） |
| **下一跳** | 常**改成**与自己相连的接口 | **默认不变**（仍是外部邻居地址）→ 需 **IGP 可达** |

**口诀**：**e 跨 AS 直连 TTL1 · i 同 AS 环回 TTL255 · e 改下一跳 · i 水平分割**

---

<a id="ch5-3-ebgp-ibgp-topo"></a>

### 3）最简场景：AS100（电信）↔ AS200（联通）

| 步骤 | 动作 |
|------|------|
| 1 | 电信边界 **R1** ↔ 联通边界 **R2** 建 **eBGP（E）** → 互学对方网段 |
| 2 | 电信内部 **R3、R4** 与 **R1** 建 **iBGP（I）** → R1 把联通路由传给 R3、R4 |
| 3 | **R3、R4 之间不能直接互发 iBGP**（水平分割防环） |

**没有 iBGP 会怎样？**

- 只有 **R1** 知道联通怎么走  
- **R3、R4** 不知道 → 包到 R3/R4 就**丢（黑洞）**

```text
  AS200（联通）                    AS100（电信）
  ┌─────────┐                    ┌──────────────────────────────┐
  │   R2    │◄──── eBGP(E) ────►│ R1 ◄──iBGP(I)──► R3          │
  │ 外网前缀 │     TTL=1 直连     │ ▲                ▲           │
  └─────────┘                    │ └──iBGP(I)──► R4 │           │
                                 │                  │           │
                                 │    OSPF/IGP（AS 内导航）     │
                                 └──────────────────────────────┘

  eBGP：R1↔R2 跨 AS 学外网路由，AS-Path 防环
  iBGP：R1→R3/R4 把外网路由传全；R3↔R4 不互发 iBGP
  IGP ：R3/R4/R1 之间算 AS 内最短路（到下一跳/边界）
```

→ 大图精编：[#ch5-3-ebgp-ibgp-topo](#ch5-3-ebgp-ibgp-topo)

---

### 4）与 OSPF / IS-IS（IGP）的关系（别混）

| 协议 | 管什么 | 一句话 |
|------|--------|--------|
| **eBGP** | AS **之间**交换外网路由 | **出国** |
| **iBGP** | AS **内部**同步 BGP 外网路由 | **国内通知** |
| **IGP（OSPF/IS-IS）** | AS **内部**怎么走最快 | **国内导航** |

**分工**：iBGP 告诉内部「有哪些外网网段、下一跳是谁」；IGP 负责在 AS 内**把包送到那个下一跳**。

---

### 5）直接回答：「BGP 不是 AS 之间用的吗？为什么还要 I？」

1. eBGP 学到的外部路由，**必须让 AS 内所有路由器都知道**，否则内部**路由黑洞**  
2. **不能用 OSPF 传 BGP 路由**（规模太大、策略控制弱）  
3. 所以 BGP 自己搞 **iBGP**，专门在 AS 内同步 BGP 路由，同时**水平分割**防环  

大规模 AS 还常用 **RR（路由反射器）**、**联盟** 避免 iBGP 全互联 → [#ch5-3-bgp-neighbor](#ch5-3-bgp-neighbor)

---

### 6）5 行默写 · 易错

```text
E=eBGP外部跨AS，I=iBGP内部同AS传全外网路由。
eBGP：AS-Path防环，TTL默认1，一般直连，下一跳常改。
iBGP：水平分割不互传，TTL默认255，环回建邻，下一跳默认不变。
eBGP出国，iBGP国内通知，IGP(OSPF)国内导航。
没iBGP只有边界知道外网→内部黑洞。
```

| 易混 | 纠正 |
|------|------|
| BGP 只管 AS 之间？ | **还要 iBGP** 在 AS **内**同步外网路由 |
| iBGP = 跨 AS？ | **否**；**同 AS 内**；跨 AS 是 **eBGP** |
| 用 OSPF 传 BGP 路由？ | **不行**（规模/策略）；靠 **iBGP** |
| R3、R4 互发 iBGP？ | **不行**（水平分割）；经 **R1 或 RR** |
| iBGP 下一跳不变？ | **默认是**；内部需 **IGP 可达** 该下一跳 |

→ 选路：[#ch5-3-bgp-selection](#ch5-3-bgp-selection) · vs OSPF：[#ch5-3-bgp-vs-ospf](#ch5-3-bgp-vs-ospf) · **陌生外网场景**：[#ch5-3-unknown-prefix-forward](#ch5-3-unknown-prefix-forward)

## 〇·三、陌生外网访问：eBGP 未学到路由时，全网怎么通？

> **已知网段走 BGP 明细 · 未知网段靠默认路由层层接力**

### 基础角色

| 角色 | 设备/协议 |
|------|-----------|
| **本 AS** | **AS 100**（内网 **OSPF**） |
| **目标 AS** | **AS 200** |
| **边界 eBGP** | 本 AS **R1** ↔ AS 200 **R2** |
| **AS 内 iBGP** | **R3、R4** ↔ **R1** |
| **前提** | 目标主机网段：**当前所有 BGP 设备都没有这条路由** |

---

### 1）完整转发步骤（5 步）

| 步 | 环节 | 动作 |
|----|------|------|
| **1** | **内网主机** | PC 访问陌生外网 IP → 查表 → **默认网关** → 发给内网路由器 |
| **2** | **AS 内 IGP** | 沿途路由器查 **OSPF**；无目标明细 → 匹配 **默认路由** → 一步步转到边界 **R1** |
| **3** | **边界 R1** | 先查 **BGP**：无该网段 eBGP/iBGP 路由 → 再查 **静态/默认路由** → 发给 eBGP 邻居 **R2** |
| **4** | **跨 AS eBGP** | **R2** 查 BGP 仍无明细 → 靠自身**默认路由** → 继续往目标 AS 或上级骨干 AS 转发 |
| **5** | **目标 AS** | 抵达目标 AS 边界后 → 对方 **OSPF/IGP** → 投递到目标主机 |

```text
  PC ──默认网关──► R3/R4 ──OSPF默认路由──► R1 ──默认/eBGP──► R2(AS200)
                                                      │
                                              目标AS内OSPF投递
  （全程：BGP表无该陌生前缀，靠默认路由接力）
```

---

### 2）关键疑问：没学到路由为什么还能通？

| 点 | 说明 |
|----|------|
| **BGP 传什么** | 只传**公网明细路由**；全网海量网段不可能条条提前 eBGP 同步 |
| **未知网段** | **不会**出现在 BGP 路由表里 |
| **兜底** | 运营商/企业 AS 边界配 **默认路由（0.0.0.0/0）** → 查不到的地址**统一交给相邻 AS** |
| **滞后性** | 新网段刚上线、BGP 尚未同步 → **先走默认路由**；发布后全网学到明细 → **改走精确 BGP 路由** |

---

### 3）eBGP / iBGP / OSPF 分工配合

| 协议 | 分工 |
|------|------|
| **OSPF（IGP）** | **本 AS 内**转发；保证内网→边界 **R1** 可达 |
| **iBGP** | 把 eBGP 学到的外网路由**同步给 AS 内**；无路由时内部仍靠 OSPF **默认路由** 走向出口 |
| **eBGP** | AS 间交换**已知**公网路由；**未知网段不产生 BGP 条目** → 交给**默认路由**跨 AS |

---

### 4）极端情况

| 情况 | 结果 |
|------|------|
| **无默认路由**、也无任何指向外网的路由 | 边界**查不到**目标 → **丢弃** → 主机**超时** |
| **新网段 BGP 已收敛** | 再次访问 → 匹配 **BGP 明细路由** → 按 BGP 选路规则转发，**不再走模糊默认路由** |

---

### 5）极简总结

| 场景 | 怎么走 |
|------|--------|
| **已知网段** | eBGP 学路由 → iBGP 内网同步 → OSPF 内网转发 → **精准寻址** |
| **未知陌生网段** | **无 BGP 路由** → 全网靠 **默认路由** 层层跨 AS 接力 → 仍能访问 |

**5 行默写**

```text
陌生外网：BGP表无明细，边界靠默认路由发给eBGP邻居。
内网：OSPF默认路由把包送到出口R1。
eBGP只传已知公网明细，未知网段不产生BGP条目。
没默认路由→边界丢弃→访问超时。
新网段发布后→BGP学到明细→改走精确转发。
```

| 易混 | 纠正 |
|------|------|
| 没 BGP 路由一定不通？ | **否**；有**默认路由**仍可通 |
| BGP 负责所有外网寻址？ | **否**；只传**已知明细**；未知靠**默认路由** |
| 内网靠 iBGP 转发到边界？ | **否**；到边界靠 **OSPF/IGP**；iBGP 传**路由信息** |
| 默认路由 = BGP 路由？ | **否**；常是**静态默认**或运营商下发，与 BGP 明细**互补** |

→ 拓扑基础：[#ch5-3-ebgp-ibgp-topo](#ch5-3-ebgp-ibgp-topo)

## 一、BGP 基础定位（必背）

**BGP**（Border Gateway Protocol，**边界网关协议**）

| 项 | 说明 |
|----|------|
| **协议类型** | **EGP 外部网关协议** — 作用于**不同 AS（自治系统）**之间 |
| **地位** | **互联网骨干核心协议**；全球跨运营商路由互通的「黏合剂」 |
| **选路本质** | **策略驱动**（非单纯最短路径/最短跳） |
| **算法类型** | **路径向量（Path Vector）** — 见 [#ch5-3-path-vector](#ch5-3-path-vector) |

一句话：**AS 之间怎么通、走谁家线路，由 BGP 按策略说了算。**

<a id="ch5-3-path-vector"></a>

## 二、路径向量与 AS-Path（必考）

### 和 RIP / OSPF 的区别

| 协议 | 类型 | 传什么 |
|------|------|--------|
| **RIP** | **距离矢量 DV** | 只告诉邻居「我到目标**多远**」 |
| **OSPF** | **链路状态 LS** | 全网拓扑图，算**最短路径** |
| **BGP** | **路径向量 PV** | 不仅「我能到」，还带**整条经过的 AS 列表** |

→ **AS-Path 防环精编**：[#ch5-3-as-path-loop](#ch5-3-as-path-loop)

---

<a id="ch5-3-as-path-loop"></a>

### AS-Path 防环（BGP 域间防环核心）

#### 1）什么是 AS-Path

**AS-Path** = BGP **公认强制属性**，记录路由从源 AS 出发**依次经过的所有 AS 号序列**（**不含**本地 AS）。

格式：`[AS1, AS2, AS3, …]`

| 传递 | 规则 |
|------|------|
| **eBGP 发给邻居** | 把**自己 AS 号加到最左边**（**prepend**） |
| **iBGP 传递** | **AS-Path 不变** |

---

#### 2）防环核心规则（必背）

**收到 eBGP 路由时：若 AS-Path 里已含本地 AS 号 → 直接丢弃，不接收、不转发。**

**一句话：看到自己 → 拒收，防环。**

---

#### 3）例子（最常考）

场景：**AS100 → AS200 → AS300 → 又发回 AS100**

| 步 | 动作 | AS-Path |
|----|------|---------|
| 1 | AS100 发给 AS200 | `[100]` |
| 2 | AS200 发给 AS300 | `[200, 100]` |
| 3 | AS300 发回 AS100 | `[300, 200, 100]` |
| 4 | **AS100 收到** | 发现含 **100（自己）** → **丢弃**，环路终止 |

```text
  AS100 ──► AS200 ──► AS300 ──► AS100
  [100]     [200,100]  [300,200,100]  见100→丢
```

---

#### 4）AS-Path 只防 AS 间（eBGP）环路

| 范围 | 防环机制 |
|------|----------|
| ✅ **eBGP（AS 之间）** | **AS-Path** — 见己 AS 丢弃 |
| ❌ **iBGP（AS 内部）** | AS-Path **不防环** → 靠 **水平分割**、**RR（路由反射器）**、**联盟（Confederation）** |

→ iBGP 精编：[#ch5-3-ebgp-ibgp](#ch5-3-ebgp-ibgp) · 邻居速查：[#ch5-3-bgp-neighbor](#ch5-3-bgp-neighbor)

---

#### 5）两个作用（考试常一起问）

| 作用 | 说明 |
|------|------|
| **防环** | eBGP 收到含**本地 AS** 的路由 → **丢弃** |
| **选路** | **AS-Path 越短越优先**（第 4 条选路规则）；可人为 **prepend 加长** 做流量工程（TE） |

→ 选路 13 条：[#ch5-3-bgp-selection](#ch5-3-bgp-selection)

---

#### 6）记忆口诀 · 3 行默写

```text
EBGP左加AS号prepend，iBGP传递AS-Path不变。
收到eBGP见己AS直接丢：看到自己就放下。
AS-Path防eBGP环+选路越短越优；iBGP防环靠水平分割/RR/联盟。
```

| 易混 | 纠正 |
|------|------|
| iBGP 也靠 AS-Path 防环？ | **否**；靠**水平分割 / RR / 联盟** |
| AS-Path 含本地 AS 还收？ | **eBGP 拒收** |
| prepend 加在哪边？ | **最左边**（eBGP 发出时） |
| AS-Path 短 = 一定选？ | **否**；先比 **Weight/Local_Pref** 等策略 |

## 三、BGP 与 OSPF 核心区别（必考表）

| 对比维度 | **OSPF（IGP）** | **BGP（EGP）** |
|----------|-----------------|----------------|
| **适用范围** | **同一 AS 内部** | **不同 AS 之间** |
| **核心算法/思路** | **链路状态**、最短路径（SPF） | **路径向量**、**策略**选路 |
| **设计目标** | 转发性能、时延最优 | **路由可控**、安全合规、**商业策略优先** |
| **封装** | **IP 协议号 89**（无 TCP/UDP） | **TCP 179** |

→ OSPF 精读：[5.2](../5.2_ospf_intra_as_routing/study.md#ch5-2-ospf-exam)

<a id="ch5-3-bgp-features"></a>

## 四、BGP 核心特性

| # | 特性 |
|---|------|
| 1 | 依托 **TCP 179** 建立邻居，**可靠**传输 UPDATE 等报文 |
| 2 | 路由携带 **AS-Path**（途经 AS 号列表）→ **天然防 AS 级环路** |
| 3 | 丰富**路径属性**：AS-Path、**Next_Hop**、**Local_Pref**、MED 等 |
| 4 | **策略能力强**：路由过滤、策略路由、优先级修改（import/export policy） |

### 封装对比（考试常考）

| 协议 | 类型 | 承载 |
|------|------|------|
| OSPF | IGP | **IP 89** |
| RIP | IGP | UDP 520 |
| **BGP** | EGP | **TCP 179** |

<a id="ch5-3-bgp-neighbor"></a>

## 五、BGP 两大邻居类型（速查）

> **精编** → [#ch5-3-ebgp-ibgp](#ch5-3-ebgp-ibgp) · 拓扑：[#ch5-3-ebgp-ibgp-topo](#ch5-3-ebgp-ibgp-topo)

| 类型 | 全称 | 邻居 | 防环 | TTL |
|------|------|------|------|-----|
| **eBGP（E）** | External BGP | **不同 AS** | **AS-Path** 见己 AS 丢 | 默认 **1** |
| **iBGP（I）** | Internal BGP | **同 AS 内** | **水平分割** | 默认 **255** |

**iBGP 工程要点**

- 从 **iBGP** 学到的路由 → **不再发给其他 iBGP 邻居**
- 下一跳默认不变 → 需 **IGP 可达** 或策略调整
- 大规模 AS：**RR（路由反射器）**、**联盟** 避免 iBGP 全互联

### 5 种报文

| 报文 | 作用 |
|------|------|
| **OPEN** | 建立邻居、协商参数 |
| **UPDATE** | 发路由 / **撤销**路由（**增量更新**） |
| **KEEPALIVE** | 保活，维持邻居 |

| **ROUTE-REFRESH** | 重新请求路由 |

### 6 个状态

```text
Idle → Connect → Active → OpenSent → OpenConfirm → Established（正常）
```

<a id="ch5-3-bgp-selection"></a>

## 七、BGP 选路规则（13 条 · 前 6 必考）

多条路径到同一前缀时，**按顺序比，先赢者优先，后面不再比**。

| # | 规则 | 原则 |
|---|------|------|
| 1 | **Weight**（Cisco 私有） | **越大越好**（仅本机） |
| 2 | **Local_Pref** | **越大越好**（整个 AS） |
| 3 | **本地生成的路由** | network > 重分发 > 聚合 |
| 4 | **AS-Path 最短** | 经过 AS **越少越好** |
| 5 | **Origin** | **i**（IGP）< **e**（EGP）< **?**（未知） |
| 6 | **MED** | **越小越好**（影响邻居 AS 选路） |
| 7–13 | Router ID、邻居类型等 | 一般不考 |

**一句话**：**先策略（Weight/Local_Pref）→ 再 AS-Path 短 → 再 Origin/MED 等。**

#### 选路口诀（前 6）

```text
Weight本地大优先，LocalPref整网大
本地生成排第三，AS-Path短者胜
Origin i<e<?，MED越小越优
```

#### 简单例子

同一前缀两条路：

| 路径 | Local_Pref | AS-Path |
|------|------------|---------|
| A | **200** | 3 个 AS |
| B | 100 | **2 个 AS |

→ 先比 Local_Pref → **选 A**（200 > 100），**不再比** AS-Path。

<a id="ch5-3-bgp-policy"></a>

## 八、BGP 选路原则（策略本质）

**不单纯**以距离、带宽判定「最优」路径（详见 [#ch5-3-bgp-selection](#ch5-3-bgp-selection)）。

优先按：

- **商业策略**（客户 / 对等 / 提供商关系）  
- **路由优先级**（**Local_Pref** 越大越优先出 AS）  
- **AS-Path 长度**、MED、前缀过滤等  

**热土豆（Hot Potato）**：尽快把流量交给**邻居 AS**，减少本 AS 承载。

<a id="ch5-3-bgp-exam"></a>

## 九、必考核心考点 · 考试背诵

### 三句话必背

1. **BGP 是路径向量协议，用 TCP 179，负责 AS 间路由。**  
2. **选路顺序：先策略（Local_Pref/Weight）→ 再 AS-Path 最短 → 其他。**  
3. **eBGP 靠 AS-Path 防环；iBGP 靠水平分割防环。**  
4. **未知外网网段：BGP 无明细 → 默认路由接力；收敛后走 BGP 精确路由。**

### 四句口诀

```text
BGP边界跨AS间，TCP179路径向量
AS-Path防环路，eBGP外iBGP内
选路先策略后路径，LocalPref大AS-Path短
OSPF讲效率BGP讲策略，iBGP水平分割防环
```

### 30 字

**BGP：路径向量、EGP、TCP179；先策略后 AS-Path；eBGP 外 iBGP 内；非纯最短。**

### 考点速记

| 点 | 一句 |
|----|------|
| 定位 | **EGP**，**不同 AS** 间，**路径向量** |
| vs OSPF | OSPF=**IGP/LS/最短**；BGP=**EGP/PV/策略** |
| 防环 | **eBGP**：AS-Path 见己 AS 拒；**iBGP**：水平分割/RR/联盟 → [#ch5-3-as-path-loop](#ch5-3-as-path-loop) |
| 邻居 | **eBGP（E）** 跨 AS；**iBGP（I）** 同 AS 内传全外网路由 |
| e/i 分工 | **e 出国 · i 国内通知 · IGP 国内导航** → [#ch5-3-ebgp-ibgp](#ch5-3-ebgp-ibgp) |
| 未知网段 | **无 BGP 明细** → **默认路由**接力；发布后走 **BGP 精确路由** → [#ch5-3-unknown-prefix-forward](#ch5-3-unknown-prefix-forward) |
| 封装 | **TCP 179**（OSPF 是 **IP 89**） |
| 选路 | [#ch5-3-bgp-selection](#ch5-3-bgp-selection) 前 6 条 |

### 易错点

| 易混 | 纠正 |
|------|------|
| BGP 追求最短路径？ | **否**；**策略与商业关系**优先 |
| BGP 用 UDP？ | **否**；**TCP 179** |
| AS-Path 防什么环？ | **AS 间 eBGP**；**iBGP 不靠 AS-Path** |
| iBGP 靠 AS-Path 防环？ | **否**；**水平分割 / RR / 联盟** |
| iBGP = 不同 AS？ | **否**；**同 AS 内**；跨 AS 是 **eBGP（E）** |
| BGP 只管 AS 之间？ | **否**；还需 **iBGP** 在 AS 内同步，否则**黑洞** |
| 没 BGP 路由外网不通？ | **否**；边界**默认路由**可兜底（无默认才丢） |
| iBGP 怎么防环？ | **水平分割**（iBGP 路由不传给其他 iBGP） |
| 目录 5.3 vs 章 §5.4 | 目录 **5.3=BGP 精读**；章 **§5.4=BGP** 概述 |
