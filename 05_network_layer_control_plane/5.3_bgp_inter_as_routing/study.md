# 5.3 BGP 自治系统间路由

> 章级精读：[§5.4 BGP](../study.md#ch5-4) · **通俗版**：[#ch5-3-bgp-simple](#ch5-3-bgp-simple) · [快递公司版](#ch5-3-bgp-courier) · [选路规则](#ch5-3-bgp-selection) · AS 内：[5.2 OSPF](../5.2_ospf_intra_as_routing/study.md) · [AS≠IGP](../5.1_routing_algorithm/study.md#ch5-1-as-vs-igp)

## 本节核心目标

掌握 **BGP（EGP）** 定位、**路径向量**、**TCP 179**、**AS-Path 防环**、**eBGP/iBGP**、**选路 13 条（前 6 必考）** 及与 **OSPF** 对比。

> **总纲**：BGP **不算最快路径，算最符合策略的路径**；**路径向量**协议，**TCP 179**，负责 **AS 间选路**。

<a id="ch5-3-bgp-simple"></a>

## 〇、新手易懂：BGP 是什么

**BGP = Border Gateway Protocol（边界网关协议）**

| 项 | 说明 |
|----|------|
| 类型 | **EGP** — 连接**不同 AS**（运营商/大公司） |
| 地位 | **互联网核心协议**，全球运营商靠它互通 |

**类比**

| 协议 | 比喻 |
|------|------|
| **OSPF/RIP（IGP）** | 城市**内部**交通规则（找最短/最快路） |
| **BGP** | 城市**之间**物流协议（优先政策、商业、成本，**不只看远近**） |

**终极对比一句**：**OSPF 讲效率，BGP 讲政治（策略）。**

---

<a id="ch5-3-bgp-courier"></a>

### 超通俗新手版：快递公司类比

把每个 **AS** 看成一家**独立大型快递公司**：

| 范围 | 用什么 | 比喻 |
|------|--------|------|
| **AS 内部**送货 | **OSPF / RIP（IGP）** | 自家公司内部路线 |
| **公司之间**收发包裹 | **BGP** | 不同快递公司互相通报路线、约定怎么走 |

BGP 专门管：**各家大型网络之间**互相通报路线、按规则选路。

#### 1）三个基础特点

| 特点 | 大白话 | 技术对应 |
|------|--------|----------|
| **沟通稳定** | 两家公司**打电话**（线路稳、不乱） | **TCP 179** |
| **记录全程** | 包裹路线写清经过哪些公司 | **AS-Path**（A→B→C） |
| **天生防绕圈** | 路线兜回**自家公司** → **拒收** | AS-Path **见己 AS 丢弃** |

#### 2）选路逻辑（和内网最大区别）

| | OSPF（内网） | BGP（外网） |
|---|-------------|------------|
| 看什么 | **速度最快、距离最近** | **规矩、成本、合作关系** |
| 顺序（大白话） | 算最短 | ① 自家**优先路线** → ② 经过公司**越少越好** → ③ 来源/成本 |

→ 不是近就走；**综合选最合适通路** → 精编：[#ch5-3-bgp-selection](#ch5-3-bgp-selection)

#### 3）两种邻居

| 类型 | 大白话 | 作用 |
|------|--------|------|
| **eBGP** | **跨公司**打交道 | 不同 AS 设备交换**外网**线路 |
| **iBGP** | **公司内部**互通 | 把外部路线**传遍本 AS** 所有设备 |

#### 4）五句总结

1. **管范围**：只管**不同大型网络之间**互通  
2. **核心本事**：记**完整行进路线**（AS-Path），按**商业和规则**选路  
3. **内网找近路** → OSPF/RIP  
4. **外网跨区域、按规则选路** → BGP  
5. **TCP 179 + 路径向量 + 策略优先**

→ 与 [5.1 AS≠IGP 城市口诀](../5.1_routing_algorithm/study.md#ch5-1-as-vs-igp) 对照：**城内 IGP，城城 BGP**

<a id="ch5-3-bgp-basics"></a>

## 一、BGP 基础定位（必背）

**BGP**（Border Gateway Protocol，**边界网关协议**）

| 项 | 说明 |
|----|------|
| **协议类型** | **EGP 外部网关协议** — 作用于**不同 AS（自治系统）**之间 |
| **地位** | **互联网骨干核心协议**；全球跨运营商路由互通的「黏合剂」 |
| **选路本质** | **策略驱动**（非单纯最短路径/最短跳） |
| **算法类型** | **路径向量（Path Vector）** — 见 [#ch5-3-path-vector](#ch5-3-path-vector) |

一句话：**AS 之间怎么通、走谁家线路，由 BGP 按策略说了算。**

---

<a id="ch5-3-path-vector"></a>

## 二、路径向量与 AS-Path（必考）

### 和 RIP / OSPF 的区别

| 协议 | 类型 | 传什么 |
|------|------|--------|
| **RIP** | **距离矢量 DV** | 只告诉邻居「我到目标**多远**」 |
| **OSPF** | **链路状态 LS** | 全网拓扑图，算**最短路径** |
| **BGP** | **路径向量 PV** | 不仅「我能到」，还带**整条经过的 AS 列表** |

### AS-Path 例子

```text
AS100 → AS200 → AS300（目标）
通告路由时 AS-Path = [100, 200]
```

| 规则 | 说明 |
|------|------|
| **防环** | 收到路由若 **AS-Path 含自己的 AS 号** → **丢弃** |
| 结论 | **BGP 天然防 AS 级环路**（域内环靠 IGP） |

---

<a id="ch5-3-bgp-vs-ospf"></a>

## 三、BGP 与 OSPF 核心区别（必考表）

| 对比维度 | **OSPF（IGP）** | **BGP（EGP）** |
|----------|-----------------|----------------|
| **适用范围** | **同一 AS 内部** | **不同 AS 之间** |
| **核心算法/思路** | **链路状态**、最短路径（SPF） | **路径向量**、**策略**选路 |
| **设计目标** | 转发性能、时延最优 | **路由可控**、安全合规、**商业策略优先** |
| **封装** | **IP 协议号 89**（无 TCP/UDP） | **TCP 179** |

→ OSPF 精读：[5.2](../5.2_ospf_intra_as_routing/study.md#ch5-2-ospf-exam)

<a id="ch5-3-bgp-features"></a>

## 四、BGP 核心特性

| # | 特性 |
|---|------|
| 1 | 依托 **TCP 179** 建立邻居，**可靠**传输 UPDATE 等报文 |
| 2 | 路由携带 **AS-Path**（途经 AS 号列表）→ **天然防 AS 级环路** |
| 3 | 丰富**路径属性**：AS-Path、**Next_Hop**、**Local_Pref**、MED 等 |
| 4 | **策略能力强**：路由过滤、策略路由、优先级修改（import/export policy） |

### 封装对比（考试常考）

| 协议 | 类型 | 承载 |
|------|------|------|
| OSPF | IGP | **IP 89** |
| RIP | IGP | UDP 520 |
| **BGP** | EGP | **TCP 179** |

---

<a id="ch5-3-bgp-neighbor"></a>

## 五、BGP 两大邻居类型

| 类型 | 定义 | 典型场景 |
|------|------|----------|
| **eBGP** | **不同 AS** 之间建立的 BGP 邻居 | ISP 对等、跨运营商边界；**靠 AS-Path 防环** |
| **iBGP** | **同一 AS 内部** 建立的 BGP 邻居 | 把 eBGP 学到的前缀**传遍整个 AS** |

**iBGP 防环要点**

- **水平分割**：从 **iBGP** 学到的路由，**不再发给其他 iBGP 邻居**（防 AS 内 BGP 环）
- 下一跳常不自动改 → 需 **IGP 可达** 或策略调整
- 大规模 AS 常用 **RR（路由反射器）**、**联盟** 避免 iBGP 全互联

<a id="ch5-3-bgp-messages"></a>

## 六、BGP 报文与状态（了解）

### 5 种报文

| 报文 | 作用 |
|------|------|
| **OPEN** | 建立邻居、协商参数 |
| **UPDATE** | 发路由 / **撤销**路由（**增量更新**） |
| **KEEPALIVE** | 保活，维持邻居 |
| **NOTIFICATION** | 出错、断开连接 |
| **ROUTE-REFRESH** | 重新请求路由 |

### 6 个状态

```text
Idle → Connect → Active → OpenSent → OpenConfirm → Established（正常）
```

<a id="ch5-3-bgp-selection"></a>

## 七、BGP 选路规则（13 条 · 前 6 必考）

多条路径到同一前缀时，**按顺序比，先赢者优先，后面不再比**。

| # | 规则 | 原则 |
|---|------|------|
| 1 | **Weight**（Cisco 私有） | **越大越好**（仅本机） |
| 2 | **Local_Pref** | **越大越好**（整个 AS） |
| 3 | **本地生成的路由** | network > 重分发 > 聚合 |
| 4 | **AS-Path 最短** | 经过 AS **越少越好** |
| 5 | **Origin** | **i**（IGP）< **e**（EGP）< **?**（未知） |
| 6 | **MED** | **越小越好**（影响邻居 AS 选路） |
| 7–13 | Router ID、邻居类型等 | 一般不考 |

**一句话**：**先策略（Weight/Local_Pref）→ 再 AS-Path 短 → 再 Origin/MED 等。**

#### 选路口诀（前 6）

```text
Weight本地大优先，LocalPref整网大
本地生成排第三，AS-Path短者胜
Origin i<e<?，MED越小越优
```

#### 简单例子

同一前缀两条路：

| 路径 | Local_Pref | AS-Path |
|------|------------|---------|
| A | **200** | 3 个 AS |
| B | 100 | **2 个 AS |

→ 先比 Local_Pref → **选 A**（200 > 100），**不再比** AS-Path。

<a id="ch5-3-bgp-policy"></a>

## 八、BGP 选路原则（策略本质）

**不单纯**以距离、带宽判定「最优」路径（详见 [#ch5-3-bgp-selection](#ch5-3-bgp-selection)）。

优先按：

- **商业策略**（客户 / 对等 / 提供商关系）  
- **路由优先级**（**Local_Pref** 越大越优先出 AS）  
- **AS-Path 长度**、MED、前缀过滤等  

**热土豆（Hot Potato）**：尽快把流量交给**邻居 AS**，减少本 AS 承载。

<a id="ch5-3-bgp-exam"></a>

## 九、必考核心考点 · 考试背诵

### 三句话必背

1. **BGP 是路径向量协议，用 TCP 179，负责 AS 间路由。**  
2. **选路顺序：先策略（Local_Pref/Weight）→ 再 AS-Path 最短 → 其他。**  
3. **eBGP 靠 AS-Path 防环；iBGP 靠水平分割防环。**

### 四句口诀

```text
BGP边界跨AS间，TCP179路径向量
AS-Path防环路，eBGP外iBGP内
选路先策略后路径，LocalPref大AS-Path短
OSPF讲效率BGP讲策略，iBGP水平分割防环
```

### 30 字

**BGP：路径向量、EGP、TCP179；先策略后 AS-Path；eBGP 外 iBGP 内；非纯最短。**

### 考点速记

| 点 | 一句 |
|----|------|
| 定位 | **EGP**，**不同 AS** 间，**路径向量** |
| vs OSPF | OSPF=**IGP/LS/最短**；BGP=**EGP/PV/策略** |
| 防环 | **eBGP**：AS-Path 见己 AS 拒；**iBGP**：水平分割 |
| 邻居 | **eBGP** 跨 AS；**iBGP** 同 AS 内 |
| 封装 | **TCP 179**（OSPF 是 **IP 89**） |
| 选路 | [#ch5-3-bgp-selection](#ch5-3-bgp-selection) 前 6 条 |

### 易错点

| 易混 | 纠正 |
|------|------|
| BGP 追求最短路径？ | **否**；**策略与商业关系**优先 |
| BGP 用 UDP？ | **否**；**TCP 179** |
| AS-Path 防什么环？ | **AS 级**环路；域内环路由靠 IGP |
| iBGP = 不同 AS？ | **否**；**同 AS 内**；跨 AS 是 **eBGP** |
| iBGP 怎么防环？ | **水平分割**（iBGP 路由不传给其他 iBGP） |
| 目录 5.3 vs 章 §5.4 | 目录 **5.3=BGP 精读**；章 **§5.4=BGP** 概述 |
