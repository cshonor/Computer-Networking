# 5.5 ICMP、SNMP 与网络管理

> 章级精读：[§5.6–5.8](../study.md#ch5-6)

## 一、ICMP 网际控制报文协议

### 基本定位

网络层辅助控制协议，承载于 IP 之上。

### 核心作用

1. **差错报告**：目的不可达、超时、参数错误
2. **网络探测与诊断**

### 经典工具

- **ping**：ICMP Echo 请求与应答
- **traceroute**：利用 TTL 超时探测完整路径

### 常见 ICMP 报文类型

| 类型 | 含义 |
|------|------|
| 0 | Echo Reply 回显应答 |
| 8 | Echo Request 回显请求 |
| 3 | 目的不可达 |
| 11 | 超时 |

## 二、SNMP 简单网络管理协议

### 定位

应用层网络管理协议，用于监控、配置全网网络设备。

### 核心架构

1. **NMS** 网管工作站（管理者）
2. 设备上 **SNMP Agent**（代理）
3. **MIB** 管理信息库，设备可监控参数集合

### SNMP 版本

- **v1**：最早、安全性弱
- **v2c**：增强性能
- **v3**：强加密、身份认证，生产主流

## 三、其他网络管理协议

- RMON、NETCONF、Telemetry

## 四、本节总结

- **ICMP**：网络层连通性与差错控制
- **SNMP**：全网设备状态监控与运维管理
