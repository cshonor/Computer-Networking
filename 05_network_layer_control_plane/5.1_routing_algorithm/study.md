# 5.1 路由算法与控制平面概述

> 章级精读：[控制平面基础](../study.md#ch5-control-plane-basics) · [§5.1 概述](../study.md#ch5-1) · [§5.2 路由算法](../study.md#ch5-2)

## 本节核心目标

理解控制平面如何决策，并掌握 LS/DV 两类路由算法。

## 核心知识点

1. **控制平面**：决策与管理，不算路转发用户包；生成 RIB、下发 FIB
2. **数据平面**：按 FIB 高速转发（见第 4 章）
3. **链路状态 LS**：全局拓扑 + Dijkstra（OSPF 思路）
4. **距离向量 DV**：Bellman-Ford，与邻居交换向量（RIP 思路）
5. **传统分布式 vs SDN**：控制逻辑在每台设备 vs 逻辑集中控制器

## 个人总结

控制平面是大脑定路线，路由算法是大脑里的算路引擎；算完的路要变成转发表，数据平面才能无脑转发。
