## 本节核心目标

掌握 **LS vs DV**、静态/动态路由、度量与**路由收敛**；能默写对比表并手算 **Dijkstra / Bellman-Ford** 例题。

<a id="ch5-1-classify"></a>

## 一、路由算法分类

### 1）按信息获取方式

| 类型 | 别名 | 原理 |
|------|------|------|
| **全局路由** | **链路状态 LS** | 全网拓扑**完整公开**；每台路由器**独立**算最短路径 |
| **分布式路由** | **距离矢量 DV** | 仅与**邻居**交换路由信息；**逐步迭代**学习路径 |

### 2）按配置方式

| 类型 | 特点 | 适用 |
|------|------|------|
| **静态路由** | **手动配置**，固定不变 | 小型、拓扑稳定的网络 |
| **动态路由** | **自动发现**拓扑、**自动更新**路由 | 大型、复杂、常变化网络 |

<a id="ch5-1-ls"></a>

## 二、链路状态算法 LS（必考）

| 项 | 内容 |
|----|------|
| **代表协议** | **OSPF**（AS 内 IGP）→ [5.2](../5.2_ospf_intra_as_routing/study.md) |
| **核心原理** | 全网**泛洪**拓扑信息（LSA）；每台路由器独立运行 **Dijkstra** 算最短路径 → [手算步骤+例题](#ch5-1-dijkstra) |
| **特点** | **全网视野清晰**；收敛通常较快；**不易长期环路** |
| **缺点** | 状态/报文开销大；配置与区域划分较复杂 |

```text
泛洪拓扑 → 各机建图 → Dijkstra → 本地转发表/FIB
```

---

<a id="ch5-1-dv"></a>

## 三、距离矢量算法 DV（必考）

| 项 | 内容 |
|----|------|
| **代表协议** | **RIP**（教材经典；现网 AS 内多用 OSPF/IS-IS） |
| **核心原理** | **周期性**向邻居传递 **距离 + 下一跳**；**Bellman-Ford** 迭代收敛 → [手算步骤+例题](#ch5-1-bellman-ford) |
| **固有缺陷** | **坏消息传得慢**；**计数到无穷大**；易形成**路由环路** |
| **优化** | **水平分割**、**毒性逆转（Poison Reverse）** |

**Bellman-Ford 方程（记形式）**

```text
d_x(y) = min_v { c(x,v) + d_v(y) }   （v 为 x 的邻居）
```

## 四、最短路径度量值

选路依据（**Cost** 可组合策略）：**跳数、带宽、时延、开销、负载** 等。

> 权值若与**瞬时负载**强绑定，可能引发**路由震荡**（章级 [#ch5-2](../study.md#ch5-2)）。

<a id="ch5-1-convergence"></a>

## 五、路由收敛

**定义**：网络拓扑发生变化后，全网所有路由器路由信息达成**统一、稳定**状态的全过程。

- LS：拓扑更新 → LSA 泛洪 → 重算 Dijkstra  
- DV：邻居向量变化 → 多轮迭代直至稳定（收敛前可能有**临时环路**）

## 六、核心考点对比表（考试常考）

| 路由算法 | 代表协议 | 优点 | 缺点 |
|----------|----------|------|------|
| **链路状态 LS** | **OSPF** | **无路由环路**（稳态）、**收敛快** | 开销大、配置复杂 |
| **距离矢量 DV** | **RIP** | 逻辑简单、**易部署** | **收敛慢**、**极易环路** |

### LS vs DV 速记（补充）

| 维度 | LS | DV |
|------|----|----|
| 信息范围 | 近似**全局拓扑** | 仅**邻居向量** |
| 算法 | **Dijkstra** | **Bellman-Ford** |
| 通信 | LSA **泛洪** | 与邻居**周期交换** |

<a id="ch5-1-dijkstra"></a>

## 附一、Dijkstra 最短路径（贪心 · 非负权）

### 适用条件

- 边权 **≥ 0**（**不能有负权**）
- **单源**：从一个起点到所有顶点最短路

### 核心思想

每次选**当前距离最小且未确定**的顶点 u，用 u **松弛**所有邻居 v。

### 考试标准步骤

1. **初始化**：`dist[起点]=0`，其余 `∞`；集合 **S**（已确定最短路）= ∅；可选 `prev[]` 记前驱  
2. **循环 n 次**（n = 顶点数）：  
   - ① 在 **S 外**选 `dist[u]` **最小**的 u  
   - ② u **加入 S**  
   - ③ 对每条边 u→v、权 w：若 `dist[v] > dist[u]+w`，则 `dist[v]=dist[u]+w`，`prev[v]=u`  
3. 结束，`dist[]` 即为最短路长度

**口诀**：**选最小、入 S、松邻居、非负权**

---

### 例题 1（手算必练 · 无向图）

顶点 **1～5**，边权（无向，按双向处理）：

| 边 | 权 |
|----|-----|
| 1‑2 | 2 |
| 1‑3 | 1 |
| 2‑4 | 3 |
| 3‑4 | 2 |
| 3‑5 | 4 |
| 4‑5 | 1 |

**求**：从 **1** 到各点最短路。

**初始**：`dist = [0, ∞, ∞, ∞, ∞]`（1,2,3,4,5），`S=∅`

| 轮次 | 选 u | 松弛 | dist | S |
|------|------|------|------|---|
| 1 | **1**(0) | 1→2:2；1→3:1 | [0,2,1,∞,∞] | {1} |
| 2 | **3**(1) | 3→4:3；3→5:5 | [0,2,1,3,5] | {1,3} |
| 3 | **2**(2) | 2→4:5>3 不更新 | 不变 | {1,3,2} |
| 4 | **4**(3) | 4→5:4<5 → 5=4 | [0,2,1,3,4] | {1,3,2,4} |
| 5 | **5**(4) | 无出边 | 不变 | 全入 S |

**结果**

| 目的 | 距离 | 路径 |
|------|------|------|
| 1 | 0 | 1 |
| 2 | 2 | 1‑2 |
| 3 | 1 | 1‑3 |
| 4 | 3 | 1‑3‑4 |
| 5 | 4 | 1‑3‑4‑5 |

---

<a id="ch5-1-bellman-ford"></a>

## 附二、Bellman-Ford（可负权 · 判负环）

### 适用条件

- 可有**负权边**；不能有**负权环**（否则最短路无下界）
- **单源**最短路 + **负环检测**

### 核心思想

对**所有边**反复松弛 **n−1 轮**；第 **n 轮**仍能更新 → 存在**负权环**。

### 考试标准步骤

1. `dist[s]=0`，其余 `∞`  
2. **松弛 n−1 轮**：每轮扫描**每一条边** (u→v, w)，若 `dist[v] > dist[u]+w` 则更新  
3. **第 n 轮**：再扫全部边，若还能更新 → **有负权环**

**口诀**：**n−1 轮、全边松、第 n 轮、判负环**

---

### 例题 2（含负权 · 有向图）

顶点：**s, t, y, z, x**

| 边 | 权 |
|----|-----|
| s→t | 6 |
| s→y | 7 |
| t→y | **−2** |
| t→z | 5 |
| y→z | **−3** |
| y→x | 4 |
| z→x | 2 |

**求**：从 **s** 出发最短路，并判断负环。

**初始**：`dist = [0, ∞, ∞, ∞, ∞]`（s,t,y,z,x）

**第 1 轮**（按边扫描，关键更新）

- s→t：6；s→y：7  
- t→y：6−2=**5** < 7  
- t→z：11；y→z：5−3=**2** < 11  
- y→x：9；z→x：2+2=**4** < 9  

→ `dist = [0, 6, 5, 2, 4]`

**第 2～4 轮**：继续全边松弛，**不再变化** → 收敛。

**第 5 轮（负环检测）**：所有边均不能更新 → **无负权环**。

**结果**

| 目的 | 距离 | 路径 |
|------|------|------|
| t | 6 | s→t |
| y | 5 | s→t→y |
| z | 2 | s→t→y→z |
| x | 4 | s→t→y→z→x |

---

<a id="ch5-1-algo-compare"></a>

## 附三、Dijkstra vs Bellman-Ford（必背）

| 项目 | Dijkstra | Bellman-Ford |
|------|----------|----------------|
| **权值** | **非负** | **可负** |
| **负环** | 不判 | **第 n 轮可判** |
| **复杂度** | O(m log n)（堆优化） | **O(n·m)** |
| **路由** | **OSPF（LS）** | **RIP（DV）** |
| **特点** | 快、简单 | 慢、能处理负权 |

<a id="ch5-1-walkthrough"></a>

## 附五、详细分步实例讲解（ABCD 拓扑）

<a id="ch5-1-dist-mapping"></a>

### 核心结论（先看这个）

1. **Dijkstra 与 Bellman-Ford 一样**：`dist[]` 的下标顺序是**人为约定**的，**下标 0 固定对应起点 A**，与节点一一对应，全程不变。
2. **最关键区别**：**Dijkstra 有确定集 S**；**Bellman-Ford 没有确定集**。
3. **数组与节点的映射规则**，两套算法**完全相同**；差别只在「有没有 S」以及「数值能否被反复刷新」。

---

#### 一、Dijkstra：数组 + 确定集

约定节点顺序：`[A, B, C, D, E]`（手算可只用 A～D，规则相同）

| 下标 | 节点 | 含义 |
|------|------|------|
| 0 | **A** | 起点，恒为 `dist[0]=0` |
| 1 | B | `dist[1]` |
| 2 | C | `dist[2]` |
| … | … | … |

- **确定集 S**：已敲定最短路的节点；**S 里元素的顺序** = 被确认的**先后次序**（≠ 实际走路顺序）。
- 节点**一旦入 S**，其 `dist[i]` **不再改动**。

**举例**：`dist = [0, 2, 3, 4, 7]` → 0→A，1→B，2→C，3→D，4→E；若 `S` 依次为 `{A}→{A,B}→{A,B,C}`，表示 C 是第三个被「盖章」的节点。

---

#### 二、Bellman-Ford：数组相同，无确定集

- **下标映射与 Dijkstra 一模一样**：`dist[0]` 永远是起点 A，后面依次 B、C、D、E。
- **从头到尾没有 S / U**：所有节点的距离在 **n−1 轮**（及负环检测轮）里**都可能被改小**；没有「入集即锁定」。
- 只有**数字在变**，**下标对应的节点身份不变**；负权、反复松弛也不会打乱下标↔节点关系。

---

#### 三、5 节点直观对照

排布：0→A(起点)，1→B，2→C，3→D，4→E；写法统一为 `dist[A], dist[B], …` 或 `dist[0]…dist[4]`。

| | Dijkstra | Bellman-Ford |
|--|----------|----------------|
| 下标↔节点 | 固定，0 永远是 A | **相同** |
| 额外结构 | **确定集 S** 按 A→B→C… 顺序「盖章」 | **无集合** |
| 数值 | 入 S 后该位**锁定** | 每轮扫边**可继续变小**（至收敛或发现负环） |

---

#### 四、一句话

- **下标规则**：两算法相同，**首位永远是起点 A**。
- **Dijkstra**：多一个 **S**，顺序 = 锁定先后的次序。
- **Bellman-Ford**：只有一直在变的 **dist[]**，**没有确定集**。

---

<a id="ch5-1-bf-rounds"></a>

### 贝尔曼-福特：每轮改什么、轮次代表什么（5 节点 A～E）

#### 两种算法做事差异（直白版）

| | Dijkstra | Bellman-Ford |
|--|----------|----------------|
| 节点状态 | 有 **确定集 S**；入 S 后距离**定死不改** | **全程无**「已确定」节点 |
| 顺序含义 | S 的顺序 = **锁定最短路**的先后 | **没有**节点锁定顺序 |
| 每步做什么 | 选最近未定节点，松弛其出边 | 每一轮把**所有边**挨个检查一遍 |
| 轮数 | 约 n 次「选点」 | **n−1 轮**全边松弛（5 节点 → **4 轮**）+ 可选第 5 轮判负环 |

---

#### 每一轮到底在改什么？

**只改一个东西**：起点到各节点的**最短距离数值** `dist[]`（下标↔节点映射不变，见上节）。

**松弛规则**（对每条边 u→v，权 w）：

```text
若 dist[u] + w < dist[v]  →  把 dist[v] 改小
```

没有其他操作；每轮就是反复刷新各点距离，越算越接近真最短（无负环时）。

---

#### 为何 5 个节点要循环 4 轮？

无重复绕圈时，简单路径最多经过 **n−1 = 4 条边**。因此：

| 轮次 | 本轮最多能「看透」的路径长度 |
|------|------------------------------|
| 第 1 轮 | 最多 **1 条边** 直达的距离 |
| 第 2 轮 | 最多 **2 条边** 串联的最短距离 |
| 第 3 轮 | 最多 **3 条边** |
| 第 4 轮 | 最多 **4 条边** |

4 轮跑完，所有**不绕圈**的可行路径都试过；若无负环，距离通常**不再变小**。

> **轮次数字的含义**：当前这一轮允许路径**最多经过几条边**——第 k 轮对应「最多 k 跳」的候选最短路。

---

#### 5 节点负权举例（看懂数值怎么变）

节点 **A**（起点）、B、C、D、E。有向边：

| 边 | 权 |
|----|-----|
| A→B | 3 |
| A→C | 6 |
| B→C | **−2** |
| C→D | 4 |
| D→E | 1 |

**初始**：`dist = [0, ∞, ∞, ∞, ∞]`（A,B,C,D,E）

| 轮次 | 本轮关键更新 | 轮末 dist |
|------|--------------|-----------|
| **1** | A→B:3；A→C:6 | 0, 3, 6, ∞, ∞ |
| **2** | A→B→C：3+(−2)=**1** < 6 → **改 dist[C]** | 0, 3, **1**, ∞, ∞ |
| **3** | C→D：1+4=5 | 0, 3, 1, **5**, ∞ |
| **4** | D→E：5+1=6 | 0, 3, 1, 5, **6** |

**第 5 轮（负环检测，可选）**：再扫全部边，若**仍能**改小任一 `dist` → 存在**负权环**；本例无环 → 数值稳定，最短路确定。

**负权边的作用**：正权边往往前几轮就算稳；**负权**会让后面轮次还能把距离**再压低**（绕经负边相当于「路程缩水」）。若 B↔C 等形成负环，则第 5 轮仍会不断刷新 → **无真正最短路径**。

---

#### 核心疑问：循环的「顺序」代表什么？

1. **BF 没有** Dijkstra 那种「节点确定先后」——只有 `dist[]` 数字在变。
2. **轮次** = 允许路径的**最大边数**上限，不是「先算 B 再算 C」的盖章顺序。
3. **负权** → 后几轮仍可能改小距离；**正权且无负环** → 4 轮后一般收敛。
4. **多跑一轮**：还能缩小 → **负环**；不能 → 各点最短路敲定。

---

#### 六、总结（BF 手算必记）

1. 每次循环只改：**起点到各节点的距离数值**。
2. 5 个点循环 **4** 轮 = 穷尽最多 **4** 段链路的路径方案。
3. **没有**节点锁定顺序，只有距离不断被优化。
4. **负权** + **第 n 轮检测** 是本算法相对 Dijkstra 的独有能力。

---

**统一场景（ABCD）**：节点 **A**（起点）、**B**、**C**、**D**；边权为路程开销，**全程无负权**时先完整演算 **Dijkstra**；再在同结构上加入负权边演算 **Bellman-Ford**（见下）。

### 拓扑（Dijkstra 用）

```text
    2       1
A ----→ B ----→ C
|       |  3    | 1
|   5   ↓       ↓
└----→ C ----→ D
```

| 边 | 权 |
|----|-----|
| A→B | 2 |
| A→C | 5 |
| B→C | 1 |
| B→D | 3 |
| C→D | 1 |

---

### 一、Dijkstra 详细演算

#### 核心概念

| 概念 | 含义 |
|------|------|
| **dist[]** | 起点到各节点当前最短距离；起点 0，其余初值 ∞ |
| **确定集 S** | 已**敲定**最短路的节点；入 S 后 dist **不再改** |
| **未确定集 U** | 剩余待算节点 |
| **S 的顺序** | 节点被**判定**最短路先后次序，**≠** 实际走路顺序 |

#### 初始化

`dist = [A:0, B:∞, C:∞, D:∞]`，`S = {}`，`U = {A,B,C,D}`

| 轮次 | 选 u | 入 S 后 | 松弛（关键） | dist |
|------|------|---------|--------------|------|
| 1 | **A**(0) | {A} | A→B:2；A→C:5 | 0,2,5,∞ |
| 2 | **B**(2) | {A,B} | B→C:3<5；B→D:5 | 0,2,3,5 |
| 3 | **C**(3) | {A,B,C} | C→D:4<5 | 0,2,3,4 |
| 4 | **D**(4) | {A,B,C,D} | — | 0,2,3,4 |

#### 最终结果

| 目的 | 距离 | 路径 |
|------|------|------|
| A | 0 | A |
| B | 2 | A→B |
| C | 3 | A→B→C |
| D | 4 | A→B→C→D |

#### 常见疑问

1. **S 顺序 A→B→C→D**：是算法**锁定**顺序，不是出行必须按此跳序走。
2. **入 S 即定型**：后续不会再被刷新。
3. **不能处理负权**：每轮选全局最小未定节点，负边会破坏「已定不变」假设。

---

### 二、Bellman-Ford 详细演算

#### 核心规则

1. **不划分** S / U
2. 最多 **n−1** 轮；本例 n=4 → **3 轮**全边松弛
3. 每轮遍历**每一条边**尝试更新
4. **第 n 轮**仍能更新 → **负权环**

#### 拓扑调整（加负权边）

在 Dijkstra 拓扑上增加 **C→B：-2**（其余边不变）。

边列表：`(A,B),(A,C),(B,C),(B,D),(C,B)`

`dist` 初值：`[A:0, B:∞, C:∞, D:∞]`

| 轮次 | 本轮结束 dist | 关键更新 |
|------|---------------|----------|
| 1 | 0,1,3,5 | C→B：3−2=1 刷新 B |
| 2 | 0,0,2,4 | C→B：2−2=0；B→C、B→D 改善 |
| 3 | 0,-1,1,3 | C→B：1−2=-1；B→C、B→D 再改善 |

#### 负环检测（第 4 轮）

再扫全部边**仍能**缩短距离 → 存在**负环**（本例 **B↔C** 可反复绕圈使开销无下界）。

#### 特点小结

| 项 | 说明 |
|----|------|
| 方式 | 反复遍历**所有边**，无「选最近点」 |
| 优势 | **可负权**；多一轮可**判负环** |
| 短板 | 慢于 Dijkstra |

---

### 三、两种算法对照（本例视角）

| 对比项 | Dijkstra | Bellman-Ford |
|--------|----------|----------------|
| 节点集合 | 确定集 S / 未定集 U | 无集合划分 |
| 权重 | **仅非负** | **可负** |
| 计算逻辑 | 每次选**最近未定**节点松弛 | 固定 **n−1** 轮、**逐边**松弛 |
| 负环 | 不能识别 | **第 n 轮**可检测 |
| 效率 | 快 | 偏慢 |
| S 的顺序 | 判定先后，**非行走路线** | 无此概念 |

> 标准步骤与另一套例题见 [#ch5-1-dijkstra](#ch5-1-dijkstra)、[#ch5-1-bellman-ford](#ch5-1-bellman-ford)。

## 附四、自练手算题（各 1 道 · 含答案）

### 练 1 · Dijkstra（起点 A）

有向图：A→B:1，A→C:4，B→C:2，B→D:5，C→D:1。求 **A** 到各点最短路。

<details>
<summary>答案要点</summary>

| 轮 | 选 | dist(A,B,C,D) |
|----|-----|----------------|
| 初 | — | 0,∞,∞,∞ |
| 1 | A | 0,1,4,∞ |
| 2 | B | 0,1,3,6 |
| 3 | C | 0,1,3,4 |
| 4 | D | 0,1,3,4 |

路径：A→B→C→D，A→D 距离 **4**。
</details>

### 练 2 · Bellman-Ford（判负环）

顶点 1,2,3；边：1→2:1，2→3:‑2，1→3:4。从 **1** 出发，判断是否有负环。

<details>
<summary>答案要点</summary>

n=3，松弛 2 轮后 dist=[0,1,‑1]。第 3 轮：边 2→3 仍可更新（1+(‑2)=‑1 已稳）→ 再检查 1→2→3 无改进；**无负环**。最短路：1→2→3 距离 **‑1**（若再加 3→1:‑2 则第 3 轮可更新 → **有负环**）。
</details>

## 七、考试背诵极简版

### 口诀

```text
LS全局泛洪Dijkstra，OSPF代表收敛快
DV邻居传矢量，RIP易环坏消息慢
静态手配小网用，动态大网自动算
度量跳数带宽时延，收敛全网路由稳
Dijkstra选最小松邻居；BF n-1轮判负环
```

### 30 字

**LS 泛洪+Dijkstra/OSPF 快；DV 邻居+RIP 易环；静态手配，动态自适应；拓扑变后要收敛。**

### 考点速记

| 点 | 一句 |
|----|------|
| LS | **全局拓扑** + **Dijkstra** → **OSPF** |
| DV | **距离矢量** + **Bellman-Ford** → **RIP** |
| DV 缺陷 | **坏消息慢、计数到无穷、环路** |
| DV 缓解 | **水平分割、毒性逆转** |
| 收敛 | 拓扑变后全网路由**一致稳定** |

### 易错点

| 易混 | 纠正 |
|------|------|
| OSPF = DV？ | **OSPF 是 LS**；RIP 才是经典 **DV** |
| LS 一定无环路？ | **稳态**无环；DV **收敛过程中**可有临时环 |
| 路由算法在数据平面？ | **控制平面**算路；数据平面只查 **FIB** 转发 |
| 5.1 目录 vs 章 §5.1 | 目录 **5.1=算法**；章 **§5.1=概述/SDN对比**，算法详述在 **§5.2** |
