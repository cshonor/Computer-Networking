# 第一部分 · 路由算法与协议（考点）

<a id="ch5-1-igp-egp"></a>

## 〇、IGP / EGP 与 AS（路由协议框架 · 必背）

> **路由协议 = 按「管理范围」分两大类：IGP、EGP**  
> **AS ≠ IGP**：AS 是**管辖范围**，IGP/BGP 是**跑在范围内的协议** → [#ch5-1-as-vs-igp](#ch5-1-as-vs-igp)

<a id="ch5-1-as-vs-igp"></a>

### 新手易懂：AS ≠ IGP（三个名词先拆清）

| 名词 | 是什么 | 类比 |
|------|--------|------|
| **AS 自治系统** | **管理范围** — 独立管控的大型网络整体 | **一座独立城市** |
| **IGP** | AS **里面**用的路由协议 | 城市**内部**道路怎么通行（OSPF/RIP） |
| **BGP** | AS **外面**互联用的路由协议 | **城市之间**怎么互通 |

```text
一城一网为 AS，
城内寻路用 IGP，
城城互通靠 BGP。
```

#### 1）AS 自治系统

| 项 | 说明 |
|----|------|
| 定义 | 同一公司/运营商**统一管理的整片网络** |
| 举例 | 移动全网一 AS、联通一 AS；大型企业全网也可算 AS |
| 特点 | 专属 **AS 编号（ASN）**，内部规则统一 |

#### 2）IGP 内部网关协议

| 项 | 说明 |
|----|------|
| 场景 | **同一个 AS「城里」** |
| 作用 | 让 AS 内路由器互相认识，**算最快路径** |
| 常见 | **OSPF、RIP、IS-IS** |
| 对应 | 内网、园区网、城域网**内部**转发 |

#### 3）BGP（EGP 主流）

| 项 | 说明 |
|----|------|
| 场景 | **不同 AS「城市之间」** |
| 作用 | AS 间**交换路由**，决定跨区域怎么走 |
| 主流 | **BGP**（边界网关协议） |
| 对应 | 运营商互联、跨国网络互通 |

#### 一句话对应

1. **在一个 AS 内部** → 跑 **IGP**，内网找路  
2. **多个 AS 互连** → 跑 **BGP**，外网互通  

#### 现实例子

| 场景 | 用什么 |
|------|--------|
| 家宽、小区、地市机房都在**移动 AS 内** | 设备间用 **OSPF/IGP** |
| 移动要与联通、电信传数据 | **不同 AS 对接** → **BGP** |

#### 易错纠正

| ❌ 误区 | ✅ 纠正 |
|---------|---------|
| AS = IGP？ | **否**；AS = **范围**，IGP/BGP = **协议** |
| AS = 局域网？ | **否**；家用小局域网**不算**标准 AS；运营商/大型企业全网才是 |
| AS ≠ 局域网 | 局域网是**小范围**；AS 是**大型自治管理域** |

---

### 一、大分类

| 类型 | 全称 | 范围 | 目标 | 典型 |
|------|------|------|------|------|
| **IGP** | Interior Gateway Protocol（**内部网关**） | **同一 AS 内** | 算内部最佳路径、**快收敛、无环** | **RIP、OSPF、IS-IS、EIGRP** |
| **EGP** | Exterior Gateway Protocol（**外部网关**） | **不同 AS 之间** | 传**可达性 + 策略**（选路、商业） | 现网主流 **BGP** |

---

### 二、AS（自治系统）是什么

**AS = 一个独立管理的网络整体**（像一个「国家」）

| 项 | 说明 |
|----|------|
| 管理 | **一个机构/运营商**统一管理（电信、移动、大厂…） |
| 对内 | 统一路由策略，跑 **IGP**（OSPF/RIP） |
| 对外 | 唯一 **AS 号（ASN）**，跑 **BGP** 与其他 AS 互联 |

**一句话**：**AS = 自治域；内部 IGP，外部 BGP。**

---

### 三、IGP 再细分（按算法 · 常考）

| 类型 | 代表 | 特点 | 缺点/优点 |
|------|------|------|-----------|
| **距离矢量 DV** | **RIP**、EIGRP（高级 DV） | **邻居传路由信息**；只知方向，**不知全网拓扑** | 收敛慢、易环；RIP **最大 15 跳** |
| **链路状态 LS** | **OSPF**、IS-IS | 传 **LSA**，全网同步 **LSDB 拓扑图** | 收敛快、无环、可划 **Area** |

→ 算法层：[#ch5-1-classify](#ch5-1-classify) · OSPF：[5.2](../5.2_ospf_intra_as_routing/study.md) · BGP：[5.3](../5.3_bgp_inter_as_routing/study.md)

---

### 四、IGP vs EGP 背诵

- **IGP（RIP/OSPF）**：AS **内**，选最佳路径，讲**「效率」**
- **EGP（BGP）**：AS **间**，传可达性 + 策略，讲**「规则/商业」**

**精准定义句**：**IGP — 仅用于同一 AS 内，负责 AS 内部路由计算与转发。**

### 五、协议速记卡（一页背完）

| 协议 | IGP/EGP | 算法 | 范围 | 封装 | 一句考点 |
|------|---------|------|------|------|----------|
| **RIP** | IGP | **DV** | AS 内 | **UDP 520** | 跳数度量、**最大 15 跳** |
| **OSPF** | IGP | **LS** | AS 内 | **IP 89**（无 TCP/UDP） | **Area 0**、LSA 泛洪、Dijkstra |
| **IS-IS** | IGP | **LS** | AS 内 | 链路层 | 运营商骨干常用 |
| **EIGRP** | IGP | 高级 **DV** | AS 内 | IP 88 | Cisco 私有→部分开放 |
| **BGP** | **EGP** | 路径矢量/策略 | **AS 间** | **TCP 179** | **AS-Path 防环**、eBGP/iBGP、策略选路 |

```text
AS 内：IGP（OSPF/RIP）算最短路
AS 间：BGP 讲策略、传可达性
```

## 一、路由算法分类（IGP 内部 · 按算法）

> 在 **IGP** 框架下，再按算法分 **LS** 与 **DV**（见 [#ch5-1-igp-egp](#ch5-1-igp-egp)）。

| 类型 | 别名 | 原理 |
|------|------|------|
| **全局路由** | **链路状态 LS** | 全网拓扑公开；各路由器**独立**算最短路 |
| **分布式路由** | **距离矢量 DV** | 仅与**邻居**交换路由；**迭代**学习 |

| 类型 | 特点 | 适用 |
|------|------|------|
| **静态路由** | 手动配置、固定 | 小型稳定网络 |
| **动态路由** | 自动发现、自动更新 | 大型复杂网络 |

<a id="ch5-1-ls"></a>

## 二、链路状态 LS（必考）

| 项 | 内容 |
|----|------|
| **代表协议** | **OSPF** → [5.2](../5.2_ospf_intra_as_routing/study.md) |
| **核心** | LSA **泛洪**拓扑 → 各机 **Dijkstra** → 转发表 |
| **优点** | 视野清晰、收敛快、稳态少环 |
| **缺点** | 开销大、配置复杂 |

<a id="ch5-1-dv"></a>

## 三、距离矢量 DV（必考）

| 项 | 内容 |
|----|------|
| **代表协议** | **RIP**（现网 AS 内多用 OSPF/IS-IS） |
| **核心** | 周期向邻居传 **距离+下一跳**；**Bellman-Ford** 收敛 |
| **缺陷** | 坏消息慢、计数到无穷、易环路 |
| **优化** | **水平分割**、**毒性逆转** |

```text
d_x(y) = min_v { c(x,v) + d_v(y) }
```

## 四、最短路径度量值

**Cost** 可含：跳数、带宽、时延、开销、负载。与瞬时负载强绑定可能**路由震荡**（[§5.2](../study.md#ch5-2)）。

<a id="ch5-1-convergence"></a>

## 五、路由收敛

拓扑变化后，全网路由达成**统一稳定**的过程。

- **LS**：LSA 泛洪 → 重算 Dijkstra  
- **DV**：邻居向量变化 → 多轮迭代（收敛前可有**临时环**）

## 六、LS vs DV 对比（考试常考）

| 路由算法 | 代表协议 | 优点 | 缺点 |
|----------|----------|------|------|
| **LS** | **OSPF** | 稳态无环、收敛快 | 开销大、配置复杂 |

# 第二部分 · 最短路径手算专题

<a id="ch5-1-overview-abcde"></a>
<a id="ch5-1-dist-mapping"></a>

## 七、统一约定与核心区别（A～E）

### 7.1 距离数组 `dist[]`

节点 **A（起点）、B、C、 D、 E**；下标**全程绑定不变**：

| 下标 | 0 | 1 | 2 | 3 | 4 |
|------|---|---|---|---|---|
| 节点 | **A** | B | C | D | E |

**含义**：`dist[i]` = 从 **A** 到该节点的**当前最短距离**（两算法相同）。

### 7.2 最关键区别（先看这个）

| | Dijkstra | Bellman-Ford |
|--|----------|----------------|
| **确定集 S** | **有**；入 S 后 `dist[i]` **锁死** | **无** |
| **一种「顺序」** | **S 存入顺序** = 最短路**确认先后**（≠ 走路顺序，≠ 数组重排） | **轮次** 1→2→3→4：第 k 轮≈最多 **k 条边**的路径 |
| **怎么算** | 反复「选最近未定节点 → 松弛邻居」 | 每轮**扫全部边**松弛，只改数字 |

> **极简一句**：数组排位一致，**首位必是 A**；Dijkstra 有**节点敲定顺序（S）**，BF 只有**轮次顺序**、无节点排序。

### 7.3 双算法总览

**Dijkstra**：确定集 S + 未确定集；初始化 `dist[A]=0` 其余 ∞ → 选最小未定节点入 S → 松弛直连边 → 循环；**仅正权**。

**Bellman-Ford**：无 S；**N 节点 → N−1 轮**（5 节点 **4 轮**）全边松弛；`dist[u]+w < dist[v]` 则改小 `dist[v]`；**可负权**；**第 N 轮**仍能更新 → **负环**。

| 对比维度 | Dijkstra | Bellman-Ford |
|----------|----------|--------------|
| 数组规则 | 下标固定，数值=从 A 出发距离 | **相同** |
| 计算方式 | 从已确定节点向外拓展 | 每轮全局扫全部边 |
| 数值状态 | 入 S 后不改 | 全程可多次优化 |
| 循环 | 逐个入 S 直至满 | 固定 **N−1** 轮 |
| 权重 | 仅正权 | 正权+负权 |

**认知四条**：① 共用 `dist` 规范，0 号位永远是 A；② Dijkstra 锁定后不变、向外拓；③ BF 无中心、反复扫边；④ 负权下 `dist[i]` 含义仍是「A 到该点路程」。

---

<a id="ch5-1-dijkstra"></a>

## 八、Dijkstra（附一）

**适用**：边权 **≥ 0**；**单源**最短路。

**步骤**：`dist[s]=0`，其余 ∞，`S=∅` → 循环 n 次：① S 外选 `dist` 最小 u ② u 入 S ③ 松弛 u 的所有出边。

**口诀**：选最小、入 S、松邻居、非负权。

---

<a id="ch5-1-walkthrough"></a>

### 8.1 ABCD 拓扑分步（正权 · 必练）

```text
    2       1
A ----→ B ----→ C
|   5   |  3    | 1
└----→ C ----→ D
```

| 边 | A→B:2 | A→C:5 | B→C:1 | B→D:3 | C→D:1 |

`dist` 用下标 0～3 对应 A,B,C,D。

| 轮 | 选 u | 入 S | 松弛要点 | dist |
|----|------|------|----------|------|
| 1 | A(0) | {A} | A→B:2；A→C:5 | 0,2,5,∞ |
| 2 | B(2) | {A,B} | B→C:3；B→D:5 | 0,2,3,5 |
| 3 | C(3) | {A,B,C} | C→D:4 | 0,2,3,4 |
| 4 | D(4) | 全 | — | 0,2,3,4 |

**结果**：A→B **2**，A→C **3**（A→B→C），A→D **4**（A→B→C→D）。**S 顺序 A→B→C→D** 是确认先后，不是走路必须按此跳序。

---

### 8.2 例题 1（无向图 · 顶点 1～5）

| 边 | 1‑2:2 | 1‑3:1 | 2‑4:3 | 3‑4:2 | 3‑5:4 | 4‑5:1 |

| 轮 | 选 u | dist | S |
|----|------|------|---|
| 1 | 1 | [0,2,1,∞,∞] | {1} |
| 2 | 3 | [0,2,1,3,5] | {1,3} |
| 3 | 2 | 不变 | {1,3,2} |
| 4 | 4 | [0,2,1,3,4] | +4 |
| 5 | 5 | 不变 | 全 |

最短路：2→**2**，3→**1**，4→**3**，5→**4**（路径 1‑3‑4‑5）。

## 九、Bellman-Ford（附二）

**适用**：可**负权**；无**负权环**；单源 + 负环检测。

**步骤**：`dist[s]=0` → **松弛 n−1 轮**（每轮扫**每条边**）→ **第 n 轮**仍能更新则有负环。

**口诀**：n−1 轮、全边松、第 n 轮、判负环。

### 9.1 每轮在改什么？（5 节点 → 4 轮）

**只改** `dist[]` 的**数值**；下标↔节点**不变**。

| 轮次 | 最多看透 |
|------|----------|
| 1 | **1 条边**直达 |
| 2 | **2 条边**中转 |
| 3 | **3 条边** |
| 4 | **4 条边**无环路径 |

### 9.2 五节点正权+负权链（A→E）

| 边 | A→B:3 | A→C:6 | B→C:**−2** | C→D:4 | D→E:1 |

| 轮 | 轮末 dist | 关键 |
|----|-----------|------|
| 1 | 0,3,6,∞,∞ | 直达 B、C |
| 2 | 0,3,**1**,∞,∞ | B→C 负权压到 1 |
| 3 | 0,3,1,**5**,∞ | C→D |
| 4 | 0,3,1,5,**6** | D→E |

第 5 轮不能再缩小 → **无负环**，最短路 A→E 为 **6**。

### 9.3 ABCD + C→B:−2（负环）

在 [8.1 拓扑](#ch5-1-walkthrough) 上加 **C→B:−2**，4 节点 → **3 轮**松弛后 `dist` 可达 `0,-1,1,3`；**第 4 轮**仍能更新 → **B↔C 负环**，无固定最短路。

### 9.4 例题 2（s,t,y,z,x · 无负环）

| 边 | s→t:6 | s→y:7 | t→y:**−2** | t→z:5 | y→z:**−3** | y→x:4 | z→x:2 |

第 1 轮后 `dist = [0,6,5,2,4]`，再松弛至稳定；第 5 轮无更新 → **无负环**。最短路：z **2**（s→t→y→z），x **4**。

## 十、Dijkstra vs Bellman-Ford（必背）

| 项目 | Dijkstra | Bellman-Ford |
|------|----------|----------------|
| 权值 | **非负** | **可负** |
| 负环 | 不判 | **第 n 轮可判** |
| 复杂度 | O(m log n) | O(n·m) |
| 路由 | **OSPF（LS）** | **RIP（DV）** |

## 十二、考试背诵

```text
LS泛洪Dijkstra/OSPF快；DV矢量RIP易环慢
静态手配小网；动态大网自适应；拓扑变要收敛
Dijkstra选最小入S松邻居；BF n-1轮全边松、第n轮判负环
dist下标0永远是起点；Dijkstra有S顺序，BF只有轮次无节点排序
```

| 易混 | 纠正 |
|------|------|
| OSPF = DV？ | **OSPF 是 LS** |
| LS 一定无环？ | **稳态**无环；DV 收敛中可有临时环 |
| 算路在哪？ | **控制平面**；转发查 **FIB** |
| dist 与 S | **S 顺序 ≠ 数组重排**；0 号位永远是起点 |
| SDN 算路？ | **算法不变**；控制器**全网全景**算、**任意起点**；交换机**只执行流表** → [#ch5-1-sdn-compute](#ch5-1-sdn-compute) |

<a id="ch5-1-sdn-compute"></a>

## SDN 与传统算路差异（通俗 · 跨节）

| | 传统 | SDN |
|---|------|-----|
| **谁算** | 每台路由器**各自** | **控制器集中** |
| **看见** | 局部（LSA/邻居） | **全网拓扑** |
| **起点** | 只能**以自己** | **任意节点** |
| **Dijkstra/BF** | 公式不变，**分散执行** | 公式不变，**集中执行**后 **OpenFlow 下发** |

**一句**：算法步骤没变；算路从「每台各自算」变成「控制器全景算、交换机只转发」。

→ 完整流程 + A→D 实例：[5.4 §五 SDN 算路](../5.4_sdn_controller_plane/study.md#ch5-4-routing-compute)
