# 5.1 — routing algorithm

## 知识点速记

- **控制平面**：路由/策略/编排；**数据平面**：查表转发（第 4 章）。  
- **范式**：每路由器分布式控制 ↔ **SDN** 逻辑集中 + 北向编程。  
- **LS**：全局拓扑 + Dijkstra；权值与负载耦合可**震荡**。  
- **DV**：Bellman-Ford 形式；**计数到无穷**；**毒性逆转**部分缓解。

## 与后端开发的联系

- 理解云 VPC 路由、Anycast LB、以及「为什么跨区贵」——背后是 **BGP 策略 + IGP**。
