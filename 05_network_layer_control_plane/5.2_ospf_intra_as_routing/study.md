# 5.2 OSPF 自治系统内部路由

> 章级精读：[§5.3 OSPF](../study.md#ch5-3)

## 一、OSPF 基础定位

- 开放式最短路径优先
- **IGP 内部网关协议**，用于同一个自治系统 AS 内部
- 基于链路状态 LS 算法
- 标准开放、厂商互通

## 二、OSPF 核心特点

1. 使用 IP 协议号 **89**，无传输层
2. 以开销（Cost）为度量，带宽越高开销越小
3. 支持区域划分（**Area 0** 骨干区域）
4. 支持认证、等价路由、分层架构
5. 全网同步 **LSA** 链路状态通告

## 三、OSPF 区域设计

- **Area 0 骨干区域**：所有非骨干区域必须与其直连
- **非骨干区域**：减少 LSA 泛洪范围，降低设备负载

## 四、OSPF 邻居建立过程

1. 发送 **Hello** 包，发现并建立邻居
2. 数据库描述 **DBD** 报文交互
3. **LSR/LSU/LSAck** 同步完整链路状态库
4. 同步完成，进入 **Full** 邻接状态
5. 运行 Dijkstra 计算最短路径，生成路由表

## 五、OSPF 优势 vs RIP

- 收敛速度快
- 无计数到无穷问题
- 支持大型复杂网络
- 层级化区域设计

## 六、本节易错点

- OSPF 是**链路状态**，RIP 是**距离矢量**
- 骨干区域 **Area 0** 不可缺失
