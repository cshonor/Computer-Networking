# 5.2 — ospf intra as routing

## 知识点速记

- **AS 内 IGP**；IP **协议号 89**；与 RIP/UDP、BGP/TCP 区分。  
- **LSA + SPF**；**区域**与 **Area 0 骨干**；**ABR / ASBR**。  
- 目的：扩展性、抑制泛洪、分层运维。

## 与后端开发的联系

- 数据中心 Underlay、园区网核心；与 **BFD、ECMP** 等常联合部署。
