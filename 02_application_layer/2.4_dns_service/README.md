# 2.4 — dns service

## 知识点速记

- **DNS**：名字 → IP（及 MX、CNAME 等）；分布式层次库。
- **层次**：根 → TLD → 权威；（**递归解析器** 常由 ISP/公共 DNS 提供）。
- **递归 vs 迭代**：减轻根负载的典型分工表述（实现可混合转发）。
- **RR**：`(Name, Value, Type, TTL)`；熟记 **A / NS / CNAME / MX**。
- **安全**：投毒/劫持防护思路（DNSSEC、可信解析、Anycast 等）。

## 与后端开发的联系

- 排查「域名偶发失败」：TTL、权威变更、解析链路、**HTTPS 证书与域名一致性**。
