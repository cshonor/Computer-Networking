# 2.1 — network application principle

## 知识点速记

- **应用层价值**：直接面向用户与创新；需求牵引底层（带宽、时延、CDN、QUIC 等）演进。
- **C/S vs P2P**：可扩展性、成本、治理与安全权衡；P2P 具自扩展潜力但运维复杂。
- **Socket**：进程 ↔ 运输层的 **API**；端点 = **IP + 端口**。
- **运输层需求四维**：可靠性、吞吐量、定时、安全（常结合 TLS 等）。

## 与后端开发的联系

- 设计微服务/API 网关时，先问：**协议、幂等、缓存、会话** 分别落在哪一层；别把「缓存策略」误当成「应用协议」。
