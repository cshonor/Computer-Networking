# 8.1 密码学基础

> 章级精读：[§8.1 安全概述](../study.md#ch8-1) · [§8.2 密码学](../study.md#ch8-2)

## 一、密码学核心目标

1. **机密性**：只有授权接收方才能理解数据内容
2. **完整性**：数据在传输过程中未被篡改
3. **身份认证**：确认通信双方的身份真实性
4. **不可否认性**：发送方无法否认自己发送过数据

## 二、对称密钥密码学

- 核心特点：加密和解密使用同一个密钥
- 典型算法：DES、3DES、**AES**（主流）
- 工作模式：ECB、CBC、CTR、GCM
- 优点：加密解密速度快，适合大量数据加密
- 缺点：密钥分发困难，N 个用户需要 N×(N−1)/2 个密钥

## 三、非对称密钥密码学（公钥密码学）

- 核心特点：每个用户有一对密钥，公钥公开，私钥保密
  - 公钥加密，私钥解密（机密性）
  - 私钥签名，公钥验证（身份认证/不可否认）
- 典型算法：RSA、ECC（椭圆曲线密码）
- 优点：密钥分发简单，无需提前共享密钥
- 缺点：计算速度慢，不适合直接加密大量数据

## 四、混合加密体系（实际主流方案）

- 用对称密钥加密大量数据（高效）
- 用接收方的公钥加密对称密钥（解决密钥分发问题）
- 典型应用：**HTTPS**、**IPsec**
