# 8.1 — basic cryptography

## 说明

本目录名侧重**密码学**；精读 **§8.1 网络安全概述** 为全章框架，见下方第一个链接。

## 知识点速记

- **四性**：机密性、完整性、鉴别、运行安全。  
- **Trudy 模型**：嗅探、注入、欺骗、重放。  
- **对称**：AES、模式（禁 ECB）、**混合加密**。  
- **公钥**：RSA/ECC 直觉；**会话密钥 + AES**。

## 与后端开发的联系

- 密钥轮换、KMS、HSM；选错模式或自造 MAC 会直接导致事故级漏洞。
