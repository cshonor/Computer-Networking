# 1.1 互联网概述

> 章级精读：[../study.md#ch1-1](../study.md#ch1-1)

## 本节核心目标

建立对互联网整体架构、基本概念的全局认知。

## 核心知识点

1. 区分 **internet**（泛指互联网络）与 **Internet**（特指全球互联网）
2. 互联网基本组成：端系统（主机）、通信链路、分组交换机、网络协议
3. ISP 层级结构：本地 ISP → 区域 ISP → 主干 ISP，构成全球互联底座
4. 网络通信两大模式：面向连接、无连接
5. 网络标准制定与管理组织：IETF、IEEE 等

## 个人总结

互联网本质是海量异构网络通过统一协议互联互通，分层协作实现全球数据交付。
