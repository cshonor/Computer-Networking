# 1.5 — protocol layer architecture

## 知识点速记

- **五层模型**：应用（报文）→ 运输（段）→ 网络（数据报）→ 链路（帧）→ 物理（比特）。
- **封装**：每层加首部；上层 PDU 对下层一律视为 **Payload**。
- **教材延续内容**：**1.6 安全**（恶意软件、DoS/DDoS、嗅探、IP 欺骗）、**1.7 历史**、**1.8 小结** 已写入章级 [study.md](../study.md)（本仓库未单独建子目录）。

## 与后端开发的联系

- 抓包时在 Wireshark 里看到的「一层包一层」，就是**封装**的现实对应；读报文首部从链路层一路展开到应用层是后端基本功。
