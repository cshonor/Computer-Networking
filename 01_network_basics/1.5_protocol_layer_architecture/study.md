# 1.5 协议分层与体系结构

> 章级精读：[../study.md#ch1-5](../study.md#ch1-5) · 封装实图：[../../04_network_layer_data_plane/study.md#ch4-encapsulation](../../04_network_layer_data_plane/study.md#ch4-encapsulation)

## 本节核心目标

掌握 TCP/IP 五层模型与封装解封装核心逻辑。

## 核心知识点

1. TCP/IP 五层自上而下：  
   应用层 → 运输层 → 网络层 → 数据链路层 → 物理层
2. 分层设计优点：模块化、解耦、易于开发排错、协议复用
3. 对等层通信：同层之间使用本层协议对话
4. 封装与解封装：
   - **发送**：逐层添加首部，数据由内向外嵌套
   - **接收**：逐层剥离首部，由外向内解析
5. 完整嵌套：应用数据 → TCP → IP → 以太网帧（**MAC 最外，TCP 最内**）

## 个人总结

分层 + 封装，是整个 TCP/IP 体系最核心的设计思想。
