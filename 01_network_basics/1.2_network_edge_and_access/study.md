# 1.2 网络边缘与接入

> 章级精读：[../study.md#ch1-2](../study.md#ch1-2)

## 本节核心目标

理解主机侧（网络边缘）如何接入互联网。

## 核心知识点

1. 网络边缘 = 所有终端主机、客户端与服务器
2. 主流接入方式：
   - 家庭接入：光纤、DSL、同轴电缆
   - 企业接入：有线以太网、局域网
   - 无线接入：WiFi、4G/5G
3. 传输介质：双绞线、光纤、无线信道
4. 两种应用架构：C/S 客户端-服务器、P2P 对等网络

## 个人总结

接入网负责把终端设备连接到网络核心，不同接入方式决定带宽、时延与适用场景。
