# 1.2 — network edge and access

## 知识点速记

- **网络边缘**：端系统 + **接入网**；接入带宽与形态直接决定体验上限。
- **住宅接入**：DSL（专用/不对称）、HFC（共享同轴）、FTTH、5G FWA（无线频谱共享）。
- **企业/DC**：以太网、Wi‑Fi；数据中心强调**高密互联、高吞吐、低时延**。
- **物理媒介**：导引型（双绞线、同轴、光纤）vs 非导引型（无线电、卫星）；**光纤**是长距离骨干主力。

## 与后端开发的联系

- 线上「慢」经常不在你的服务进程，而在**接入或公网路径**；要能区分接入瓶颈与服务器瓶颈。
