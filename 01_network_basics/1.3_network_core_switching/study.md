# 1.3 网络核心与交换技术

> 章级精读：[../study.md#ch1-3](../study.md#ch1-3)  
> 深化：**转发表/FIB** → [第 4 章 §4.4](../../04_network_layer_data_plane/study.md#ch4-fib) · **路由协议/RIB** → [第 5 章控制平面](../../05_network_layer_control_plane/study.md#ch5-control-plane-basics)

## 本节核心目标

弄懂网络核心的数据转发原理，分清**电路交换 / 分组交换**，理解**路由 vs 转发**，以及分组交换下的**数据报 vs 虚电路**。

---

## 一、网络核心（Network Core）

### 1）定义

由大量**路由器 + 交换机 + 高速光纤链路**组成的**全球转发骨干网**，负责把数据从源主机转发到目标主机。

### 2）核心功能

| 功能 | 含义 |
|------|------|
| **转发（Forwarding）** | 本地把分组从**入接口**换到**出接口** |
| **路由（Routing）** | 全局计算路径，生成/更新路由表 |
| **互联** | 连接无数异构网络，形成 Internet |

一句话：**边缘是主机，核心是路由器转发网。**

---

## 二、两种交换技术（重点对比）

### 1）电路交换（Circuit Switching）

**典型：传统电话网**

- 通信前 **先建立一条独占的物理链路**（连接建立 → 通话 → 释放）
- **资源独占**：全程占用带宽，别人不能用
- **实时性强、时延小、抖动小**
- **缺点：利用率极低、不适合突发数据**

类比：**专属私人车道，全程独占**。

| 复用方式 | 要点 |
|----------|------|
| **FDM** | 频谱划频段，连接期间独占该频段 |
| **TDM** | 时间划时隙，用户在固定时隙独占带宽 |

---

### 2）分组交换（Packet Switching）——互联网主流

**典型：Internet、4G/5G、Wi‑Fi**

- 数据切成**小分组（packet）**，每个分组带**目标地址**（或标签，见虚电路）
- **存储‑转发（store‑and‑forward）**：路由器收到 → 暂存 → 查表 → 转发（须收齐整组比特再发）
- **链路共享（统计复用）**：多用户共享带宽，利用率高
- **优点：灵活、高效、适合突发数据**
- **缺点：有排队时延、可能乱序、可能丢包**

**简化时延**（忽略传播/处理）：单分组经 **N** 段速率均为 **R** 的链路：

`d_end-end ≈ N × (L / R)`（**L** 分组长度 bit，**R** bps）

类比：**快递分包裹，走不同路线，共享公路网**。

![分组交换：存储转发；数据报 vs 虚电路](../assets/packet_switching_store_forward.png)

#### 分组交换的两种形态

| | **数据报（Datagram）** | **虚电路（Virtual Circuit）** |
|--|------------------------|-------------------------------|
| 连接性 | **无连接**（每包独立选路） | **面向连接**（呼叫建立时定路径） |
| 转发依据 | 分组头 **目的地址** | **VCI 标签**（本地有效，每跳可改） |
| 路径 | 各包路径**可不同** | 建立后路径**固定** |
| 路由器状态 | 一般**无** per-flow 状态 | 须维护**虚电路表** |
| 类比 | 每路口**问路** | 先订好**专属通道号** |
| 代表 | **Internet（IP）** | X.25、**ATM** |

![虚电路：每跳 VCI 查表、换标](../assets/virtual_circuit.png)

## 三、电路交换 vs 分组交换（背诵对比表）

| 对比项 | 电路交换 | 分组交换 |
|--------|----------|----------|
| 连接方式 | 面向连接（独占链路） | 无连接 / 面向连接（共享链路） |
| 资源分配 | 固定预留 | 动态按需（统计复用） |
| 时延 | 小、固定 | 较大、可变（排队） |
| 可靠性 | 高（无丢包） | 可能丢包、乱序 |
| 适用场景 | 语音、实时专线 | 数据、网页、突发流量 |
| 代表网络 | 电话网 | 互联网（TCP/IP） |

一句话：**电话用电路，互联网用分组。**

---

## 四、路由 vs 转发（必考）

![路由算法填表；转发按 header 查出接口](../assets/routing_vs_forwarding.png)

### 1）转发（Forwarding）——本地动作

- 发生在**单个路由器**
- 依据**转发表（FIB）**：查分组头（如目的前缀）→ **出接口**
- **把分组从入接口送到出接口**
- 快、偏硬件、毫秒级

### 2）路由（Routing）——全局计算

- 发生在**整个网络**（分布式算法）
- 依靠**路由协议**（如 OSPF、BGP）
- **计算源到目的的最优路径，生成/更新路由表（RIB）**，再下发到 FIB
- 慢、软件计算、秒级～分钟级

### 一句话区分

**路由 = 选路（全局）；转发 = 送货（本地）**

## 五、易错对比（考试速记）

| 易混 | 纠正 |
|------|------|
| 路由 = 转发？ | **路由**算路填表；**转发**按表换接口 |
| 分组交换 = 一定无连接？ | **数据报**无连接；**虚电路**在网层面向连接 |
| 电路交换一定更快？ | 时延稳定，但**静默期浪费带宽**；突发数据不如分组 |
| 存储转发 = 边收边发？ | 须**收齐整组**再查表转发（增加每跳时延） |
| Internet 用虚电路？ | 主流是 **IP 数据报**；VC 见于 ATM 等历史/专网 |

## 个人总结（直接背）

**网络核心由路由器组成；数据交换分电路交换（独占、实时）和分组交换（存储‑转发、共享、互联网主流）；分组交换分数据报（IP）与虚电路（VCI+状态）；路由是全局选路，转发是本地送出。分组交换 + 路由选择，是互联网高效传输海量数据的根本。**
