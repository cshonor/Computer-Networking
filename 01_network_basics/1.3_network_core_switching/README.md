# 1.3 — network core switching

## 知识点速记

- **分组交换**：报文切分为分组；**存储转发**：收齐整组比特再转发。
- **简化时延**：单分组经 **N** 段速率 **R** 的链路，`d ≈ N × (L/R)`（忽略传播/处理时）。
- **电路交换**：FDM / TDM 预留资源；对突发流量效率通常不如分组交换的统计复用。
- **网络的网络**：Tier-1、**IXP 对等**、内容提供商自建网络「靠近用户」以降低时延与成本。

## 与后端开发的联系

- 理解「流量如何到达用户」有助于排查**跨 ISP、DNS、CDN 边缘**问题；与后续 BGP/IXP 等主题衔接。
