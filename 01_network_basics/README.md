# 第1章 计算机网络和因特网

> 本章小节索引。每个子目录内均有 `README.md` / `study.md` / `demo_code/`。

- [1.3_network_core_switching](./1.3_network_core_switching/README.md) — 分组交换与电路交换、ISP 与 IXP、内容提供商网络
