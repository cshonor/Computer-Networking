# 1.4 — delay loss throughput

## 知识点速记

- **节点总时延**：`d_proc + d_queue + d_trans + d_prop`（处理、排队、传输、传播）。
- **传输 vs 传播**：前者是「把分组推上链路要多久」，后者是「比特在介质里飞多久」；升级带宽主要影响前者。
- **拥塞信号**：流量强度 **La/R** 接近 1 时排队时延急剧恶化；队列满则**丢包**。
- **吞吐量**：路径上由**最慢一段（瓶颈链路）**主导，常见瓶颈在接入网。

## 与后端开发的联系

- 调优与排障时要会算/会估：**RTT、带宽、队列、丢包** 如何共同影响接口耗时与重传。
