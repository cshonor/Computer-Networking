# 2.7 TIME_WAIT 状态

> 套接字选项：`SO_REUSEADDR`（Ch 7） · 建立/终止：[2.6](../2.6_TCP_Connect_Terminate/notes.md)

## 核心知识点

**主动关闭**一端在发完最后一个 ACK 后须停留 **2MSL**（最大分节生存期，常 **1～4 分钟**）。

## 存在理由（两个）

| # | 理由 |
|---|------|
| **1** | **可靠终止**：若最后 ACK 丢失，对端重传 FIN；主动方仍在 TIME_WAIT 可**重传 ACK**；否则只能回 **RST** |
| **2** | **旧分节消逝**：同 IP+端口立即建新连接时，网上**迷途旧分节**可能误入新连接；2MSL 内旧报文应已消亡 |

## 易错点与坑点

**端口占用**：TIME_WAIT 占用本地端口 → 立即重启服务器 `bind` 失败（**Address already in use**）→ 常用 **`SO_REUSEADDR`**（Ch 7）。
