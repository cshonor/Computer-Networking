## 核心知识点

网络应用由相互通信的 **客户（client）** 与 **服务器（server）** 组成，通信遵循特定 **协议（protocol）**。本书以 **TCP/IP 协议族** 为切入点，说明局域网与广域网互连的物理与逻辑结构。

| 概念 | 说明 |
|------|------|
| **客户/服务器模型** | 客户端主动发起请求，服务器被动响应 |
| **TCP/IP** | 网络程序经同一网络或互连网通信；**TCP** 提供面向连接的可靠字节流，**IP** 负责路由 |
| **LAN** | 同一网络内应用通信**无需路由器** |
| **WAN** | 不同局域网间需经 **路由器** 连接；最大 WAN 即 **因特网（Internet）** |
| **逻辑 vs 物理** | 应用层表现为端到端逻辑通信；物理上经本地协议栈 → 介质 → 对端协议栈 |

## 易错点与坑点

| 易混 | 纠正 |
|------|------|
| **因特网 vs 网际网** | **Internet**（专有，全球最大 TCP/IP 网络）≠ **internet**（普通名词，任意采用 TCP/IP 的网络） |
| **应用协议 vs 网络协议** | Web 用 **HTTP**（应用层）；实际传输靠 **TCP / IP**（传输层、网络层） |
