## C ↔ Rust 对照

| C | Rust |
|---|------|
| `argc`/`argv[1]` | `env::args()`，`len()==2` |
| `sockaddr_in`+`htons`+`inet_pton` | `format!("{host}:13")` |
| `socket`+`connect` | `TcpStream::connect(&addr)` |
| `while read>0` | `loop { read; if n==0 break }` |
| `recvline[n]=0`+`fputs` | `from_utf8_lossy(&buf[..n])` |

## 编译运行

```bash
cd code/1.2_SimpleTimeClient/rewrite_rust
cargo run -- 127.0.0.1
```

## 要点

- TCP **必须循环 read**；`n==0` = 对端 FIN。
- `connect` 失败须**重新** `TcpStream::connect`。
- 可选 [readn.rs](./code/1.2_SimpleTimeClient/rewrite_rust/readn.rs) → [Ch 3.9](../Chapter03_SocketProgramIntro/3.9_Readn_Writen_Readline.md)。
