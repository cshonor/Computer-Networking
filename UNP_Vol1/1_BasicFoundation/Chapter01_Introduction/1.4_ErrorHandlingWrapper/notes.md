# 1.4 错误处理：包裹函数

---

## 核心主旨

系统调用可能失败，必须检查返回值。本书用 **包裹函数（首字母大写）** 统一 `err_sys` 退出，避免错误检查淹没业务逻辑。

---

## 核心机制

- 例：`socket` → **`Socket`**；返回值 < 0 → **`err_sys`**（读 **`errno`**）→ `exit`  
- **`errno`** 仅在函数**返回错误**时有意义；成功时不保证为 0  

---

## 易错细节

| 场景 | 要点 |
|------|------|
| **多线程** | `errno` 常为 TLS |
| **Pthread** | 错误在**返回值**，不设置 `errno` |
