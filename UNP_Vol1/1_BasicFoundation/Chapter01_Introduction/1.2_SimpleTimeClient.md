# 1.2 一个简单的时间获取客户程序

## 本节要会什么

**TCP 客户端五步法** + 在 `sockaddr_in` 里分清 **IP 和端口各填哪个字段**。

**程序干什么**：连对方 **TCP 端口 13（Daytime）**，读一行时间文字并打印。

## 一、五步法（第 2 步：IP 和端口分开看）

| # | 步骤 | 做什么 |
|---|------|--------|
| 1 | `socket` | 创建 TCP/IPv4 套接字 → 得到 `sockfd` |
| 2 | **填服务器地址** | 往 `sockaddr_in servaddr` 里写 **IP + 端口**（见下表） |
| 3 | `connect` | 把地址交给内核 → **三次握手** |
| 4 | `while (read…)` | 循环读 TCP **字节流**（可能分多次） |
| 5 | `exit` / `close` | 关连接（发 FIN） |

### 第 2 步必记：哪个是 IP？哪个是端口？

连服务器要像打电话：**拨哪个号（IP）** + **分机几（端口）**。1.2 里写进 **`struct sockaddr_in servaddr`**：

| 你要填的 | 结构体字段 | 1.2 代码 | 数据从哪来 |
|----------|------------|----------|------------|
| **IP 地址** | **`sin_addr`** | `inet_pton(AF_INET, argv[1], &servaddr.sin_addr)` | 命令行 **`argv[1]`**，如 `"127.0.0.1"` |
| **端口号** | **`sin_port`** | `servaddr.sin_port = htons(13);` | 固定 **13**（Daytime 服务） |
| **IPv4** | **`sin_family`** | `servaddr.sin_family = AF_INET;` | 和 `socket(AF_INET,…)` 一致 |
| **先清零** | 整个 `servaddr` | `bzero(&servaddr, sizeof(servaddr));` | 避免垃圾字节 |

```text
  argv[1] "192.168.0.1" ──inet_pton──► sin_addr   （IP，4 字节）
  整数 13 ──htons───────────────► sin_port  （端口，网络序）
                    servaddr
                         │
                    connect()
                         ▼
                   内核：连到 该IP:13
```

**「网络字节序」**只影响**怎么把数字写进 `sin_port` / `sin_addr`**（端口用 `htons`；IP 用 `inet_pton`）。详解不重复写 → [附录·字节序](./1.2_Appendix_C新手与字节序.md#ch1-2-byteorder)。

```text
socket → 填 servaddr(IP+端口) → connect → while read → exit
```

<a id="ch1-2-api"></a>

## 二、API 速查

| API | 一句话 |
|-----|--------|
| `socket(AF_INET, SOCK_STREAM, 0)` | IPv4 + TCP |
| `connect(fd, (SA*)&servaddr, sizeof…)` | 主动连接；失败不能同 fd 再 connect |
| `read` / `while (n>0)` | TCP 无边界；`n==0` 对端关闭；`n<0` 出错 |

```c
struct sockaddr_in {
    sin_family;   /* AF_INET */
    sin_port;     /* 端口 ← htons(13) */
    sin_addr;     /* IP   ← inet_pton(..., argv[1], ...) */
    sin_zero[8];  /* 填 0 */
};
```

<a id="ch1-2-cheat"></a>

## 三、易错（4 条）

| ❌ | ✅ |
|----|-----|
| 一次 `read` 读完 | **`while` 循环** |
| `sin_port = 13` 不 htons | **`htons(13)`** |
| `connect` 失败再 connect 同 fd | **close → 新 socket** |
| 对 `inet_pton` 结果再 `htonl` | **只 pton，别重复转** |

## 六、个人总结

1. 五步法；**第 2 步**：**`sin_addr`=IP（`inet_pton`+`argv[1]`），`sin_port`=端口（`htons(13)`）**。
2. TCP 要 **while read**；C 里 `recvline[n]=0` 只为 `fputs` 当字符串。
3. 深材料看附录，主笔记只留骨架。

**30 字**：建套接字 → 填 IP 与 13 端口 → connect → 循环读到 0 → 退出。
