# 1.7 OSI 模型

> 原始套接字：Ch 28（绕过传输层）· Ch 29（数据链路层）

## 核心知识点

介绍 **OSI 七层**与 **TCP/IP 四层**的映射，并说明**套接字 API** 位于应用层与传输层的交界。

## 执行流程原理

### OSI 七层

1. 物理层 · 2. 数据链路层 · 3. 网络层 · 4. 传输层 · 5. 会话层 · 6. 表示层 · 7. 应用层

### TCP/IP 简化映射

| TCP/IP | 对应 OSI |
|--------|----------|
| **应用层** | 会话 + 表示 + 应用（顶上三层合并） |
| **传输层** | 传输层（TCP / UDP） |
| **网络层** | 网络层（IPv4 / IPv6） |

### 套接字 API 的定位

- 套接字是 OSI **顶上三层进入传输层**的接口  
- **上三层**：业务逻辑，多为**用户进程**  
- **下四层**：可靠性、路由等，多为**内核**  
- **结论**：API 自然落在用户进程与内核模块交界处

### 原始套接字（Raw Socket）

| 层级 | 章节 |
|------|------|
| 绕过传输层，直接用 IPv4/IPv6 | Ch 28 |
| 绕过 IP，读写链路层帧 | Ch 29 |
