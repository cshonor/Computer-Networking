## 一、C 零基础 FAQ

### `argc != 2`

| 命令 | `argc` |
|------|--------|
| `./daytimetcpcli` | 1 ❌ |
| `./daytimetcpcli 127.0.0.1` | 2 ✅ |
| `./daytimetcpcli 1.1.1.1 x` | 3 ❌ |

`argv[0]`=程序名，`argv[1]`=**IP 字符串**。代码含义：**不是 2 就报错**（必须「程序名+1 个 IP」）。

### `bzero`

整块清零 `servaddr`，避免未赋值字段是垃圾值。等价 `memset(&servaddr, 0, sizeof(servaddr))`；BSD/POSIX 提供，UNP 老习惯。

### `inet_pton` 三参数

```c
inet_pton(AF_INET, argv[1], &servaddr.sin_addr);
```

| 参数 | 作用 |
|------|------|
| `AF_INET` | 按 IPv4 解析 |
| `argv[1]` | **输入**：`"192.168.0.1"` |
| `&sin_addr` | **输出**：4 字节二进制（已网络序） |

## 二、网络字节序（只记和 1.2 相关的）

**网络字节序** = 上网时多字节整数用**大端**（高位字节在前）。PC 内存常是小端，所以**端口**要自己转。

| 填什么 | 字段 | 代码 | 说明 |
|--------|------|------|------|
| **端口 13** | `sin_port` | `htons(13)` | 不写 htons，小端机上可能连到**错误端口** |
| **IP** | `sin_addr` | `inet_pton(...)` | 内部已转好，**勿再** `htonl` |

**端口 13 的字节**：网络序 `00 0D`；错写 `sin_port=13`（小端）可能变成 `0D 00` → 被读成 3328。

**IP `192.168.0.1`**：字符串不是「大端」；`inet_pton` 后 4 字节为 `C0 A8 00 01`（与点分从左到右一致）。

## 三、内核在干什么（简图）

```text
填 servaddr（IP+端口）→ connect → 内核三次握手 → read 从 TCP 缓冲区取数据 → exit 关 fd
```

`connect` 失败：**不能**同一 fd 再 connect → close → 新 socket。
